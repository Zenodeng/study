A 集合 Sets

A1　符号与计数

基础

∈ 元素，⊆ 集合；∩ 交，∪ 并，′ 补，∅ 空集，ξ 全集。n(A ∪ B) = n(A) + n(B) - n(A ∩ B)。

Venn 应用题顺序

先填交集 → 再填只 A、只 B → 最后填都不 → 验算总数等于 n(ξ)。三集合先填最中间，再填两两部分去掉三交集的部分。

De Morgan

(A ∪ B)′ = A′ ∩ B′；(A ∩ B)′ = A′ ∪ B′。取补后，或与且互换。

B 二次函数与交点

B1　联立与判别式

必考

直线与曲线：代入 → 整理成二次方程 → 解 x → 代回直线求 y → 写 (x, y) 对。Δ > 0 两交点；Δ = 0 相切；Δ < 0 无交点。

切线模板

联立得二次方程，令 Δ = 0 解参数 k，再把 k 代回解切点横坐标，最后代回直线得纵坐标。只给 k 不给切点会丢分。

B2　配方法

必考

2x² - 8x + 5 = 2(x-2)² - 3：顶点 (2,-3)，最小值 -3，值域 y ≥ -3。配平方后括号外的常数要乘回系数。

C 根式指数对数

C1　根式与指数

必考

√48 = 4√3；有理化用共轭：(a+b)(a-b) = a²-b²。27^(2/3) = 9：先开立方再平方。负指数是倒数，零指数是 1（底数 ≠ 0）。

C2　对数法则为什么成立

深挖

设 a^m = x，a^n = y，则 xy = a^(m+n)，所以 log_a(xy) = log_a x + log_a y。同理可得商、幂的法则。log(a+b) ≠ log a + log b。

验根

平方、去对数、换元（y > 0）后都必须验根：检查定义域和原方程。log 定义域取交集。

D 因式定理

D1　余数与因式

主力

f(x) = (x-a)Q(x) + f(a)，所以除以 (x-a) 的余数是 f(a)；f(a) = 0 当且仅当 (x-a) 是因式。试根先试 ±1、±2、±常数项因数；首系数不是 1 时，有理根的分子是常数项因数，分母是首系数因数。

三次分解流程

试根 → 确认因式 → 综合除或长除得二次商式 → 再分解二次式 → 令每个因式等于 0，写出全部根。

E 函数与绝对值

E1　复合与反函数

必考

fg(x) = f(g(x))，从右往左。复合存在条件：内层值域 ⊆ 外层定义域。反函数步骤：设 y = f(x)，解出 x，互换，写定义域（= 原函数值域）。

E2　绝对值

分段

y = |f(x)| 翻下方；y = f(|x|) 左右对称。|ax+b| = c 拆两条；|x| < a 是一段区间；|x| > a 是两段。两个绝对值相加用分段点分区间，解与区间取交集。

变换效果
y = f(x) + a向上平移 a
y = f(x + a)向左平移 a
y = af(x)纵向伸缩 a 倍
y = f(ax)横向伸缩 1/a 倍
y = -f(x) / y = f(-x)关于 x 轴 / y 轴反射

F 跨章综合

Ch1 + Ch8：用集合语言写定义域、值域。Ch2 + Ch8：直线与 |x| 图象交点，先画图定个数，再分段联立。Ch3 + Ch4：三次式系数含根式，先分解再化简。Ch3 + Ch8：复合或反函数里出现 log、根号、分母，第一步永远是定义域。Ch2 + Ch4：曲线与 x 轴交点横坐标就是方程的根。

多步题检查清单

定义域 → 参数范围是否拆成两段 → 增根是否验 → 坐标与解集格式 → 最后代回原题检验一次。

G 应试技巧：同样会做，怎么多拿 5 分

① 定义域、值域在第一步写，不要等到最后补。② Hence 的题用上一问结论，不要另起炉灶。③ exact form 时不要写小数。④ 坐标写成 (x, y) 对，解集写成集合或不等式。⑤ 判别式题先确认 x² 系数 ≠ 0。⑥ 平方、去对数后验根并写出舍去的理由。

H 考前 15 分钟速查

  • Δ = b² - 4ac；Δ > 0 两交点，Δ = 0 相切，Δ < 0 无交点。
  • 配方法：2x² - 8x + 5 = 2(x-2)² - 3，顶点 (2,-3)。
  • log 法则：积变和，商变差，幂变系数；换底 log_a b = ln b / ln a。
  • 余数 f(a)，因式 f(a) = 0；综合除最后一位是余数。
  • fg 先 g 后 f；f⁻¹ 定义域 = f 值域；f⁻¹(x) ≠ 1/f(x)。
  • |x| < a 一段，|x| > a 两段；|f(x)| 翻下方，f(|x|) 左右对称。
  • n(A ∪ B) = n(A) + n(B) - n(A ∩ B)；De Morgan 取补后或与且互换。
