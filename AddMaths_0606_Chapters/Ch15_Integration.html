15.1–15.3 逆微分求 +c、幂函数积分与 (ax + b)ⁿ

15.1 Differentiation Reversed & Constant c · 15.2 ∫ xⁿ dx · 15.3 ∫ (ax + b)ⁿ dx
⚠️ 忘写 + c 直接扣 A1 分 二阶导反推原方程需两组条件

15.1 逆微分与由边界条件 (x₀, y₀) 反求常数 c

积分（Integration）是微分的逆运算（Anti-differentiation）。由于任何常数的导数都是 0，若已知 dydx = f'(x)，积分只能还原出相差一个垂直平移常数的曲线族 y = f(x) + c（c 称为积分常数 Constant of integration）。必须代入给定的边界条件（Boundary condition，如过点 (x₀, y₀) 或已知某点切线斜率）才能唯一确定 c。

  • 一阶还原（1 次积分）：已知 dydx 及一点 (x₀, y₀) ⇒ y = ∫ (dydx) dx + c，代入点坐标解出 c。
  • 二阶还原（2 次积分）：已知 d²ydx²，第一次积分先求 dydx（产生 + c₁，用已知切线斜率或驻点 dy/dx = 0 定 c₁），第二次积分再求 y（产生 + c₂，用已知点定 c₂）。

15.2–15.3 基本幂函数 ∫ xⁿ dx 与线性复合 ∫ (ax + b)ⁿ dx（n ≠ −1）

∫ k xⁿ dx = k xn+1n + 1 + c  (n ≠ −1)   |   ∫ (ax + b)ⁿ dx = (ax + b)n+1a(n + 1) + c  (n ≠ −1)
三大禁区红线：
1. 指数 n = −1 是特例！对 x⁻¹ 或 (ax + b)⁻¹ 若套用公式会除以 0，必须改用 15.6 对数积分 ln|ax + b|！
2. 线性底数限制：公式 15.3 中的括号内必须是线性一次式 ax + b（导数为常数 a）。遇到 ∫ (x² + 1)² dx 绝对不能写成 (x²+1)³/(6x)——必须先展开成 x⁴ + 2x² + 1 再逐项积分！
3. 乘除先化简为幂次和：没有“积分乘积法则”或“积分商法则”！遇到 ∫ x² − 3√x dx 先拆成 ∫ (x3/2 − 3x−1/2) dx！
📘 例题 15.1–15.3 · 线性复合根式积分与二阶导反推原曲线（Paper 1）

(a) 求不定积分 ∫ (3x − 2)⁴ dx；
(b) 已知曲线满足 dydx = 6√2x + 1 且经过点 (4, 20)，求曲线方程 y。

解：
(a) ∫ (3x − 2)⁴ dx = (3x − 2)⁵3 × 5 + c = 115(3x − 2)⁵ + c。
(b) 先改写为负分数指数：y = ∫ 6(2x + 1)−1/2 dx = 6 · (2x + 1)1/22 × ½ + c = 6√2x + 1 + c。
代入点 (4, 20)：20 = 6√8 + 1 + c = 18 + c ⇒ c = 2。
故曲线方程为 y = 6√2x + 1 + 2。

15.4–15.6 标准初等函数积分速查表

小节 被积表达式 不定积分结果（必须 + c） 考场防错警报
15.4 指数 ∫ eax + b dx 1a eax + b + c 分母是 a（注意负指数如 ∫ e−2x dx = −½ e−2x + c）；求值时别忘 e⁰ = 1！
15.5 三角 (sin) ∫ sin(ax + b) dx −1a cos(ax + b) + c 积分 sin 带负号！（恰与微分相反，随时逆求导验算！）x 必须弧度！
15.5 三角 (cos) ∫ cos(ax + b) dx +1a sin(ax + b) + c 积分 cos 为正号；求导才出负号，两者切勿混淆！
15.5 三角 (sec²) ∫ sec²(ax + b) dx 1a tan(ax + b) + c 见到 ∫ tan² x dx 立即用 sec² x − 1 替换 ⇒ tan x − x + c！
15.6 倒数 (ln) ∫ 1ax + b dx 1a ln|ax + b| + c 必有系数 1a 与绝对值符号；如 ∫ 63x − 2 dx = 2 ln|3x − 2| + c！
🔄 Paper 1/2 两大隐形积分改写（没有直接公式，必须先变身！）

① 三角平方积分：
• ∫ tan²(kx) dx = ∫ [sec²(kx) − 1] dx = 1k tan(kx) − x + c。
• ∫ sin² x dx = ∫ ½(1 − cos 2x) dx = ½x − ¼ sin 2x + c； ∫ cos² x dx = ∫ ½(1 + cos 2x) dx = ½x + ¼ sin 2x + c。
② 假分式长除/拆项成 1/(ax+b)：遇到分子次数 ≥ 分母，如 4x + 52x + 1，先凑分子 2(2x + 1) + 32x + 1 = 2 + 32x + 1，积分立刻得 2x + 32 ln|2x + 1| + c！

15.7 逆向求导技巧 ("Differentiate … hence find ∫ …")

Further Indefinite Integration: Reverse Differentiation (0606 Paper 1/2 Exam Classic)
必考套路：“hence” 两问联动 0606 不考分部积分，全靠此法!

15.7.1 为什么考纲出 “Differentiate F(x) and hence find ∫ g(x) dx”？

IGCSE Additional Mathematics (0606) 考纲不包含分部积分（Integration by parts）或换元积分，但考官仍然会让你求 ∫ x e3x dx、∫ x cos(2x) dx、∫ ln x dx 或 ∫ x√x + 1 dx！解题的唯一密码就是：第一问先求某个函数 F(x) 的导数，第二问直接把第一问的等式两边同时取积分并移项！

📘 例题 15.7 · 逆向求导经典双连击：指数与三角型（Paper 1）

(a) 求 ddx(x e3x)，并由此（hence）计算定积分 ∫₀¹ 6x e3x dx 的精确值。
(b) 求 ddx[x sin(2x)]，并由此求不定积分 ∫ x cos(2x) dx。

解：
(a) ddx(x e3x) = 3x e3x + e3x。
两边积分得：x e3x = 3 ∫ x e3x dx + ∫ e3x dx = 3 ∫ x e3x dx + 13 e3x。
注意被积式是 6x e3x = 2 × (3x e3x)，直接把整个原式乘以 2：
∫ 6x e3x dx = 2(x e3x − 13 e3x) = 2x e3x − 23 e3x + c。
代上下限 [0, 1]：[2e³ − 23 e³] − [0 − 23 e⁰] = 43 e³ + 23 = 4e³ + 23。
(b) ddx[x sin(2x)] = 2x cos(2x) + sin(2x)。
故 2 ∫ x cos(2x) dx = x sin(2x) − ∫ sin(2x) dx = x sin(2x) + ½ cos(2x)。
两边除以 2 并加 + c：∫ x cos(2x) dx = ½ x sin(2x) + ¼ cos(2x) + c。

15.8–15.9 定积分运算性质与 Paper 1 精确化简

∫ab f(x) dx = [ F(x) ]ab = F(b) − F(a)
定积分核心法则与常见陷阱：
• 常数 + c 在 F(b) − F(a) 中互相抵消，定积分不必写 + c。
• 下限为 0 ≠ 结果为 0！遇到 e⁰ = 1、cos 0 = 1、(2·0 + 3)³ = 27 务必老老实实代入算出来，切忌随手划成 0！
• 对数定积分必用对数律合并：ln b − ln a = ln(ba)（考纲常要求答成单一对数 k ln p 形式）。

15.10–15.11 曲边面积：x 轴上下分段绝对值与两曲线间面积

  • 单曲线与 x 轴围成面积 (15.10)：
    • 曲线在 x 轴上方（y ≥ 0）：面积 = ∫ab y dx > 0。
    • 曲线在 x 轴下方（y ≤ 0）：定积分算出为负值，几何面积必须加负号或绝对值：Area = −∫ab y dx = |∫ab y dx|。
    • 跨 x 轴区域（Crossing x-axis）：必须先解方程 y = 0 找到交点 x = c ∈ (a, b)，分段求值再取绝对值相加：Total Area = |∫ac y dx| + |∫cb y dx|！直接积分 ∫ab y dx 会导致正负面积抵消而全错！
  • 两曲线（或曲线与直线）围成面积 (15.11)：
    • Step 1：联立 f(x) = g(x) 求解两交点横坐标 a 与 b（作为积分上下限）。
    • Step 2：判断在 (a, b) 内哪条曲线在上方（取一测试点代入比较 yupper > ylower）。
    • Step 3：直接套用 Area = ∫ab (yupper − ylower) dx（只要上减下正确，即使区域部分或全部位于 x 轴下方，该公式依然直接输出正面积，无需分段！）。

SME 15.1 · Paper 1 逆微分与边界条件求常数 +c[6 marks]
A curve is such that d²ydx² = 4e2x − 18(3x + 1)² for x > −13. At the point (0, 5), the gradient of the curve is 10.
Find the exact equation of the curve in terms of x.
无计算器：连续两次积分由二阶导数还原曲线，并用导数条件和点坐标分别确定 c₁ 与 c₂。
查看官方评分标准 (Mark Scheme · 6 Marks)

M1 First integration: dydx = ∫ [4e2x − 18(3x + 1)⁻²] dx = 2e2x + 18(3x + 1)⁻¹3 + c₁ = 2e2x + 63x + 1 + c₁ (A1).

M1 At x = 0, dy/dx = 10: 10 = 2(1) + 6 + c₁ ⇒ c₁ = 2 (A1).

M1 Second integration: y = ∫ [2e2x + 63x + 1 + 2] dx = e2x + 2 ln(3x + 1) + 2x + c₂ (A1 for ln coefficient 6/3 = 2).

A1 At (0, 5): 5 = e⁰ + 2 ln 1 + 0 + c₂ = 1 + 0 + c₂ ⇒ c₂ = 4.
Hence y = e2x + 2 ln(3x + 1) + 2x + 4.

SME 15.2 · Paper 1 逆向求导经典 "Differentiate x cos(3x) hence…"[7 marks]
(a) Differentiate x cos(3x) with respect to x. [2]
(b) Hence find ∫ x sin(3x) dx, and calculate the exact value of ∫₀π/6 x sin(3x) dx. [5]
无计算器：先求 x cos(3x) 的导数，再逆用它求出 ∫ x sin(3x) dx 及其精确积分值。
查看官方评分标准 (Mark Scheme · 7 Marks)

M1 Product rule: ddx(x cos 3x) = cos 3x − 3x sin 3x (A1).

M1 Integrate both sides: x cos 3x = ∫ cos 3x dx − 3 ∫ x sin 3x dx.

M1 Rearrange: 3 ∫ x sin 3x dx = 13 sin 3x − x cos 3x.

A1 Divide by 3: ∫ x sin(3x) dx = 19 sin(3x) − 13 x cos(3x) + c.

M1 Evaluate from 0 to π/6: [19 sin(π2) − π18 cos(π2)] − [0 − 0].

A1 = 19(1) − 0 = 19.

SME 15.3 · Paper 1 直线与双曲线围成面积（联立求限 + ln）[7 marks]
The curve y = 6x (x > 0) and the straight line y = 7 − x intersect at two points A and B.
(a) Find the coordinates of A and B. [3]
(b) Find the exact area of the finite region enclosed between the line and the curve, giving your answer in the form p − q ln 6, where p is a rational fraction and q is an integer. [4]
先联立曲线与直线求出两个交点横坐标作为积分上下限，再用“上减下”求出含 ln 6 的精确夹面积。
查看官方评分标准 (Mark Scheme · 7 Marks)

M1 Equate: 6x = 7 − x ⇒ x² − 7x + 6 = 0 ⇒ (x − 1)(x − 6) = 0 (A1 x = 1, 6).

A1 Intersection points: A(1, 6) and B(6, 1).

M1 On [1, 6], line is above curve (check x = 2: 5 > 3): Area = ∫₁⁶ (7 − x − 6x) dx.

M1 Antiderivative: [ 7x − 12x² − 6 ln x ]₁⁶ (A1).

A1 = (42 − 18 − 6 ln 6) − (7 − 12 − 6 ln 1) = 24 − 6 ln 6 − 132 = 352 − 6 ln 6.

SME 15.4 · Paper 1/2 跨 x 轴三角函数曲线总面积[6 marks]
The curve y = 2 sin(2x) − 1 crosses the x-axis at x = π12 inside the interval 0 ≤ x ≤ π4.
(a) Verify that y = 0 when x = π12. [1]
(b) Find the exact total area bounded by the curve, the x-axis, and the lines x = 0 and x = π4. [5]
三角曲线在给定区间内穿过 x 轴，必须按零点 π/12 拆成两段分别积分并取绝对值相加！
查看官方评分标准 (Mark Scheme · 6 Marks)

B1 At x = π12, y = 2 sin(π6) − 1 = 2(½) − 1 = 0 ✓.

M1 Antiderivative: F(x) = ∫ (2 sin(2x) − 1) dx = −cos(2x) − x (A1).

M1 Below x-axis on [0, π/12]: [−cos 2x − x]₀π/12 = (−√32 − π12) − (−1) = 1 − √32 − π12 < 0 ⇒ Area₁ = √32 + π12 − 1.

M1 Above x-axis on [π/12, π/4]: Area₂ = (−π4) − (−√32 − π12) = √32 − π6.

A1 Total Area = Area₁ + Area₂ = √3 − 1 − π12 (≈ 0.470).

I01 · Unit 15.1Constant +c
Why must an indefinite integral include + c, and how is c found?
不定积分为何必写 + c？如何求其精确数值？
👆 点击查看参考答案
Differentiating any constant gives 0, so integration gives a family of vertical shifts. Substitute a given boundary condition (x₀, y₀) to solve for c.

I03 · Unit 15.3Linear Power

👆 点击查看参考答案
(ax + b)n+1 / [a(n + 1)] + c. It ONLY works when the inside is linear (constant derivative a), never for x² + 1!

👆 点击查看参考答案
Two boundary conditions (e.g., a gradient dy/dx at some x to find c₁, and a point (x₀, y₀) to find c₂; or two points).
