7.1 圆的标准方程、一般式配方与几何定圆

7.1 Equation of a Circle: Standard & General Forms, Diameter Endpoints & 3-Point Circumcircle
2025–2027 新考纲核心大章 先除以 x²/y² 首项系数再配方

7.1.1 圆的两大方程形式与配方提心算半径

1. 标准式 (Standard Form)：(x − a)² + (y − b)² = r²  ⇒  圆心 C(a, b)，半径 r
2. 一般式 (General Form)：x² + y² + 2gx + 2fy + c = 0  ⇒  圆心 (−g, −f)，半径 r = √g² + f² − c

实圆存在判别条件：一般式必须满足 g² + f² − c > 0 才代表真实存在的圆（若 = 0 退化为单点；若 < 0 无图形）。
考场最稳动作——直接配方（不要死背 g, f 正负号！）：遇到 ax² + ay² + … = 0（a ≠ 1）时，第一步必须两边同除以 a 把 x², y² 系数化为 1，再对 x 和 y 各自配成完全平方！

例题 7.1A · 系数非 1 的圆方程配方求圆心与半径

求圆 2x² + 2y² − 12x + 8y − 24 = 0 的圆心坐标与半径。
解：
① 两边同除以 2：x² − 6x + y² + 4y = 12。
② 分别配方：(x − 3)² − 9 + (y + 2)² − 4 = 12 ⇒ (x − 3)² + (y + 2)² = 25。
③ 读出结果：圆心 C(3, −2)，半径 r = √25 = 5。

7.1.2 已知直径端点或三点求圆方程 + 点与圆位置判定

  • 已知直径两端点 A(x₁, y₁), B(x₂, y₂)： ① 圆心 C = MAB（中点），半径 r = 12 AB； ② 半圆圆周角公式（直径式）：圆上任意点 P(x, y) 满足 ∠APB = 90°（mAP · mBP = −1），即 (x − x₁)(x − x₂) + (y − y₁)(y − y₂) = 0！
  • 已知圆上三点 A, B, C 求圆方程（两大路径）：
    • 几何中垂线法（首选，无计算器极快！）：任意两条弦（如 AB 与 BC）的垂直平分线交点即为圆心 O，再算 r² = OA²！
    • 待定系数法：将三点依次代入 x² + y² + 2gx + 2fy + c = 0 解三元一次方程组。
  • 点 P(x₀, y₀) 与圆的相对位置及最远/最近距离：计算 d² = (x₀ − a)² + (y₀ − b)²：d² < r² 在圆内，d² = r² 在圆上，d² > r² 在圆外；圆外一点 P 到圆周的最近距离为 PC − r，最远距离为 PC + r。
例题 7.1B · 两条垂直平分线秒求过三点 A(0,0), B(6,0), C(2,4) 的圆

① 弦 AB 水平，中点 (3, 0) ⇒ 垂直平分线为 x = 3；
② 弦 AC 中点 (1, 2)，斜率 mAC = 4 − 02 − 0 = 2 ⇒ m⊥ = −12，中垂线为 y − 2 = −12(x − 1)；
③ 联立 x = 3 得 y = 2 − 12(2) = 1 ⇒ 圆心 (3, 1)，r² = (3−0)² + (1−0)² = 10。
故圆方程为 (x − 3)² + (y − 1)² = 10（代入 B(6,0) 与 C(2,4) 均得 10 ✓）。

7.2 Intersection of Lines & Circles, Tangents & Normals, Chord Length & Tangent-Pair Kite
Δ = b² − 4ac vs 半径距离 d 风筝形 TCP₁P₂ 面积 = r · TP

7.2.1 直线与圆位置判别 & 圆上一点切线/法线

  • 直线与圆相交 / 相切 / 相离双轨判定： ① 代数联立判别式法：把直线代入圆方程整理成一元二次方程 Ax² + Bx + C = 0，Δ > 0 两交点（割线 Secant）、Δ = 0 相切（Tangent）、Δ < 0 相离； ② 几何垂距法：圆心 C(a, b) 到直线 px + qy + c = 0 的距离 d = |pa + qb + c|√p² + q²，对比 d < r、d = r、d > r。
  • 圆上一点 P(x₁, y₁) 的切线 (Tangent) 与法线 (Normal)： 法线即过圆心 C 与切点 P 的直线（永远过圆心！）；切线垂直于半径 CP，故 mtan = −1 / mCP（若半径水平或竖直，切线对应为 x = x₁ 或 y = y₁）。

7.2.2 弦长公式、圆外点双切线与风筝形 (Kite) 面积

  • 弦长 AB 极速垂径定理：若已知弦所在直线，先求圆心 C 到弦的垂足距离 d（或弦中点 M 到圆心距离），利用勾股定理直接得 AB = 2√r² − d²；也可联立求出两交点 A, B 直接套两点距离。
  • 圆外一点 T 引两切线 TP₁, TP₂ 形成的风筝形 TCP₁P₂：
    • 切线长：因为 ∠CP₁T = 90°，TP₁ = TP₂ = √TC² − r²；
    • 风筝面积：由两个全等直角三角形构成，Area(TCP₁P₂) = 2 × (12 r · TP₁) = r · TP₁；
    • 两切线方程求法：设切线 y − yT = m(x − xT)，代入圆方程令 Δ = 0 解出两个 m（若关于 m 的二次方程退化为一次方程，丢掉的另一条必是铅垂切线 x = xT！）；
    • 弦与直径组成的图形面积：若弦 AB 与圆心或直径组成三角形/风筝形，直接结合垂足高 d 与弦长 AB 得 Area(ΔCAB) = 12 · AB · d，或直径张开两直角三角形！
例题 7.2 · 圆外原点双切线与风筝面积 + 垂径求弦长

(a) 从原点 T(0, 0) 向圆 (x − 5)² + y² = 5 引两条切线，求切线斜率及风筝形 TCP₁P₂ 面积。
(b) 求直线 3x + 4y − 10 = 0 截圆 (x − 1)² + (y + 2)² = 25 所得弦长 AB。

(a) 设过原点切线 y = mx，代入圆方程得 (1 + m²)x² − 10x + 20 = 0。
相切 Δ = 0 ⇒ 100 − 80(1 + m²) = 0 ⇒ m² = 14 ⇒ m = ±12。
切线长 TP = √TC² − r² = √25 − 5 = 2√5，风筝面积 = r · TP = √5 · 2√5 = 10。
(b) 圆心 (1, −2)，r = 5。圆心到直线距 d = |3(1) + 4(−2) − 10|√3² + 4² = 155 = 3 ⇒ AB = 2√5² − 3² = 8。

7.3 两圆相对位置关系、圆心距判别与公共弦

7.3 Relative Positions of Two Circles: C₁C₂ vs r₁ ± r₂, Touching & Common Chord
外切 D = r₁ + r₂ · 内切 D = |r₁ − r₂| Eq₁ − Eq₂ 消去 x²+y² 秒得公共弦

7.3.1 六种两圆位置关系全判定表（设圆心距 D = |C₁C₂|）

位置关系判别不等式/等式交点个数考点与解题关键
1. 外离 (Disjoint Externally) D > r₁ + r₂ 0 个 两圆上点最短距 = D − r₁ − r₂；最长距 = D + r₁ + r₂。
2. 外切 (Touch Externally) D = r₁ + r₂ 1 个 切点在线段 C₁C₂ 上，按比例 r₁ : r₂ 内分 C₁C₂！
3. 相交 (Intersect) |r₁ − r₂| < D < r₁ + r₂ 2 个 两圆展开式相减消去 x² + y² 得公共弦一次直线，再代回一圆！
4. 内切 (Touch Internally) D = |r₁ − r₂| (D > 0) 1 个 切点在 C₁C₂ 延长线上；大圆包含小圆并共切线。
5. 内含 (One Inside Another) 0 < D < |r₁ − r₂| 0 个 小圆完全在大圆内部，不相交也不相切。
6. 同心圆 (Concentric) D = 0 (r₁ ≠ r₂) 0 个 两圆圆心坐标完全相同（如环道宽度 = |r₁ − r₂|）。
例题 7.3 · 两圆相交公共弦、交点与风筝形 C₁AC₂B 面积

已知圆 C₁: x² + y² = 25（圆心 (0, 0), r₁ = 5）与圆 C₂: x² + y² − 10x + 15 = 0。
① 配方 C₂：(x − 5)² + y² = 10 ⇒ 圆心 C₂(5, 0), r₂ = √10 ≈ 3.16。
② 圆心距 D = 5，满足 5 − √10 < 5 < 5 + √10 ⇒ 两圆相交于两点。
③ 两方程直接相减求公共弦：(x² + y² − 25) − (x² + y² − 10x + 15) = 0 ⇒ 10x − 40 = 0 ⇒ x = 4。
④ 代回 C₁：16 + y² = 25 ⇒ y = ±3，交点为 A(4, 3) 与 B(4, −3)（弦长 AB = 6）。
⑤ 两圆心与交点组成风筝形 C₁AC₂B 的面积：12 · D · AB = 12(5)(6) = 15！

SME 7.1 · 直径式建圆、点位置判定与法线方程 (Paper 1)[7 marks]
Points A(−1, 4) and B(5, −4) are the endpoints of a diameter of circle C.
(a) Find the equation of circle C in standard form. [3]
(b) Determine whether P(6, 2) lies inside, on, or outside circle C. [2]
(c) Find the equation of the normal to C at the point Q(−1, −4). [2]
(a) 由直径端点求圆方程；(b) 判断点在圆内外；(c) 求圆上点处的法线方程。
查看评分细则 (Mark Scheme · 7 Marks)

B1 (a) Centre M = (−1+52, 4−42) = (2, 0).

M1 Radius squared: r² = (5 − 2)² + (−4 − 0)² = 9 + 16 = 25.

A1 (x − 2)² + y² = 25.

M1 (b) CP² = (6 − 2)² + (2 − 0)² = 16 + 4 = 20.

A1 Since 20 < 25 (CP < r), P lies inside the circle.

M1 (c) Verify Q(−1, −4) is on circle (9 + 16 = 25). Normal passes through centre (2, 0) and Q(−1, −4): m = 0 − (−4)2 − (−1) = 43.

A1 y − 0 = 43(x − 2) ⇒ 4x − 3y − 8 = 0.

SME 7.2 · 圆上切线、外部交点与风筝形面积综合[8 marks]
Circle C has equation (x − 2)² + (y − 1)² = 25 with centre A. Point P(5, 5) lies on C.
(a) Find the equation of the tangent to C at P in the form ax + by = c. [3]
(b) This tangent meets the x-axis at T. A second tangent from T touches the circle at Q. Find the exact area of kite AT PQ (i.e. AP T Q). [5]
求过切点切线、切线与 x 轴交点 T，以及从 T 引两切线组成的风筝形精确面积。
查看评分细则 (Mark Scheme · 8 Marks)

M1 (a) mAP = 5 − 15 − 2 = 43 ⇒ mtan = −34 (M1).

A1 y − 5 = −34(x − 5) ⇒ 4y − 20 = −3x + 15 ⇒ 3x + 4y = 35.

B1 (b) On x-axis, y = 0 ⇒ 3x = 35 ⇒ T(353, 0).

M1 Length TP = √(353 − 5)² + (0 − 5)² = √(203)² + 5² = 5√169 + 1 = 253 (A1, exact rational!).

M1 Kite APTQ consists of two congruent right triangles (∠APT = ∠AQT = 90°), r = 5:

A1 Area = r · TP = 5 × 253 = 1253 units².

SME 7.3 · 两圆相交公共弦、交点与风筝面积 (Paper 1)[7 marks]
Circle C₁ has equation x² + y² = 25 and circle C₂ has equation x² + y² − 10x + 15 = 0.
(a) Find the centre and exact radius of C₂, and verify that C₁ and C₂ intersect at two distinct points. [3]
(b) Find the equation of the common chord and the coordinates of the intersection points A and B. [3]
(c) Find the exact area of quadrilateral C₁ A C₂ B. [1]
(a) 验证两圆相交；(b) 两圆相减求公共弦与交点；(c) 求对角线垂直风筝形面积。
查看评分细则 (Mark Scheme · 7 Marks)

B1 (a) Complete square for C₂: (x − 5)² + y² = 10 ⇒ Centre C₂(5, 0), radius r₂ = √10.

M1 D = |C₁C₂| = 5. Check 5 − √10 < 5 < 5 + √10 (A1, two intersections).

M1 (b) Subtract C₁ − C₂: 10x − 15 = 25 ⇒ 10x = 40 ⇒ x = 4 (common chord).

M1 Sub x = 4 into C₁: 16 + y² = 25 ⇒ y = ±3 ⇒ A(4, 3), B(4, −3) (A1).

B1 (c) C₁C₂ ⊥ AB with C₁C₂ = 5, AB = 6 ⇒ Area = 12(5)(6) = 15.

SME 7.4 · 两圆外切求切点坐标与公切线方程[7 marks]
Circle C₁ has centre (1, 2) and radius 3. Circle C₂ has centre (7, 10) and radius 7.
(a) Show that C₁ and C₂ touch externally. [2]
(b) Find the coordinates of the point of contact P. [2]
(c) Find the equation of the common tangent at P in the form ax + by = c. [3]
(a) 证明两圆外切；(b) 求切点坐标；(c) 求切点处的公切线方程。
查看评分细则 (Mark Scheme · 7 Marks)

M1 (a) D = √(7 − 1)² + (10 − 2)² = √36 + 64 = 10.

A1 Since r₁ + r₂ = 3 + 7 = 10 = D, the circles touch externally.

M1 (b) P divides C₁C₂ in ratio 3 : 7: P = (1 + 310(6), 2 + 310(8)) = (2.8, 4.4) (A1, or (145, 225)).

M1 (c) mC₁C₂ = 10 − 27 − 1 = 43 ⇒ mtan = −34 (M1).

A1 3x + 4y = 3(145) + 4(225) = 1305 = 26 ⇒ 3x + 4y = 26 (also equals C₁ − C₂ divided by 2!).

State the equation of a circle with centre (a, b) and radius r.

👆 点击查看参考答案
(x − a)² + (y − b)² = r². Watch the signs: (x + 3)² means centre x-coord is −3, and RHS is r² (NOT r!).
C7-02 · 7.1 一般式General Form
Given x² + y² + 2gx + 2fy + c = 0, write its centre, radius and real-circle condition.
写出一般式圆方程的圆心、半径及圆存在的判别条件。
👆 点击查看参考答案
Centre (−g, −f); Radius r = √(g² + f² − c); Real circle exists iff g² + f² − c > 0. If coeff of x², y² is k ≠ 1, divide by k first!
C7-03 · 7.1 直径式Diameter
Give TWO ways to find the circle equation when A(x₁, y₁) and B(x₂, y₂) are diameter endpoints.
已知直径两端点 A, B，写出两种建圆方法。
👆 点击查看参考答案
① Centre = midpoint MAB and r = ½ AB; ② Angle in semicircle = 90° (mAP · mBP = −1): (x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0.
C7-04 · 7.1 三点定圆3 Points
What is the fastest geometric method to find the circle passing through three points A, B, C?
求过不共线三点 A, B, C 的圆，最快的几何方法是什么？
👆 点击查看参考答案
Find equations of two perpendicular bisectors (e.g. of chords AB and BC); their intersection is the centre O, then r² = OA².
C7-05 · 7.1 点圆位置Point vs Circle
How do you find whether P is inside/outside a circle and its shortest/furthest distance to the circle?
如何判断点在圆内外，并求圆外点到圆周的最近与最远距离？
👆 点击查看参考答案
Compare PC² vs r² (< inside, = on, > outside). From outside point P, shortest distance = PC − r; furthest distance = PC + r.
C7-06 · 7.2 线圆相切Discriminant
State the two equivalent methods to prove a line is tangent to a circle.
写出证明直线与圆相切的两种等价判别方法。
👆 点击查看参考答案
① Algebraic: substitute line into circle to form quadratic and set Δ = b² − 4ac = 0; ② Geometric: perpendicular distance from centre d = r.

At point P on a circle with centre C, how do you get the normal and tangent equations?
过圆上一点 P，如何直接写出法线与切线方程？
👆 点击查看参考答案
Normal is simply the line through C and P; Tangent ⊥ radius CP, so mtan = −1 / mCP passing through P.
C7-08 · 7.2 垂直切线漏洞Edge Case
When solving Δ = 0 for tangents y − yT = m(x − xT) from external T, what if you only get ONE m?
用 Δ = 0 求圆外点 T 的切线斜率时，若只解出一个 m，丢失的那条是什么？
👆 点击查看参考答案
There are always TWO tangents from an external point! When the m² term cancels, the missing tangent is the vertical line x = xT (infinite gradient!).
C7-09 · 7.2 弦长速算Chord Length
Write the Pythagoras formula for chord length AB using radius r and perpendicular distance d from centre.
写出利用半径 r 与弦心距 d 速算弦长 AB 的公式。
👆 点击查看参考答案
Perpendicular from centre bisects the chord, so AB = 2√(r² − d²).
C7-10 · 7.2 切线风筝Tangent Kite
Two tangents from external point T touch circle (centre C, radius r) at P₁, P₂. Write tangent length TP₁ & Kite area.
写出外部点引两切线形成的切线长 TP₁ 与风筝形 TCP₁P₂ 面积公式。
👆 点击查看参考答案
Since ∠CP₁T = 90°, TP₁ = √(TC² − r²), and Kite area = 2 × (½ r · TP₁) = r · TP₁.
C7-11 · 7.2 弦高推垂足Chord Midpoint
How do you find the midpoint M of a chord cut by line L without finding the endpoints A, B?
不用解交点 A, B，如何最快求出直线 L 截圆所得弦的中点 M？
👆 点击查看参考答案
CM is perpendicular to L, so M is simply the foot of the perpendicular from centre C to line L!
C7-12 · 7.3 外切与外离External
State the distance condition D = C₁C₂ for two circles to touch externally, and how to find the point of contact.
写出两圆外切条件以及切点坐标的计算方法。
👆 点击查看参考答案
Touch externally: D = r₁ + r₂ (disjoint if D > r₁ + r₂). Contact point divides segment C₁C₂ internally in ratio r₁ : r₂.
C7-13 · 7.3 相交判据Intersecting
Write the complete inequality on D = C₁C₂ required for two circles to intersect at TWO points.
写出两圆相交于两个不同交点必须同时满足的双边不等式。
👆 点击查看参考答案
|r₁ − r₂| < D < r₁ + r₂. Remember BOTH bounds (triangle inequality): too far (D > r₁+r₂) or one inside the other (D < |r₁−r₂|) gives 0 intersections!
C7-14 · 7.3 内切与同心Internal
Distinguish touching internally, one inside the other, and concentric circles using D.
用圆心距 D 区分内切、内含与同心圆。
👆 点击查看参考答案
Touch internally: D = |r₁ − r₂| (D > 0); Strictly inside: 0 < D < |r₁ − r₂|; Concentric: D = 0 (same centre).
C7-15 · 7.3 公共弦Common Chord
How do you find the equation of the common chord (or intersection points) of two circles?
如何最快求出两个相交圆的交点与公共弦方程？
👆 点击查看参考答案
Make sure both equations start with 1x² + 1y², then subtract Eq₁ − Eq₂ to cancel x² + y² immediately → linear equation of the common chord! Then substitute into one circle.
C7-16 · 7.3 相切公切线Common Tangent
What does subtracting Eq₁ − Eq₂ produce when two circles touch (externally or internally)?
当两圆恰好外切或内切时，把两个标准展开式相减会直接得到什么直线？
👆 点击查看参考答案
Subtracting Eq₁ − Eq₂ directly yields the common tangent at the point of contact (which is perpendicular to line of centres C₁C₂)!
