11.1 杨辉三角（Pascal's Triangle）与二项式系数

Pascal's Triangle, Row Indexing & Paper 1 Rapid nCr Mental Arithmetic
Paper 1 无计算器快速算 ⁿCᵣ 杨辉三角第 0 行起算规律

11.1.1 杨辉三角构造律与 ⁿCᵣ 快速心算口诀

二项式 (a + b)ⁿ 展开式的系数恰好构成杨辉三角（Pascal's Triangle），注意行号从 n = 0 开始编号（第 n 行有 n + 1 个数）：

杨辉递推恒等式：ⁿCᵣ₋₁ + ⁿCᵣ = ⁿ⁺¹Cᵣ  |  对称性：ⁿCᵣ = ⁿCₙ₋ᵣ
Paper 1 约分速算法：ⁿCᵣ = n(n − 1)(n − 2)···(共 r 个连续递减因数)r!

示范：无计算器算 ⁹C₃ = 9 × 8 × 73 × 2 × 1 = 3 × 4 × 7 = 84；算 ¹⁰C₈ = ¹⁰C₂ = 10 × 92 × 1 = 45（先用对称性变小！）。

11.2 二项式定理：常数项、参数反求与双括号乘积展开

The Binomial Theorem: General Term, Term Independent of x & Product Expansions
通项公式必拿分 考卷提供展开式，不提供通项序号细节

11.2.1 二项式定理与四大必考母题

(a + b)ⁿ = aⁿ + ⁿC₁ aⁿ⁻¹ b + ⁿC₂ aⁿ⁻² b² + ··· + ⁿCᵣ aⁿ⁻ʳ bʳ + ··· + bⁿ
特别地：(1 + x)ⁿ = 1 + nx + n(n − 1)2! x² + n(n − 1)(n − 2)3! x³ + ···
📝 母题 1 & 2 · 常数项（Term Independent of x）与反求未知参数 n, a

题目 1： Find the term independent of x in the expansion of (2x² − 1x)⁹.
解析： 通项 Tᵣ₊₁ = ⁹Cᵣ (2x²)⁹⁻ʳ (−x⁻¹)ʳ = ⁹Cᵣ · 2⁹⁻ʳ · (−1)ʳ · x¹⁸⁻²ʳ⁻ʳ。
令 x 的总指数为 0：18 − 3r = 0 ⇒ r = 6。
代入得第 7 项：⁹C₆ · 2³ · (−1)⁶ = 84 × 8 × 1 = 672。

题目 2： The first three terms in the expansion of (1 + ax)ⁿ, in ascending powers of x, are 1 + 20x + 160x². Find n and a.
解析： 对照系数列联立方程：
① na = 20；② n(n − 1)2 a² = 160 ⇒ n(n − 1)a² = 320。
将 a = 20n 代入②：n(n − 1) · 400n² = 320 ⇒ n − 1n = 320400 = 45。
交叉相乘：5(n − 1) = 4n ⇒ n = 5，代回①得 a = 4。

📝 母题 3 · 双括号乘积展开 (1 + px + qx²)(2 − x)⁵

题目： Find the coefficient of x² in the expansion of (1 + 2x − 3x²)(2 − x)⁵.

解析： 先将 (2 − x)⁵ 只需展开到 x² 项：
(2 − x)⁵ = 2⁵ + ⁵C₁(2⁴)(−x) + ⁵C₂(2³)(−x)² + ··· = 32 − 80x + 80x² + ···
仅挑选乘积恰为 x² 的三对组合相加：
(1)(80x²) + (2x)(−80x) + (−3x²)(32) = (80 − 160 − 96)x² = −176x²。
因此 x² 的系数为 −176（只答数字，不带 x²！）。

11.3 等差数列（Arithmetic Progressions, AP）

AP: nth Term uₙ, Sum Sₙ Formulas, uₙ = Sₙ − Sₙ₋₁ & Word Problems
公差 d = uₙ₊₁ − uₙ 恒定 考卷提供 uₙ 与 Sₙ 公式

11.3.1 等差数列核心公式与性质

通项公式：uₙ = a + (n − 1)d  |  三数成等差中项性质：2b = a + c
前 n 项和：Sₙ = n2 [2a + (n − 1)d] = n2 (a + l)（l = uₙ 为末项）
知 Sₙ 反求通项：uₙ = Sₙ − Sₙ₋₁（n ≥ 2，首项 u₁ = S₁）
📝 AP 联立求解与“最小项数不等式”

题目： In an arithmetic progression, the 4th term is 17 and the 10th term is 35. (a) Find a and d. (b) Find the least value of n such that Sₙ > 1000.

解析：
(a) u₄ = a + 3d = 17，u₁₀ = a + 9d = 35。两式相减：6d = 18 ⇒ d = 3，代回得 a = 8。
(b) Sₙ = n2[16 + 3(n − 1)] = n(3n + 13)2 > 1000 ⇒ 3n² + 13n − 2000 > 0。
求根公式得正根 n = −13 + √169 + 240006 ≈ 23.7（无计算器可用试值验算：n=23 时 S₂₃ = 23×41 = 943；n=24 时 S₂₄ = 12×85 = 1020）。
故最小正整数为 n = 24。

11.4 等比数列（Geometric Progressions, GP）

GP: nth Term uₙ = arⁿ⁻¹, Sum Sₙ, Even-Power ±r Trap & Log Inequalities
偶次幂 r²ᵏ = c 必出 ± 两解！ 对数不等式除以负数要变号

11.4.1 等比公式与两大防扣分暗礁

通项公式：uₙ = a rⁿ⁻¹  |  三数成等比中项：b² = ac
前 n 项和：Sₙ = a(1 − rⁿ)1 − r = a(rⁿ − 1)r − 1（r ≠ 1）
⚠️ GP 高频失分双陷阱

① 偶次方根丢负公比：若题干只说“geometric progression”而没说“all terms are positive”，解出 r² = 4 时必须同时写出 r = 2 与 r = −2 并分别求对应答案！
② 用对数解指数不等式忘变号：当 0 < r < 1（如 0.8ⁿ < 0.01）两边取 ln 或 lg 时，由于 ln(0.8) < 0，两边除以负数 ln(0.8) 时不等号必须反向为 >！

📝 GP 交错符号公比示范

题目： In a GP, the 2nd term is 12 and the 5th term is −324. Find r, a, and S₆.

解析：
① 两式相除：u₅u₂ = ar⁴ar = r³ = −32412 = −27 ⇒ r = −3。
② a(−3) = 12 ⇒ a = −4。
③ S₆ = −4[1 − (−3)⁶]1 − (−3) = −4(1 − 729)4 = −(−728) = 728。

11.5 无穷等比级数（S∞）与 AP / GP 综合联立

Infinite Geometric Series: Convergence |r| < 1, S∞ = a/(1−r), Recurring Decimals & AP/GP Crossover
收敛充要条件 |r| < 1 循环小数 · 反弹小球 · AP/GP 互化

11.5.1 收敛条件、循环小数与反弹球模型

无穷等比级数收敛条件（Condition for Convergence）：|r| < 1（即 −1 < r < 1）
无穷和公式：S∞ = a1 − r（当且仅当 |r| < 1 时 rⁿ → 0）
图 11.2 · 无穷等比收敛极限图（左）与反弹球上下双程陷阱模型（右）
📝 无穷级数应用：循环小数化最简分数 & 反弹球

例 1（循环小数）： Express 0.415 = 0.4151515··· as a fraction in simplest form.
解析： 拆出非循环前缀 0.4 + 循环无穷 GP：0.4 + 0.015 + 0.00015 + ···
其中循环段 a = 151000, r = 1100：
S∞ = 15/10001 − 1/100 = 15990 = 166。
合并前缀：410 + 166 = 25 + 166 = 132 + 5330 = 137330。

例 2（反弹球）： A ball is dropped from 18 m and rebounds to 23 of its previous height on each bounce. Total distance travelled before coming to rest = 18 + 2 × 121 − 2/3 = 18 + 2(36) = 90 m。

SME 11.1 · Paper 1 双括号二项展开与系数联立[7 marks]
(a) Find the first four terms in the expansion of (2 − x2)⁶ in ascending powers of x. [4]
(b) Given that the coefficient of x² in the expansion of (1 + ax)(2 − x2)⁶ is 12, find the value of a and hence find the coefficient of x³. [3]
(a) 升幂展开前 4 项；(b) 由乘积展开式的 x² 系数求出 a 并进而求 x³ 系数。
查看 SaveMyExams 标准采分步骤 (Mark Scheme · 7 Marks)

M1 2⁶ + ⁶C₁(2⁵)(−x2) + ⁶C₂(2⁴)(−x2)² + ⁶C₃(2³)(−x2)³ (A1 for coeffs 1, 6, 15, 20).

A1A1 = 64 − 96x + 60x² − 20x³（每项核对：6·32·(−1/2) = −96；15·16·(1/4) = 60；20·8·(−1/8) = −20）。

M1 (b) x² term from (1 + ax)(64 − 96x + 60x² − 20x³): 1(60) + a(−96) = 12.

A1 −96a = −48 ⇒ a = 12.

A1 Coefficient of x³ = 1(−20) + (12)(60) = −20 + 30 = 10.

SME 11.2 · AP 与收敛 GP 交叉综合大题[8 marks]
The first, fourth and fifth terms of an arithmetic progression, with non-zero common difference d, are consecutive terms of a convergent geometric progression.
(a) Find the common ratio r of the geometric progression. [4]
(b) Given that the sum to infinity of the geometric progression is 27, find the first term a and common difference d of the arithmetic progression, and hence find the sum of the first 10 terms of the arithmetic progression. [4]
某公差非零的 AP 第 1、4、5 项恰好组成收敛 GP 的连续三项：(a) 求 GP 公比 r；(b) 已知 GP 无穷和为 27，求 AP 的 a, d 及前 10 项和。
查看评分细则 (Mark Scheme · 8 Marks)

B1 AP terms: u₁ = a, u₄ = a + 3d, u₅ = a + 4d.

M1 GP property (u₄)² = u₁ · u₅: (a + 3d)² = a(a + 4d).

M1 a² + 6ad + 9d² = a² + 4ad ⇒ 2ad + 9d² = 0 ⇒ d(2a + 9d) = 0. Since d ≠ 0, 2a = −9d ⇒ d = −2a9.

A1 r = a + 3da = a − 2a/3a = 13（满足 |r| < 1 ✓）。

M1 (b) S∞ = a1 − 1/3 = 27 ⇒ 3a2 = 27 ⇒ a = 18 (A1).

A1 d = −2(18)9 = −4.

A1 Sum of first 10 terms of AP: S₁₀ = 102[2(18) + 9(−4)] = 5(36 − 36) = 0.

SME 11.3 · Paper 2 无穷和与截断误差 ln 不等式[6 marks]
A geometric progression has first term 160 and common ratio 34.
(a) Find the sum to infinity S∞. [2]
(b) Find the least integer value of n for which S∞ − Sₙ < 0.5. [4]
(a) 求无穷和 S∞；(b) 求使截断余项 S∞ − Sₙ < 0.5 的最小正整数 n（注意除以负对数变号！）。
查看评分细则 (Mark Scheme · 6 Marks)

M1 (a) S∞ = 1601 − 3/4 = 1601/4 A1 = 640.

M1 (b) S∞ − Sₙ = a1 − r − a(1 − rⁿ)1 − r = a rⁿ1 − r = 640(0.75)ⁿ.

M1 640(0.75)ⁿ < 0.5 ⇒ (0.75)ⁿ < 11280.

M1 Take logs: n ln(0.75) < ln(11280). Since ln(0.75) < 0, flip sign: n > ln(1/1280)ln(0.75) ≈ 24.87.

A1 Least integer n = 25.

SR01 · 11.1Pascal Identity
State Pascal's addition identity and how (a + b)ⁿ relates to row n of Pascal's triangle.
默写杨辉三角加法恒等式及第 n 行的索引规则。
👆 点击查看参考答案
ⁿCᵣ₋₁ + ⁿCᵣ = ⁿ⁺¹Cᵣ. Row indexing starts at n = 0 ("1"), and row n has (n + 1) entries: ⁿC₀, ⁿC₁, …, ⁿCₙ.
SR02 · 11.2General Term
Write the general (r + 1)-th term in the expansion of (a + b)ⁿ.
写出 (a + b)ⁿ 展开式的第 (r + 1) 项通项公式。
👆 点击查看参考答案
Tᵣ₊₁ = ⁿCᵣ aⁿ⁻ʳ bʳ. Remember to include any minus sign inside b (e.g. (−2/x)ʳ)!
SR03 · 11.2Independent Term
What condition locates the "term independent of x" in a binomial expansion?
如何快速定位二项展开中的“不含 x 的常数项”？
👆 点击查看参考答案
Combine all powers of x in Tᵣ₊₁ into x^(f(r)) and set exponent f(r) = 0 to solve for non-negative integer r (if r is non-integer, no constant term exists).
SR04 · 11.2Coeff vs Term
Distinguish between "the coefficient of x³" and "the term in x³".
英文问法 “coefficient of x³” 与 “term in x³” 答题格式有何不同？
👆 点击查看参考答案
Coefficient = number only (e.g. −176); Term = includes the variable power (e.g. −176x³).
SR05 · 11.2Product Trick
How do you find the xᵏ coefficient of (1 + px + qx²)(a + bx)ⁿ without expanding the whole thing?
求解双括号乘积指定次幂系数时如何只算必要项？
👆 点击查看参考答案
Expand (a + bx)ⁿ ONLY up to xᵏ, then multiply ONLY the matching pairs whose exponents add to k and sum their coefficients.
SR06 · 11.3AP Formulas
State the n-th term and both sum formulas of an Arithmetic Progression (AP).
默写等差数列（AP）通项公式与两种前 n 项和公式。
👆 点击查看参考答案
uₙ = a + (n − 1)d；Sₙ = (n/2)[2a + (n − 1)d] and Sₙ = (n/2)(a + l).
SR07 · 11.3uₙ from Sₙ
Given a formula for Sₙ, how do you recover uₙ and verify u₁?
已知前 n 项和表达式 Sₙ，如何反求任意第 n 项 uₙ？
👆 点击查看参考答案
uₙ = Sₙ − Sₙ₋₁ (for n ≥ 2), and u₁ = S₁ (always check whether the n ≥ 2 formula also works at n = 1!).
SR08 · 11.3–11.43 Consecutive Terms
If x, y, z are 3 consecutive terms of (a) an AP, (b) a GP, state the algebraic equation linking them.
若 x, y, z 是连续三项，分别写出它们成 AP 与成 GP 的方程。
👆 点击查看参考答案
AP (common difference): y − x = z − y (i.e. 2y = x + z). GP (common ratio): y/x = z/y (i.e. y² = xz).
SR09 · 11.4GP ±r Trap
Given u₃ = 12, u₅ = 48 with no restriction on signs, why must you check TWO values of r?
已知 GP 偶数间隔的两项求公比时，容易丢掉哪个解？
👆 点击查看参考答案
u₅/u₃ = r² = 4 gives BOTH r = +2 and r = −2 (yielding an alternating-sign GP unless "all terms positive" is stated!).
SR10 · 11.4Log Inequality
What critical rule applies when solving (0.75)ⁿ < 0.01 by taking logarithms?
用对数求解底数在 (0, 1) 之间的 GP 不等式时，哪一步最容易扣分？
👆 点击查看参考答案
Since 0 < 0.75 < 1, ln(0.75) < 0! Dividing both sides by a negative number reverses the inequality sign: n > ln(0.01)/ln(0.75).
SR11 · 11.5Convergence
State the necessary and sufficient condition for a geometric series to converge, and state S∞.
写出无穷等比级数的严格收敛条件及求和公式 S∞。
👆 点击查看参考答案
Converges iff |r| < 1 (strictly −1 < r < 1, so rⁿ → 0 as n → ∞). Then S∞ = a / (1 − r).
SR12 · 11.5Recurring Decimal
How do you convert 0.4151515··· into an exact fraction using an infinite geometric series?
如何把含非循环前缀的循环小数拆成“前缀 + 无穷等比级数”？
👆 点击查看参考答案
Separate the non-repeating prefix 0.4 from the repeating GP 0.015 + 0.00015 + … with a = 0.015, r = 0.01, then add 0.4 + S∞.
SR13 · 11.5Bouncing Ball
Why is the total distance travelled by a ball dropped from height H with rebound ratio r NOT simply H/(1−r)?
反弹球总路程为什么不能直接套 H/(1−r)？正确公式是什么？
👆 点击查看参考答案
The first drop H happens once, while every subsequent bounce travels BOTH UP AND DOWN (×2): Total = H + 2·[rH/(1 − r)].
SR14 · 11.5AP/GP Crossover
When solving an AP/GP crossover problem where d(2a + 9d) = 0 arises, what justifies rejecting d = 0?
AP 与 GP 联立得出 d(k·a + m·d) = 0 时，依据什么舍去 d = 0？
👆 点击查看参考答案
The problem specifies a non-zero common difference (d ≠ 0) or distinct terms (if d = 0, r = 1 so S∞ does not converge!).
