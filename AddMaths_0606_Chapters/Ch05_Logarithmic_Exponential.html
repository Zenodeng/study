5.0 预备技能速通 · 指数律、根式化简与同底指数方程

Prerequisite: Indices & Surds — Laws of Indices, Rationalising Denominators & Same-Base Exponential Equations

5.0.1 根式化简与分母有理化 (Surds & Rationalising the Denominator)

在 2025–2027 新考纲 Paper 1 禁用计算器条件下，涉及平方根的答案必须写成最简根式 (Simplest Surd Form) 且分母不能保留根号。

1. 分拆最大平方因数：√ab = √a · √b  （例：√72 = 6√2，√75 = 5√3）
2. 单项根式分母有理化：k√a = k√aa
3. 二项共轭分母有理化 (Conjugate Surds)：1a − b√c × a + b√ca + b√c = a + b√ca² − b²c
例题 5.0A · 无计算器化简共轭分母根式

将 4 + √32 − √3 写成 p + q√3 的精确形式（p, q 为整数）。

解：分子分母同乘共轭根式 2 + √3：
原式 = (4 + √3)(2 + √3)2² − (√3)² = 8 + 4√3 + 2√3 + 34 − 3 = 11 + 6√3。

5.0.2 分数指数、负指数与同底法解指数方程

指数定律 (Laws of Indices)核心含义与转化技巧Paper 1 高频示例
am · an = am+n，am ÷ an = am−n 乘加除减；加减项如 2x+1 + 2x 必须先提取公因式 2x！ 2x+1 + 2x = 3 · 2x
(am)n = amn 把底数 4, 8, 9, 27, 125 统一改写成质因数 2, 3, 5 的幂。 8x+2 = (2³)x+2 = 23x+6
a−n = 1an，(ab)−n = (ba)n 负指数只代表取倒数，绝不改变底数本身的正负号！ (8125)−2/3 = (1258)2/3 = (52)² = 254
am/n = (ⁿ√a)m 先开 n 次方再乘 m 次幂（数值更小，心算不易错！）。 27−2/3 = 1(³√27)² = 19
例题 5.0B · 同底比较法 vs 隐含二次代换法

(a) 解方程 42x−1 = 8x+2；  (b) 解方程 22x+1 − 9 · 2x + 4 = 0。

(a) 统一化为底数 2：(2²)2x−1 = (2³)x+2 ⇒ 24x−2 = 23x+6 ⇒ 比较指数：4x − 2 = 3x + 6 ⇒ x = 8。
(b) 注意 22x+1 = 2 · (2x)²。令 u = 2x（注意 u > 0）：
方程化为 2u² − 9u + 4 = 0 ⇒ (2u − 1)(u − 4) = 0 ⇒ u = 12 或 u = 4。
代回得 2x = 2−1 ⇒ x = −1，或 2x = 2² ⇒ x = 2。

5.1–5.2 常用对数 lg 与任意底对数 logₐ

5.1 Logarithms to Base 10 (lg) & 5.2 Logarithms to Base a
指数 ↔ 对数互化桥 真数 M > 0 · 底数 a > 0 且 a ≠ 1

5.1 以 10 为底的常用对数 (Logarithms to Base 10: lg x)

在剑桥 0606 教材中，lg x 专指以 10 为底的对数 log₁₀ x，即“10 的多少次方等于 x”。

  • 核心等价关系：10y = x ⇔ y = lg x（要求真数 x > 0）。
  • Paper 1 无计算器秒算值：lg 1000 = 3（因 10³ = 1000）；lg 1 = 0；lg 0.01 = −2（因 10⁻² = 0.01）；lg(10√10) = lg(103/2) = 32。
  • 互逆消去恒等式：10lg x = x（x > 0）且 lg(10y) = y。

5.2 一般底数对数 (Logarithms to Base a)

ax = y  ⇔  x = loga y   （条件：a > 0, a ≠ 1, 真数 y > 0）

四大基本恒等式： ① loga 1 = 0（任何合法底数的 1 的对数都是 0）； ② loga a = 1； ③ loga(ak) = k； ④ aloga y = y。

例题 5.2 · 求对数值与带未知底数方程

(a) 求 log₉ 27：设 log₉ 27 = x ⇒ 9x = 27 ⇒ 32x = 3³ ⇒ x = 32。
(b) 解 logx 81 = 4：改写为指数式 x⁴ = 81 ⇒ x = ±3。因对数底数必须满足 x > 0, x ≠ 1，故舍去 −3，得 x = 3。

5.3 对数三大运算法则的双向使用

  • 合并成单个对数 (Single Logarithm)：先用幂次法则 k loga x = loga(xk) 把所有前缀数字（如 2, ½）和常数（写成 c = loga(ac)）搬入对数内部，再用加变乘、减变除！
  • 拆成已知字母表达式：例如已知 p = loga 2，q = loga 3，求 loga(18√a) = loga 2 + 2 loga 3 − 12 loga a = p + 2q − 12。

5.4 解对数方程的三步标准流与“舍根铁律”

⚠️ 考场头号丢分陷阱：不写 Reject 增根直接扣 A1！

合并对数会改变原方程的定义域！例如解 lg(x + 2) + lg(x − 1) = 1 时，合并成 (x + 2)(x − 1) = 10 解出 x = 3 和 x = −4。由于原式要求 x − 1 > 0，必须在答案末尾显式写出“Reject x = −4 since x − 1 < 0 (log of negative undefined)”，只留 x = 3！

例题 5.4 · 两类高频对数方程示范

(a) 解 2 log₅(x − 1) = log₅(2x + 1)；  (b) 解 (lg x)² − 3 lg x + 2 = 0。

(a) ① 把系数 2 移入指数：log₅(x − 1)² = log₅(2x + 1)；
② 两边同底去对数：(x − 1)² = 2x + 1 ⇒ x² − 2x + 1 = 2x + 1 ⇒ x² − 4x = 0 ⇒ x = 0 或 x = 4；
③ 验根：当 x = 0 时，x − 1 = −1 ≤ 0，故 舍去 x = 0；最终仅 x = 4。
(b) 令 u = lg x（注意 (lg x)² ≠ 2 lg x！）：u² − 3u + 2 = 0 ⇒ (u − 1)(u − 2) = 0 ⇒ lg x = 1 或 lg x = 2 ⇒ x = 10 或 x = 100（均 > 0，均有效）。

5.5 两边取对数解不同底指数方程

当两边底数无法化成同底（如 32x−1 = 5x+1）时，两边同时取 lg 或 ln，把含 x 的指数拉到前面，再移项合并同类项！

例题 5.5 · 精确形式 (Paper 1) 与二次指数方程

(a) 解 32x−1 = 5x+1（给出精确 ln 形式与 3 s.f. 近似值）；(b) 解 52x − 7 · 5x + 10 = 0。

(a) 两边取 ln：(2x − 1) ln 3 = (x + 1) ln 5 ⇒ (2 ln 3 − ln 5) x = ln 5 + ln 3
⇒ 精确解：x = ln 15ln(9/5)（≈ 4.61 to 3 s.f.）。
(b) 令 u = 5x：u² − 7u + 10 = 0 ⇒ (u − 2)(u − 5) = 0。
当 5x = 2 时，x = lg 2lg 5（或 log₅ 2 ≈ 0.431）；当 5x = 5 时，x = 1。

5.6 换底公式 (Change of Base of Logarithms)

loga b = logc blogc a   |   倒数特例 (令 c = b)：loga b = 1logb a

选底原则：若两项底数分别为 4 和 16（或 3 和 9），统一换成较小的底或质底 2, 3；若出现 log2 x 与 logx 2，直接用倒数关系换元成 u 与 1/u！

例题 5.6 · 换底 + 倒数二次方程

解方程 log₂ x − 4 logx 2 = 3。
解：由换底倒数律 logx 2 = 1log₂ x。令 u = log₂ x：
u − 4u = 3 ⇒ u² − 3u − 4 = 0 ⇒ (u − 4)(u + 1) = 0。
当 log₂ x = 4 ⇒ x = 2⁴ = 16；当 log₂ x = −1 ⇒ x = 2−1 = 12（均 > 0 且 ≠ 1，全部保留）。

5.7–5.8 自然对数 (ln, e) 与指数建模应用

5.7 Natural Logarithms & 5.8 Practical Applications / Exponential Modelling
eln x = x · ln(ex) = x 初始值 t=0 · 渐近极限 t→∞ · 倍增半衰期

5.7 自然常数 e 与自然对数 ln x

  • 核心性质：e ≈ 2.71828，ln x ≡ loge x；ln 1 = 0，ln e = 1；恒等消去律：eln A = A（A > 0），ln(eB) = B。
  • 含 e−x 方程秒杀法：如 2ex − 5 + 2e−x = 0，两边同乘 ex 得 2(ex)² − 5ex + 2 = 0 ⇒ (2ex − 1)(ex − 2) = 0，解得 ex = 12 或 2 ⇒ x = −ln 2 或 x = ln 2（若解出 ex ≤ 0 必须立刻舍去！）。

5.8 实际应用建模 (Practical Applications & Exponential Growth/Decay)

常见模型：N = N₀ ekt 或冷却/饱和模型 T = A + B e−kt（k > 0）。剑桥真题标准 4 问套路：

常考设问关键词数学动作示范计算（以 V = 800e−0.04t + 200 为例）
Initial value (初始值) 代入 t = 0（利用 e⁰ = 1） V₀ = 800(1) + 200 = 1000
Rate / Constant k (已知某时刻反求常数) 代入已知 (t, V)，先隔离 ekt 再取 ln 如已知 t=25 时给定 V，先移项除以 800，再取 ln
Find time t (何时降到某阈值 / 一半) 先移常数、除系数，使左边只剩 e−0.04t 令 V = 400 ⇒ 800e−0.04t = 200 ⇒ e−0.04t = 14 ⇒ t = 25 ln 4 = 50 ln 2
Long-term / Asymptotic value (当 t → ∞) 当 t → ∞ 且指数为负时，e−kt → 0 V → 800(0) + 200 = 200（永远达不到但无限逼近 200）

5.11 指数函数与对数函数的互逆关系 (Inverse Functions)

任何严格单调的指数或对数函数都是 1-to-1 函数，均存在反函数，且图像严格关于直线 y = x 对称。求反函数 3 步：

  1. 先写出原函数 f(x) 的值域 Range（画草图或看渐近线最不易错）；
  2. 令 y = f(x)，互换 x 与 y（或反解出 x 再改写字母），用 e 消去 ln，或用 ln 消去 e；
  3. 写出 f−1(x) 并标注定义域 = 原函数值域！
例题 5.11 · 求 f(x) = 3e2x − 6 (x ∈ ℝ) 的反函数及定义域

① 原函数值域：因 e2x > 0 ⇒ 3e2x − 6 > −6，即 Range: f(x) > −6。
② 令 y = 3e2x − 6，反解 x：e2x = y + 63 ⇒ 2x = ln(y + 63) ⇒ x = 12 ln(y + 63)。
③ 改写自变量：f−1(x) = 12 ln(x + 63)，定义域为 x > −6。

SME 5.4 · 对数函数渐近线、反函数与定义域值域互换[7 marks]

(a) Write down the equation of the asymptote to the curve y = f(x) and the coordinates of its x-intercept. [2]
(b) Find an expression for f−1(x) and state its domain and range. [4]
(c) State the geometric relationship between the graphs of y = f(x) and y = f−1(x). [1]

查看评分细则 (Mark Scheme · 7 Marks)

B1 (a) Vertical asymptote: 3x − 5 = 0 ⇒ x = 53.

B1 x-intercept when 3x − 5 = 1 ⇒ 3x = 6 ⇒ (2, 0).

M1 (b) Let y = 2 ln(3x − 5) ⇒ ln(3x − 5) = y2 ⇒ 3x − 5 = ey/2 (M1).

A1 Swap variables: f−1(x) = ex/2 + 53.

C5-01 · 5.0 根式Surds
How do you rationalise a binomial denominator such as 1 / (a − b√c)?
如何有理化二项根式分母 1 / (a − b√c)？
👆 点击查看参考答案
Multiply top and bottom by its conjugate surd (a + b√c) so the denominator uses difference of squares: a² − b²c (all roots vanish!).
C5-02 · 5.0 指数Indices
Evaluate a−m/n mentally in Non-Calculator Paper 1 without arithmetic slips.
无计算器下如何按最稳顺序心算负分数幂 a−m/n？
👆 点击查看参考答案
① Negative sign means reciprocal 1 / am/n (never flips +/− sign!); ② Take the n-th root first, then raise to power m: 1 / (ⁿ√a)m.
C5-03 · 5.0 指数Same Base
How do you simplify 2x+2 + 2x and solve 42x = 8x+1?
如何合并指数加减项并解同底可化指数方程？
👆 点击查看参考答案
Factor out common base: 2x(2² + 1) = 5 · 2x. For 42x = 8x+1, rewrite both as base 2: 24x = 23x+3 ⇒ 4x = 3x + 3.
C5-04 · 5.0 换元Hidden Quadratic
Spot the substitution for 32x+1 − 10 · 3x + 3 = 0 and state the sign restriction on u.
写出该指数二次方程的换元变量及取值范围限制。
👆 点击查看参考答案
Let u = 3x > 0; rewrite 32x+1 = 3 · (3x)² = 3u² ⇒ 3u² − 10u + 3 = 0. Any root u ≤ 0 must be rejected.
C5-05 · 5.1–5.2Definition
State the equivalence y = ax ⇔ … and all three restrictions on a and y.
默写指数与对数互化定义以及底数 a 与真数 y 的三重限制条件。
👆 点击查看参考答案
y = ax ⇔ x = loga y. Valid only when a > 0, a ≠ 1, and y > 0. Note lg y = log₁₀ y and ln y = loge y.
C5-06 · 5.2 恒等式Identities
Write the values of loga 1, loga a, loga(ak) and aloga x.
写出对数四大基本恒等式的结果。
👆 点击查看参考答案
loga 1 = 0；loga a = 1；loga(ak) = k；aloga x = x (x > 0).
C5-07 · 5.3 对数律Laws
State the three Laws of Logarithms and two illegal operations students often invent.
写出三大对数运算法则以及考场严禁编造的两个错误公式。
👆 点击查看参考答案
Product: loga(MN) = loga M + loga N; Quotient: loga(M/N) = loga M − loga N; Power: loga(Mk) = k loga M. Forbidden: log(M+N) ≠ log M + log N and (log M)² ≠ 2 log M.
C5-08 · 5.4 方程顺序Combining
Before combining 2 loga x − loga(x + 3) = 1, what two steps must be done first?
合并含系数和常数的对数方程前，必须先做哪两步预处理？
👆 点击查看参考答案
① Move coefficient 2 inside as power: loga(x²); ② Convert constant 1 to loga a (or combine LHS into single log first, then raise base a¹ = a).
C5-09 · 5.4 验根红线Rejection
Why must you check every candidate root back into the ORIGINAL logarithmic equation?
为什么解对数方程后必须代回“原方程”检验，且必须写出舍去理由？
👆 点击查看参考答案
Combining lg A + lg B → lg(AB) widens domain (two negatives give positive product!). Always verify every original argument > 0 and explicitly state “reject x = … as log of negative is undefined”.
C5-10 · 5.5 精确解Exact Form
How do you solve ax = b and 2x+1 = 3x−2 in exact logarithmic form?
如何用对数求出不同底指数方程的 Paper 1 精确解？
👆 点击查看参考答案
Take lg or ln on both sides, bring exponents to front: (x+1) ln 2 = (x−2) ln 3, group all x-terms on one side and factorise: x = (ln 2 + 2 ln 3) / (ln 3 − ln 2).
C5-11 · 5.6 换底公式Change of Base
Write the Change of Base formula and its reciprocal identity linking loga b and logb a.
默写对数换底公式及其倒数恒等式。
👆 点击查看参考答案
loga b = (logc b) / (logc a)；putting c = b gives the reciprocal law loga b = 1 / logb a (used in log₂ x + 4 logx 2 = 5).
C5-12 · 5.7 自然对数Natural Log
What is the fastest first step to solve 3ex − 7 + 2e−x = 0?
遇到同时含 ex 与 e−x 的方程时，第一步怎么处理最稳？
👆 点击查看参考答案
Multiply the entire equation by ex (since ex ≠ 0) to eliminate negative power: 3(ex)² − 7ex + 2 = 0, then solve quadratic in u = ex > 0.
C5-13 · 5.8 建模极限Modelling
For cooling model T = 22 + 78e−0.05t, find initial value and long-term limit as t → ∞.
在指数衰减冷却模型中，如何读出初始值与长期极限温度？
👆 点击查看参考答案
Initial (t = 0): e⁰ = 1 ⇒ T₀ = 22 + 78 = 100; Long-term (t → ∞): since e−0.05t → 0, T → 22 (room temperature asymptote).
C5-14 · 5.10 指数图Exp Graph
For y = k enx + a, state its asymptote, y-intercept, and how sign of k sets the range.
写出平移指数函数 y = k enx + a 的渐近线、截距与值域判定规则。
👆 点击查看参考答案
Horizontal asymptote: y = a; y-intercept: (0, k + a). Since enx > 0 always, range is y > a if k > 0, and y < a if k < 0.
C5-15 · 5.10 对数图Log Graph
For y = k ln(ax + b) (a > 0), find the vertical asymptote, x-intercept and domain.
写出对数图像 y = k ln(ax + b) 的铅垂渐近线、x 轴截距与定义域。
👆 点击查看参考答案
Vertical asymptote where argument = 0: x = −b/a; x-intercept where argument = 1: x = (1 − b)/a; Domain: ax + b > 0; Range: y ∈ ℝ.
C5-16 · 5.11 互逆Inverse
When finding f−1(x) for an exponential or log function, what must accompany the formula?
写出指数/对数反函数表达式时，还必须补写什么才能拿全分？
👆 点击查看参考答案
State the domain of f⁻¹, which equals the range of f! Geometrically, f and f⁻¹ are reflections in y = x, swapping horizontal ↔ vertical asymptotes.
