12.1 导函数与幂函数求导（先化为指数形式！）

The Gradient Function: Power Rule & Rewriting Roots/Fractions Before Differentiating
未提供公式表！全部求导法则必背 先拆除根号/分母再求导

12.1.1 幂函数求导法则与“求导前化简铁律”

导数本质：曲线 y = f(x) 在任意点处的切线斜率（Gradient of tangent）dydx = f'(x)
幂函数求导（Power Rule）：若 y = a xⁿ，则 dydx = a n xⁿ⁻¹（常数求导为 0）
🚫 头号考场错误：直接对分子、分母分别求导或带着根号硬求导！

遇到分母是单项式或带根号的分式（如 3x² − 2√xx）或乘积括号（如 x²(x − 3)），必须先利用指数律拆成 a xⁿ 的和差，再逐项求导：
y = 3x²x − 2x1/2x = 3x − 2x−1/2 ⇒ dydx = 3 − 2(−12)x−3/2 = 3 + x−3/2。当 x = 4 时，dydx = 3 + 18 = 258。

12.2 链式法则（The Chain Rule）

Differentiating Composite Functions: dy/dx = (dy/du) · (du/dx)
外层降幂 · 内层别忘乘 f'(x) 负/分数次幂复合根式

12.2.1 链式法则公式与负分数幂秒算

若 y = f(u) 且 u = g(x)：dydx = dydu × dudx
实用快捷式：ddx [a (g(x))ⁿ] = a n [g(x)]ⁿ⁻¹ · g'(x)
📝 教材精选题 · 含根号分母的链式求导

题目： Given y = 6√2x² + 1, find dydx and evaluate it at x = 2.

解析： 先改写为幂指数形式：y = 6(2x² + 1)−1/2。
外层求导乘内层导数 g'(x) = 4x：
dydx = 6 · (−12)(2x² + 1)−3/2 · (4x) = −12x(2x² + 1)3/2。
代入 x = 2：2(4) + 1 = 9 ⇒ 93/2 = (√9)³ = 27，故斜率 = −2427 = −89。

12.3 乘积法则（Product Rule）与最低次幂提公因式

The Product Rule: (uv)' = u'v + uv' & Factoring Out Lowest Fractional Power
Show That 证明题核心化简技 提出最小（含负）指数括号

12.3.1 乘积求导后如何化简成单个整洁分式？

乘积法则：ddx(uv) = u dvdx + v dudx（注意：(uv)' ≠ u'v'！）
📝 0606 必杀化简技 · 提出最低次幂因式

题目： Differentiate y = x √2x + 1 and show that dydx = 3x + 1√2x + 1.

解析： 令 u = x（u' = 1），v = (2x + 1)1/2（v' = 12(2x + 1)−1/2 · 2 = (2x + 1)−1/2）。
dydx = 1 · (2x + 1)1/2 + x (2x + 1)−1/2。
关键动作：比较指数 12 与 −12，提取最小次幂 (2x + 1)−1/2！
= (2x + 1)−1/2 [(2x + 1)1 + x] = 3x + 1√2x + 1（在 x = 4 处斜率为 133）。

12.4 商法则（Quotient Rule）与求导法则决策流

The Quotient Rule: d/dx(u/v) = (v·du/dx − u·dv/dx) / v²
分子顺序：先下乘上导 − 上乘下导 切勿乱展开分母平方 v²

12.4.1 商法则公式、决策树与防错要点

商法则：ddx(uv) = v dudx − u dvdxv²

口诀：“分母平方放下面，分母先不动乘分子导 − 分子乘分母导”。注意：① 中间是减号，绝对不能颠倒 vu' 与 uv' 顺序！② 分子有括号时切记加括号再减；分母 v² 保持括号形式，方便后续约分或求驻点。

图 12.1 · 求导法则快速选择流程图（左）与曲线切线法线垂直几何关系（右）
📝 商法则标准步骤示例

题目： Differentiate y = x² + 32x − 1 and find the gradient at x = 2.

解析： u = x² + 3 (u' = 2x)，v = 2x − 1 (v' = 2)：
dydx = (2x − 1)(2x) − (x² + 3)(2)(2x − 1)² = 4x² − 2x − 2x² − 6(2x − 1)² = 2(x² − x − 3)(2x − 1)²。
代入 x = 2：2(4 − 2 − 3)3² = −29。

12.5 切线与法线方程（Tangents and Normals）

Finding Equations of Tangents, Normals & Parallel/Perpendicular Curve Points
先代入数值 x₁ 算斜率 法线斜率取负倒数 −1/m

12.5.1 切线与法线标准解法

求曲线 y = f(x) 在点 P(x₁, y₁) 处的切线或法线方程：

  1. 若仅给 x₁，先代回原曲线求出纵坐标 y₁；
  2. 求导函数 f'(x) 并代入 x = x₁ 得到切线数值斜率 mₜ = f'(x₁)（切忌把含 x 的导数表达式直接塞进点斜式！）；
  3. 法线斜率 mₙ = −1mₜ（特例：若 mₜ = 0，水平切线 y = y₁，铅垂法线 x = x₁）；
  4. 代入点斜式 y − y₁ = m(x − x₁)。
📝 切法线与坐标轴交点例题

题目： Find the equation of the normal to y = x³ − 3x² + 4 at x = 1, and find where it cuts the x-axis.

解析： 当 x = 1 时，y = 1 − 3 + 4 = 2（切点 (1, 2)）。
dydx = 3x² − 6x ⇒ mₜ = 3(1) − 6(1) = −3 ⇒ 法线斜率 mₙ = 13。
法线方程：y − 2 = 13(x − 1) ⇒ x − 3y + 5 = 0。令 y = 0 得与 x 轴交点为 (−5, 0)。

12.6 微小增量与百分比近似计算（Small Increments）

Small Increments & Approximations: δy ≈ (dy/dx)·δx & Percentage Change
δx 可正（增加）可负（减少） 百分比变化不需给 x 具体数值

12.6.1 线性近似式与百分比变化公式

微小增量近似：δy ≈ dydx · δx  |  近似新值：f(x + δx) ≈ f(x) + δy
百分比变化（Percentage change in y）：δyy × 100% ≈ 1y(dydx) δx × 100%
📝 无计算器根式估算与百分比变化双例

例 1（估算）： Use calculus to estimate √16.08 without a calculator.
设 y = x1/2，取 x = 16, δx = +0.08。dydx = 12√x = 18 = 0.125。
δy ≈ 0.125 × 0.08 = 0.01 ⇒ √16.08 ≈ 4 + 0.01 = 4.01。

例 2（百分比变化）： Given y = kx², if x increases by 1.5%, find the approximate percentage change in y.
δx = +0.015x；dydx = −2kx³。
δy ≈ (−2kx³)(0.015x) = −0.03(kx²) = −0.03y ⇒ y 约 减少 3%（−3%）。

12.8 二阶导数（Second Derivatives d²y/dx²）

Second Derivatives: Notation f''(x), d²y/dx² & Differential Identities
对 dy/dx 再求导一次 注意记号位置 d²y / dx²

12.8.1 二阶导数记法与证明恒等式

将一阶导数 dydx 再对 x 求导一次即得二阶导数 d²ydx² = f''(x)（切勿写成 (dy/dx)²！）。

📝 二阶导数恒等式验证

题目： Given y = x + 4x, show that x²d²ydx² + xdydx − y = 0.

解析： y = x + 4x⁻¹ ⇒ dydx = 1 − 4x⁻² ⇒ d²ydx² = 8x⁻³ = 8x³。
代入左边：x²(8x³) + x(1 − 4x²) − (x + 4x) = 8x + x − 4x − x − 4x = 0（证毕）。

12.9 驻点判定：极大值、极小值与拐点

Stationary Points: Max, Min & Point of Inflexion via d²y/dx² or First-Derivative Sign Test
令 dy/dx = 0 找驻点坐标 d²y/dx² = 0 时退回符号表！

12.9.1 递增递减区间与驻点分类双法

  • 递增函数（Increasing）：dydx > 0；递减函数（Decreasing）：dydx < 0。
  • 驻点（Stationary point）：令 dydx = 0 解出横坐标 x₀（如题干问 coordinates 别忘了再算 y₀！）。
  • 判定驻点性质（Nature of stationary point）：
    • 方法一（二阶导数法）：d²ydx² < 0 ⇒ Maximum；d²ydx² > 0 ⇒ Minimum；若 d²ydx² = 0 ⇒ 无法判定（既可能是极值也可能是拐点，如 x⁴ vs x³），必须改用方法二！
    • 方法二（一阶导数符号检验表）：取 x₀ 左右紧邻点检查 dy/dx 正负变化：+ → 0 → − 为极大；− → 0 → + 为极小；同号（+ → 0 → + 或 − → 0 → −）则为驻点拐点（Stationary point of inflexion）！

12.10 实际应用最值建模（Practical Max/Min Problems）

Modelling Constraints, Proving S(x), Solving dS/dx = 0 & Verifying Nature
4 步稳拿 8–10 分建模大题 结尾必算二阶导验证 Max/Min！

12.10.1 剑桥最值应用大题四步通关模板

  1. 设约束消元：由固定体积 / 固定周长等条件把第二个变量 h（或 y）写成 x 的表达式。
  2. 构造并证明目标式（Show that S = …）：代入表面积 / 体积 / 成本函数，化简成题干给定单变量公式（💡 考场救命诀窍：哪怕第一问没证出来，第二问直接照抄题干给的 S(x) 求导仍可拿满后面 6 分！）。
  3. 令导数为零求正根：设 dSdx = 0，只保留有几何意义的正解 x > 0。
  4. 必须验证性质：算出 d²Sdx² 在该点正负（> 0 为极小，< 0 为极大），最后看清题目问的是“求 x”还是“求最值 S”！

SME 12.1 · 商法则提公因式 + 法线与坐标轴围成面积[8 marks]
A curve has equation y = 2x + 1√x − 1 for x > 1.
(a) Show that dydx = 2x − 52(x − 1)3/2. [4]
(b) Find the equation of the normal to the curve at x = 2, and find the area of the triangle enclosed by this normal and the coordinate axes. [4]
(a) 用商法则化简证明导数表达式；(b) 求 x = 2 处法线方程及其与坐标轴围成的三角形面积。
查看 SaveMyExams 标准采分步骤 (Mark Scheme · 8 Marks)

M1 Let u = 2x + 1 (u' = 2), v = (x − 1)1/2 (v' = 12(x − 1)−1/2).

M1 Quotient rule: dydx = 2(x − 1)1/2 − 12(2x + 1)(x − 1)−1/2x − 1.

M1 Multiply top and bottom by 2(x − 1)1/2: numerator = 4(x − 1) − (2x + 1) = 2x − 5.

A1 dydx = 2x − 52(x − 1)3/2 (shown).

B1 (b) At x = 2: y = 5, mₜ = 4 − 52(1) = −12 ⇒ mₙ = 2 (M1).

A1 Normal: y − 5 = 2(x − 2) ⇒ y = 2x + 1.

A1 Intercepts (0, 1) and (−12, 0) ⇒ Area = 12 × 1 × 12 = 14 units².

SME 12.2 · 圆锥注水关联变化率 (Connected Rates)[7 marks]
An inverted hollow cone of base radius 6 cm and height 12 cm is held vertically with its vertex pointing downwards. Water is poured in at a constant rate of 8π cm³/s. When the depth of water is h cm, find:
(a) the volume V of water in terms of h only, [2]
(b) the rate of increase of the water depth dh/dt when h = 4 cm, [3]
(c) the rate of increase of the circular surface area A of the water at the same instant. [2]
倒立圆锥底半径 6 cm、高 12 cm，以 8π cm³/s 注水。求水深 h = 4 cm 时的水深上升速率及水面圆面积增长速率。
查看评分细则 (Mark Scheme · 7 Marks)

M1 (a) Similar triangles: rh = 612 ⇒ r = h2.

A1 V = 13π r² h = 13π (h2)² h = π h³12.

M1 (b) dVdh = π h²4；at h = 4, dVdh = 4π.

M1 dVdt = dVdh · dhdt ⇒ 8π = 4π · dhdt A1 ⇒ dhdt = 2 cm/s.

M1 (c) A = π r² = π h²4 ⇒ dAdh = π h2；at h = 4, dAdh = 2π.

A1 dAdt = dAdh · dhdt = 2π × 2 = 4π cm²/s.

SME 12.3 · 实际应用极值建模（无盖正方底盒）[8 marks]
An open-top rectangular box has a square base of side x cm and height h cm. Its volume is fixed at 108 cm³.
(a) Show that the total outer surface area S cm² is given by S = x² + 432x. [2]
(b) Find the value of x for which S has a stationary value, and calculate this stationary value of S. [4]
(c) Determine, with justification, whether this stationary value is a maximum or a minimum. [2]
无盖正方底长方体盒子容积固定 108 cm³：(a) 证明表面积公式；(b) 求驻点 x 与表面积；(c) 用二阶导数论证极大/极小性。
查看评分细则 (Mark Scheme · 8 Marks)

M1 (a) V = x² h = 108 ⇒ h = 108x².

A1 Open top = 1 base + 4 sides: S = x² + 4xh = x² + 4x(108x²) = x² + 432x (shown).

M1 (b) dSdx = 2x − 432x⁻² (A1).

M1 Set dSdx = 0 ⇒ 2x³ = 432 ⇒ x³ = 216 ⇒ x = 6 cm.

A1 Minimum surface area S = 6² + 4326 = 36 + 72 = 108 cm².

M1 (c) d²Sdx² = 2 + 864x³. At x = 6: d²Sdx² = 2 + 864216 = 6 > 0.

A1 Since d²Sdx² > 0, it is a minimum.

How must you rewrite 4x³ − √xx² before differentiating?

👆 点击查看参考答案
Split by denominator and convert to negative/fractional indices: 4x − x^(−3/2), then apply Power Rule term-by-term.
DF02 · 12.2Chain Rule
State the Chain Rule and differentiate y = (ax² + b)ⁿ.
默写链式法则并写出复合括号求导公式。
👆 点击查看参考答案
dy/dx = (dy/du)·(du/dx). Derivative: n(ax² + b)ⁿ⁻¹ · (2ax) (never forget the inner derivative 2ax!).
DF03 · 12.3Product Rule
State the Product Rule and the key algebraic step to simplify A(2x+1)¹/² + B(2x+1)⁻¹/².
默写乘积法则及出现分数/负指数和时的标准因式分解动作。
👆 点击查看参考答案
d/dx(uv) = u(dv/dx) + v(du/dx). Always factor out the lowest (most negative) power, i.e., (2x + 1)^(−1/2)!
DF04 · 12.4Quotient Rule
State the Quotient Rule for y = u/v. When should you avoid it and use the Chain Rule instead?
默写商法则公式；分子是常数时改用什么法则更快？
👆 点击查看参考答案
(v·u' − u·v') / v² (v·u' MUST come first!). If numerator u is a constant (e.g. 5/(3x−1)²), rewrite as 5(3x−1)⁻² and use Chain Rule!
DF05 · 12.1–12.4Common Error
Explain why ddx(x² · (x+1)³) ≠ 2x · 3(x+1)².
为什么乘积/商不能简单把导数直接相乘或相除？
👆 点击查看参考答案
Differentiation is NOT multiplicative: (uv)' ≠ u'v' and (u/v)' ≠ u'/v'. You MUST use Product or Quotient Rule!
DF06 · 12.5Tangent & Normal
How are tangent gradient mₜ and normal gradient mₙ related? What if mₜ = 0?
切线斜率与法线斜率的关系？水平切线对应的法线方程是什么？
👆 点击查看参考答案
mₙ = −1 / mₜ (substitute numerical x₁ into f'(x) FIRST!). If mₜ = 0 (horizontal tangent y = y₁), the normal is vertical: x = x₁.
DF07 · 12.6Small Increments
Write the linear approximation formula for a small change δx and explain what negative δx means.
默写微小增量公式；若题目说变量“减少 (decreases)”怎么处理符号？
👆 点击查看参考答案
δy ≈ (dy/dx) · δx. When x decreases, δx < 0; similarly a negative δy indicates that y decreases.
DF08 · 12.6% Change
How do you find approximate percentage change in y if x changes by p% without knowing x?
题目只给 x 的百分比变化而没给具体数值，如何算出 y 的百分比变化？
👆 点击查看参考答案
Set δx = (p/100)x, compute δy ≈ (dy/dx)(p/100)x, and divide by y to find (δy / y) × 100% (powers of x cancel!).
DF09 · 12.7Connected Rates
State the chain rule linking dV/dt and dh/dt, and the sign rule for "leaking/shrinking".
默写关联变化率公式及“漏水/缩小”时的正负号约定。
👆 点击查看参考答案
dV/dt = (dV/dh) · (dh/dt). Always attach a negative sign (−) to any rate described as decreasing/leaking/evaporating!
DF10 · 12.7Cone Reduction
In an inverted cone problem, why can't you differentiate V = 13πr²h with respect to h directly?
为什么圆锥体积公式不能把 r 当常数直接对 h 求导？
👆 点击查看参考答案
Because r varies with h! Use similar triangles r/h = R/H to eliminate r (or h) BEFORE differentiating.
DF11 · 12.8Increasing / Decreasing
State the derivative conditions for a function f(x) to be increasing or decreasing on an interval.
如何根据导函数符号确定原函数的单调递增与递减区间？
👆 点击查看参考答案
Increasing when f'(x) > 0; Decreasing when f'(x) < 0 (solve quadratic/cubic inequality for x).
DF12 · 12.92nd Derivative Test
How do you classify a stationary point (dy/dx = 0) using d²y/dx²?
已知驻点处 dy/dx = 0，如何用二阶导数判定极大、极小？
👆 点击查看参考答案
d²y/dx² < 0 ⇒ Maximum (concave down ∩); d²y/dx² > 0 ⇒ Minimum (concave up U).
DF13 · 12.9Inconclusive d²y/dx²
What MUST you do if d²y/dx² = 0 at a stationary point x = a?
当驻点处 d²y/dx² = 0 时为什么不能下结论？应该改用什么方法？
👆 点击查看参考答案
d²y/dx² = 0 is inconclusive! Perform the First-Derivative Sign Test (check signs of dy/dx at x = a⁻ and a⁺): +/0/+ or −/0/− means Point of Inflexion.
DF14 · 12.10Optimization Steps
State the 4 mandatory steps of a 0606 practical max/min word problem.
实际应用极值建模题的四个标准拿分动作是什么？
👆 点击查看参考答案
(1) Eliminate 2nd variable via constraint; (2) Show S(x); (3) Solve dS/dx = 0 (keep realistic x > 0); (4) Verify max/min via d²S/dx²!
DF15 · 12.10Exam Rescue
In an optimization question, if you get stuck on part (a) "Show that S = x² + 432/x", can you still score full marks on parts (b)–(c)?
优化大题若第 (a) 问“证明表面积公式”卡住了，第 (b)(c) 问还能拿分吗？
👆 点击查看参考答案
YES! Because (a) is a "Show that" formula, immediately use the printed formula in (b) and (c) to earn all remaining differentiation and verification marks!
