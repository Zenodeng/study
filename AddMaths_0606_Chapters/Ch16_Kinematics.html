16.1 微分在运动学中的应用：s → v → a 与运动图像

Applications of Differentiation in Kinematics: s, v = ds/dt, a = dv/dt & s–t / v–t Graphs
变加速运动禁用 SUVAT 公式！ 0606 高频压轴：英文关键词秒译

16.1.1 位移 s、速度 v、加速度 a 的微分链条与考题英文翻译表

当质点沿直线做变加速运动（Variable acceleration）时，物理中的等加速 SUVAT 公式（v = u + at 等）全部失效，必须使用微积分定义处理时间 t（t ≥ 0）的函数关系：

位移 Displacement s(t)  ── 求导 ──▶  速度 Velocity v = dsdt  ── 求导 ──▶  加速度 Acceleration a = dvdt = d²sdt²
三大概念严防混淆：
• 位移 (Displacement, s)：带正负方向，表示“当前相对于固定原点 O 的有向位置”。
• 速度 (Velocity, v) vs 速率 (Speed, |v|)：v > 0 向正方向走，v < 0 向反方向折返；速率为非负值 |v|。
• 最大/最小速度：令加速度 a = dvdt = 0（极值条件，绝不是令 v = 0！）。
考卷英文原句 (Exam Phrasing) 必须列出的数学方程 Paper 1/2 考场避坑点
“Starts from a fixed point O” 当 t = 0 时，s = 0 用于积分还原位移时确定常数 + c（注意有时说 “starts 5 m from O” 则 s = 5）。
“Initial velocity / initially” 代入 t = 0 求 v(0) 或 a(0) 指数/三角题代入 t = 0 时谨记 e⁰ = 1、cos 0 = 1！
“Instantaneously at rest / changes direction” 解方程 v = 0 必须舍去负时间 t < 0！解出所有 t > 0 的折返时刻。
“Returns to O / passes through O again” 解方程 s = 0（取 t > 0） 注意区分“回到原点 s = 0”与“停在原地 v = 0”，千万别解错函数！
“Maximum / minimum velocity” 解 a = dv/dt = 0 并查 d²v/dt² 若题目问最大/最小 Speed（速率），还需比较端点及 |v| 的绝对值！
“Deceleration / retardation” 负加速度值或与速度反向 题目问 “Find the deceleration” 时，若算出 a = −6 m s⁻²，应答 deceleration = 6 m s⁻²。

📘 例题 16.1 · 三次位移函数的完整微分运动分析（Paper 1）

质点从原点 O 出发沿直线运动，t 秒后的位移为 s = t³ − 6t² + 9t（t ≥ 0）。求：
(a) 初速度（Initial velocity）；
(b) 质点处于瞬时静止（Instantaneous rest）的时刻；
(c) t = 3 时的加速度；
(d) 质点的最小速度及其发生时刻。

解：
(a) v = dsdt = 3t² − 12t + 9。令 t = 0 ⇒ 初速度 v(0) = 9 m s⁻¹。
(b) 令 v = 0：3(t² − 4t + 3) = 3(t − 1)(t − 3) = 0 ⇒ t = 1 s 与 t = 3 s。
(c) a = dvdt = 6t − 12。当 t = 3 时，a = 6(3) − 12 = 6 m s⁻²。
(d) 速度极值处 a = dvdt = 0 ⇒ 6t − 12 = 0 ⇒ t = 2 s。因 d²vdt² = 6 > 0，故在 t = 2 s 取最小速度 vmin = 3(4) − 24 + 9 = −3 m s⁻¹。

16.2 积分在运动学中的应用：求 +c、位移 vs 总路程与超越函数

Applications of Integration: Boundary Conditions (+c), Displacement vs Total Distance & Exp/Trig Velocity
⚠️ 致命区别：净位移 Δs vs 总路程 Distance 0606 压轴：含 e^(kt) 与 sin/cos 的运动学

16.2.1 积分反推链与“折返总路程”三步拆解法

逆向过程是先由加速度积分求速度 v = ∫ a dt（用已知速度条件定 + c₁），再由速度积分求位移 s = ∫ v dt（用已知位置条件定 + c₂）。在求总路程（Total distance travelled）时，绝不能直接算出终末位移 s(T) − s(0) 了事！

净位移 Δs = s(T) − s(0) = ∫₀T v(t) dt   vs   总路程 Total Distance = ∫₀T |v(t)| dt
求 [0, T] 内总路程标准三步法（绝不丢分）：
Step 1：解方程 v(t) = 0，找出严格落在区间 (0, T) 内的所有瞬时静止/折返时刻 t₁ < t₂ < …（区间外的根直接忽略！）。
Step 2：分别算出起始点、所有折返点与终点的位移：s(0), s(t₁), s(t₂), …, s(T)。
Step 3：分段取绝对值相加：Total Distance = |s(t₁) − s(0)| + |s(t₂) − s(t₁)| + … + |s(T) − s(tk)|！

📘 例题 16.2a · 二次速度函数两次折返的总路程（Paper 1）

质点沿直线运动，速度 v = t² − 4t + 3 m s⁻¹（t ≥ 0），且 t = 0 时过原点 O（s = 0）。求 0 ≤ t ≤ 4 内质点的：
(a) t = 4 时的位移（Displacement）；  (b) 行驶的总路程（Total distance travelled）。

解：
① 积分求位移：s = ∫ (t² − 4t + 3) dt = 13t³ − 2t² + 3t + c。因 t = 0 时 s = 0，故 c = 0。
(a) 代入 t = 4：s(4) = 643 − 32 + 12 = 643 − 20 = 43 m。
(b) 先找 (0, 4) 内瞬时静止点：v = (t − 1)(t − 3) = 0 ⇒ t = 1, t = 3（均在区间内！）。
计算各关键时刻位移：
• s(0) = 0；
• s(1) = 13 − 2 + 3 = 43；
• s(3) = 9 − 18 + 9 = 0；
• s(4) = 43。
分段取绝对值相加：Total Distance = |43 − 0| + |0 − 43| + |43 − 0| = 4 m（是净位移的 3 倍！）。

16.2.2 含指数函数 e^(kt) 与三角函数 sin/cos 的运动学

📘 例题 16.2b · 指数衰减加速度与极限速度 + 三角振荡总路程（Paper 1）

【指数型】 质点从原点静止出发（t = 0 时 s = 0, v = 0），加速度 a = 6e−0.5t m s⁻²。求 v(t) 与 s(t) 表达式。
解：
v = ∫ 6e−0.5t dt = 6−0.5 e−0.5t + c₁ = −12e−0.5t + c₁。
代入 t = 0, v = 0（注意 e⁰ = 1）：0 = −12(1) + c₁ ⇒ c₁ = 12，故 v(t) = 12(1 − e−0.5t)（当 t → ∞ 时趋于极限速度 12 m s⁻¹）。
再积分求位移：s = ∫ (12 − 12e−0.5t) dt = 12t + 24e−0.5t + c₂。
代入 t = 0, s = 0：0 = 0 + 24(1) + c₂ ⇒ c₂ = −24，故 s(t) = 12t + 24e−0.5t − 24。

【三角型】 质点速度 v = 4 cos(2t) m s⁻¹，初始位置 s = 1 m（t = 0）。求在 0 ≤ t ≤ π2 内行驶的总路程。
解：
s = ∫ 4 cos(2t) dt = 2 sin(2t) + c。代入 t = 0, s = 1：1 = 2(0) + c ⇒ c = 1，故 s(t) = 2 sin(2t) + 1。
在 (0, π2) 内令 v = 0：cos(2t) = 0 ⇒ 2t = π2 ⇒ t = π4。
计算关键位移：s(0) = 1； s(π4) = 2 sin(π2) + 1 = 3； s(π2) = 2 sin π + 1 = 1。
总路程 = |3 − 1| + |1 − 3| = 2 + 2 = 4 m（虽然净位移为 0 m！）。

SME 16.1 · Paper 1 多项式速度双折返点总路程与极值速度[7 marks]
A particle travels in a straight line such that t seconds after passing through a fixed point O, its velocity v m s⁻¹ is given by v = 3t² − 18t + 24.
(a) Find the times when the particle is instantaneously at rest and the acceleration at each of these times. [3]
(b) Find the minimum velocity of the particle. [2]
(c) Calculate the total distance travelled by the particle in the first 5 seconds (0 ≤ t ≤ 5). [2]
无计算器经典大题：求两次瞬时静止时刻及其加速度、最小速度，以及前 5 秒跨双折返点的总路程。
查看官方评分标准 (Mark Scheme · 7 Marks)

M1 3t² − 18t + 24 = 0 ⇒ 3(t − 2)(t − 4) = 0 ⇒ t = 2 s, t = 4 s (A1).

A1 a = dvdt = 6t − 18: at t = 2, a = −6 m s⁻²; at t = 4, a = +6 m s⁻².

M1 Minimum velocity when a = 0 ⇒ 6t − 18 = 0 ⇒ t = 3 (d²v/dt² = 6 > 0).

A1 vmin = 3(9) − 18(3) + 24 = −3 m s⁻¹.

M1 s = ∫ (3t² − 18t + 24) dt = t³ − 9t² + 24t (s(0) = 0 ⇒ c = 0).
Values: s(0) = 0, s(2) = 8 − 36 + 48 = 20, s(4) = 64 − 144 + 96 = 16, s(5) = 125 − 225 + 120 = 20.

A1 Total distance = |20 − 0| + |16 − 20| + |20 − 16| = 20 + 4 + 4 = 28 m (note: net displacement is only 20 m!).

SME 16.2 · Paper 1/2 指数速度折返与精确总路程[8 marks]
A particle leaves a fixed point O at t = 0 and moves in a straight line with velocity v = 6e−0.5t − 2 m s⁻¹.
(a) Find the exact time t at which the particle is instantaneously at rest, and show that its acceleration at this instant is −1 m s⁻². [4]
(b) Find an expression for the displacement s in terms of t. [2]
(c) Find the exact total distance travelled in the interval 0 ≤ t ≤ 4, in the form p − q ln 3 + r e⁻². [2]
含自然指数的速度折返大题：求精确静止时刻 t = 2 ln 3、加速度与折返后总路程的精确表达式。
查看官方评分标准 (Mark Scheme · 8 Marks)

M1 6e−0.5t − 2 = 0 ⇒ e−0.5t = 13 ⇒ −0.5t = −ln 3 ⇒ t = 2 ln 3 (A1, ≈ 2.20 s ∈ (0, 4)).

M1 a = dvdt = −3e−0.5t. At rest (e−0.5t = 13): a = −3(13) = −1 m s⁻² (A1).

M1 s = ∫ (6e−0.5t − 2) dt = −12e−0.5t − 2t + c. Since s(0) = 0: 0 = −12(1) + c ⇒ c = 12.

A1 s(t) = 12 − 12e−0.5t − 2t.

M1 At t = 2 ln 3: s(2 ln 3) = 12 − 12(13) − 4 ln 3 = 8 − 4 ln 3 (> 0). At t = 4: s(4) = 4 − 12e⁻².

A1 Total distance = |s(2 ln 3) − 0| + |s(4) − s(2 ln 3)| = (8 − 4 ln 3) + [(8 − 4 ln 3) − (4 − 12e⁻²)] = 12 − 8 ln 3 + 12e⁻² (≈ 4.83 m).

SME 16.3 · Paper 1 双质点直线追及碰撞与等速时刻[7 marks]
Two particles P and Q move along the same straight line.
At time t seconds (t ≥ 0), the displacement of P from O is sP = 3t² − 4t metres.
Particle Q is at 8 m from O when t = 0, and moves with velocity vQ = 2t + 2 m s⁻¹.
(a) Find an expression for the displacement sQ from O at time t. [2]
(b) Find the value of t when P and Q have the same velocity. [2]
(c) Find the time t and the displacement from O when P and Q collide. [3]
一维运动学双质点联动：一个给位移求导、一个给速度积分（留意初始位置 +8），分别求解等速与相遇碰撞。
查看官方评分标准 (Mark Scheme · 7 Marks)

M1 sQ = ∫ (2t + 2) dt = t² + 2t + c. At t = 0, sQ = 8 ⇒ c = 8.

A1 sQ = t² + 2t + 8.

M1 vP = dsPdt = 6t − 4. Set vP = vQ ⇒ 6t − 4 = 2t + 2 ⇒ 4t = 6.

A1 t = 1.5 s (32 s).

M1 Collide when sP = sQ ⇒ 3t² − 4t = t² + 2t + 8 ⇒ 2t² − 6t − 8 = 0 ⇒ (t − 4)(t + 1) = 0.

A1 Since t ≥ 0, t = 4 s.

A1 Common displacement s = 3(16) − 16 = 32 m (check: 4² + 2(4) + 8 = 32 ✓).

SME 16.4 · Paper 1 三角速度函数与弧度制精确总路程[6 marks]
A particle starts from O at t = 0 and moves along a straight line with velocity v = 4 sin t − 2 m s⁻¹, where t is in seconds (0 ≤ t ≤ π2).
(a) Find the exact time when the particle is instantaneously at rest and its acceleration at this instant. [3]
(b) Find the exact total distance travelled by the particle for 0 ≤ t ≤ π2. [3]
无计算器三角运动学：利用弧度制求静止时刻、根式加速度，并分段求区间 [0, π/2] 的精确总路程。
查看官方评分标准 (Mark Scheme · 6 Marks)

M1 4 sin t − 2 = 0 ⇒ sin t = 12 ⇒ t = π6 s (A1, in [0, π/2]).

A1 a = dvdt = 4 cos t; at t = π6, a = 4(√32) = 2√3 m s⁻².

M1 s = ∫ (4 sin t − 2) dt = −4 cos t − 2t + c. Since s(0) = 0: 0 = −4(1) + c ⇒ c = 4, so s(t) = 4 − 4 cos t − 2t.

M1 Key displacements:
s(0) = 0；  s(π6) = 4 − 2√3 − π3 (< 0)；  s(π2) = 4 − π (> 0).

A1 Total distance = |s(π6) − 0| + |s(π2) − s(π6)| = (2√3 + π3 − 4) + (2√3 − 2π3) = 4√3 − 4 − π3 m.

K01 · Unit 16.1SUVAT Warning
When are constant-acceleration SUVAT equations INVALID, forcing you to use calculus?
何时绝对不能使用物理 SUVAT 匀加速公式，而必须使用微积分？
👆 点击查看参考答案
Whenever acceleration a varies with time t (i.e. a is non-constant). Use v = ds/dt, a = dv/dt and integration!
K02 · Unit 16.1At Rest vs Origin
Contrast the equations solved for “instantaneously at rest” vs “returns to O”.
对比“瞬时静止”与“返回原点 O”分别对应解哪两个方程？
👆 点击查看参考答案
Instantaneous rest / reverses direction: solve v = 0 (t > 0). Returns to O: solve s = 0 (t > 0).
K03 · Unit 16.1Max/Min Velocity
What equation do you solve to find the time of maximum or minimum velocity?
求质点达到最大或最小速度的时刻应令什么等于 0？
👆 点击查看参考答案
Solve a = dv/dt = 0 (and verify nature via sign of d²v/dt², never set v = 0!).
K04 · Unit 16.1Deceleration
If v > 0 and acceleration is calculated as a = −6 m s⁻², how should you state the deceleration?
若正向运动中算出 a = −6 m s⁻²，回答“减速度 (Deceleration)”应写正数还是负数？
👆 点击查看参考答案
State deceleration = 6 m s⁻² (positive value, since “deceleration” already carries the negative meaning).
K05 · Unit 16.1s-t Graph
What physical quantities correspond to the gradient and horizontal tangents of an s–t graph?
位移–时间图像（s–t）的切线斜率和水平切线分别表示什么物理量？
👆 点击查看参考答案
Gradient = instantaneous velocity v; horizontal tangents (ds/dt = 0) represent instantaneous rest / turning points.
K06 · Unit 16.1v-t Graph
What do the gradient, t-intercepts, and areas of a v–t graph represent?
速度–时间图像（v–t）的斜率、横轴交点与曲线下面积各代表什么？
👆 点击查看参考答案
Gradient = acceleration a; t-intercept = instantaneous rest (v = 0); signed area = displacement, total unsigned area = distance.
K07 · Unit 16.1Speed vs Velocity
Suppose v ranges from −7 m s⁻¹ to +4 m s⁻¹. What is the maximum speed?
若速度 v 范围在 −7 到 +4 m s⁻¹ 之间，最大速率 (Speed) 是多少？
👆 点击查看参考答案
7 m s⁻¹! Speed is |v|, so check the largest magnitude including negative velocities!
K08 · Unit 16.1Collision 1D
What condition proves that two particles P and Q on the same line collide?
同一条直线上的两个质点 P 与 Q 碰撞时，必须满足什么条件？
👆 点击查看参考答案
Equate their displacements from the SAME origin at time t: sP(t) = sQ(t) with t ≥ 0.
K09 · Unit 16.2Reverse Chain
Write the integration formulas linking a(t), v(t) and s(t).
写出由加速度积分求速度、由速度积分求位移的表达式及各自常数意义。
👆 点击查看参考答案
v = ∫ a dt + c₁ (find c₁ from velocity at a given t) and s = ∫ v dt + c₂ (find c₂ from initial/known position).
K10 · Unit 16.2Non-Zero c
If v = 6e−0.5t and s = 0 at t = 0, why is c ≠ 0 in s = −12e−0.5t + c?
当 s(0) = 0 时，为什么积分后的常数 c 往往不等于 0？
👆 点击查看参考答案
Because e⁰ = 1 (and cos 0 = 1)! Setting 0 = −12(1) + c gives c = +12. Never assume t = 0 makes terms zero!
K11 · Unit 16.2Initial Position
What does “starts 5 m to the right of O” mean for the boundary condition on s(t)?
题干说“从原点 O 右侧 5 m 处出发”，如何写出位移边界条件？
👆 点击查看参考答案
At t = 0, s = +5 (not 0!), used to find + c in s(t).
K12 · Unit 16.2Definite disp.
What does the definite integral ∫t₁t₂ v(t) dt compute directly?
定积分 ∫t₁t₂ v(t) dt 直接算出的是位移还是总路程？
👆 点击查看参考答案
It computes change in displacement Δs = s(t₂) − s(t₁), which equals total distance ONLY if v(t) does not change sign on (t₁, t₂)!
K13 · Unit 16.2Total Distance
Write the 3-step algorithm for finding total distance travelled over 0 ≤ t ≤ T.
默写计算 0 ≤ t ≤ T 区间总路程（Total Distance）的三步标准流程。
👆 点击查看参考答案
① Solve v(t) = 0 for roots t₁, t₂ ∈ (0, T); ② Find s(0), s(t₁), s(t₂), s(T); ③ Sum |s(t₁)−s(0)| + |s(t₂)−s(t₁)| + |s(T)−s(t₂)|.
K14 · Unit 16.2Terminal Velocity
For v = 12(1 − e−0.5t), find the limiting (terminal) velocity as t → ∞.
对于指数趋近模型 v = 12(1 − e−0.5t)，当 t → ∞ 时极限速度是多少？
👆 点击查看参考答案
As t → ∞, e−0.5t → 0, so v → 12 m s⁻¹ (approached asymptotically, never exceeded).
K15 · Unit 16.2Trig Kinematics
For v = 4 cos(2t), find the first positive time at rest and explain the angle unit rule.
已知 v = 4 cos(2t)，求首次静止的精确时间及计算器模式要求。
👆 点击查看参考答案
cos(2t) = 0 ⇒ 2t = π/2 ⇒ t = π/4 s. Calculus requires radians mode throughout!
K16 · Unit 16.2Out-of-Range Roots
If v = 0 gives t = 1 and t = 5, how do you split total distance on 0 ≤ t ≤ 3?
若 v = 0 的根是 t = 1 和 t = 5，求 0 ≤ t ≤ 3 总路程时如何分段？
👆 点击查看参考答案
Only t = 1 lies inside (0, 3) (ignore t = 5!), so split only at t = 1: |s(1) − s(0)| + |s(3) − s(1)|.
