14.1 指数函数求导 d/dx(e^(ax + b))

Derivatives of Exponential Functions: eˣ, e^(ax+b) & Chain Rule e^(f(x))
Paper 1：精确保留 e 与 ln 表达式 0606 不提供微分公式表

14.1.1 自然指数 eˣ 的核心求导公式

自然底数 e ≈ 2.71828 是微积分中最特别的函数底数：y = eˣ 在任意点处的切线斜率都恰好等于它自身的函数值。结合第 12 章链式法则（Chain Rule），得到全部指数求导规则：

ddx(eˣ) = eˣ   |   ddx(eax + b) = a eax + b   |   ddx(ef(x)) = f'(x) · ef(x)
考场核心性质：对一切实数 x，恒有 ef(x) > 0（永远严格大于 0，绝不等于 0！）。因此解驻点方程 eax(px + q) = 0 时，可直接由 eax ≠ 0 推出 px + q = 0。
⚠️ 指数求导两大致命误区

① 严禁套用幂函数法则：把 eˣ 求导写成 x ex−1 是 0 分低级错误！幂函数是“底数变、指数定”（xⁿ），指数函数是“底数定、指数变”（eˣ），指数不会减 1！
② 括号与分式先展开化简再求导：例如 y = (e2x − 3)² / eˣ，不要硬上商法则！先用指数律拆成 (e4x − 6e2x + 9) / eˣ = e3x − 6eˣ + 9e−x，逐项秒出导数 3e3x − 6eˣ − 9e−x！

📘 例题 14.1 · 指数函数求导与驻点分类（Paper 1）

已知曲线 y = e2x − 4eˣ + 3，求驻点（Stationary point）的精确坐标，并用二阶导数判断其极大/极小性质。

解：
① 一阶导数：dydx = 2e2x − 4eˣ = 2eˣ(eˣ − 2)。
② 令 dydx = 0：因 eˣ > 0 无解，故必有 eˣ = 2 ⇒ x = ln 2。
③ 代回原方程（用 e2 ln 2 = (eln 2)² = 4）：y = 4 − 4(2) + 3 = −1 ⇒ 驻点为 (ln 2, −1)。
④ 二阶导数：d²ydx² = 4e2x − 4eˣ。代入 eˣ = 2 得 4(4) − 4(2) = 8 > 0 ⇒ 该点为 局部极小值点（Minimum point）。

14.2 对数函数求导与“先拆后导”黄金技巧

Derivatives of Logarithmic Functions: ln(ax+b) & Log-Law Pre-Expansion
Paper 1 高频：对数律拆项秒杀 隐含换底：logₐ x 转化

14.2.1 ln(ax + b) 导数与“系数抵消”奇观

ddx(ln x) = 1x   |   ddx[ln(ax + b)] = aax + b   |   ddx[ln f(x)] = f'(x)f(x)
为什么 d/dx [ln(5x)] 仍然等于 1/x？
因为 ln(5x) = ln 5 + ln x，常数 ln 5 的导数为 0；或用链式法则得 55x = 1x（系数 5 自动约掉！）。同样，ddx(ln(k xⁿ)) = nx！
⚡ 考场神技：求导之前，先用对数律拆开！（Pre-expand with Log Laws FIRST）

遇到 y = ln[ (A · Bⁿ) / √C ] 时，千万不要直接往 f'(x)/f(x) 里硬套乘积商法则！先用第 5 章对数律拆成线性加减：
ln(AB) = ln A + ln B， ln(A/B) = ln A − ln B， ln(Aⁿ) = n ln A， ln √C = ½ ln C。
拆分后每一项只是简单的 k ln(ax + b)，10 秒写出答案且几乎不可能算错！若题目给非自然对数 y = logₐ x（如 lg x），先换底为 ln xln a，得 dydx = 1x ln a。

📘 例题 14.2 · 对数律先拆后导（Paper 1）

已知 y = ln( (2x + 1)³x + 3 )（x > −½），求 x = 1 处的 dydx 精确值。

解：
① 先用对数律拆开：y = 3 ln(2x + 1) − ln(x + 3)。
② 逐项求导：dydx = 3 · 22x + 1 − 1x + 3 = 62x + 1 − 1x + 3。
③ 代入 x = 1：63 − 14 = 2 − 14 = 74。

14.3 三角函数求导与弧度制铁律

Derivatives of sin(ax+b), cos(ax+b), tan(ax+b) & Powers of Trig Functions
⚠️ 角度必须为弧度 (Radians) 三角幂函数链式展开

14.3.1 三大基本三角导数表与三角幂函数链式法

ddx[sin(ax + b)] = a cos(ax + b)   |   ddx[cos(ax + b)] = −a sin(ax + b)   |   ddx[tan(ax + b)] = a sec²(ax + b)
三角函数求导四大铁律：
1. 弧度铁律（Radians Only!）：以上公式仅当自变量 x 为弧度（rad）时成立！计算器切勿停留在 DEG 模式！
2. 正负号记忆法：“c”开头的函数（cos、cot、cosec）求导结果前面全带负号 (−)！
3. 三角函数的幂：把 sinⁿ(ax + b) 先改写成括号 [sin(ax + b)]ⁿ 再用三层链式法则：先幂、再三角、再内层一次式！例如 d/dx [cos³(2x)] = 3 cos²(2x) · (−2 sin 2x) = −6 cos²(2x) sin(2x)。
4. 互余恒等：记住 sec² θ = 1 / cos² θ = 1 + tan² θ，求具体数值时把 sec² θ 算成 1 / cos² θ 最不容易按错或心算错！

📘 例题 14.3 · 三角幂函数求导与 tan 导数精确值（Paper 1）

求下列导数：(a) y = sin⁴(3x)；  (b) y = 2 tan(3x − π4) 在 x = π6 处的导数值。

解：
(a) 改写为 y = [sin(3x)]⁴，按三层链式法则：
dydx = 4 [sin(3x)]³ · [3 cos(3x)] = 12 sin³(3x) cos(3x)。
(b) dydx = 2 · 3 sec²(3x − π4) = 6 sec²(3x − π4)。
代入 x = π6：括号内角度 = π2 − π4 = π4。因 cos(π4) = 1√2，故 sec²(π4) = 2。
所以 dydx = 6 × 2 = 12。

14.4 乘商法则综合、切法线、驻点与关联变化率

Further Applications: Product/Quotient Rules, Tangents, Normals, Stationary Points & Connected Rates
Paper 1：e / π / ln 精确方程 Paper 2：复合极值与变化率建模

14.4.1 Product & Quotient Rules 与超越函数组合

将第 12 章的乘积法则与商法则直接应用到 eˣ, ln x, sin x, cos x, tan x 的混合表达式中，是 0606 试卷中后部 6–8 分大题的标准配置：

  • Product Rule（乘积法则）：ddx(uv) = u dvdx + v dudx
  • Quotient Rule（商法则）：ddx(uv) = v (du/dx) − u (dv/dx)v²（注意分子减号顺序，切忌写反！）
  • 化简与求解驻点铁律：求出导数后先提取公因式（如 eax 或 cos x），千万不要随意两边同除以可能等于 0 的三角函数（例如同除以 cos x 会直接丢掉 cos x = 0 的驻点！）。
📘 例题 14.4a · 乘积法则求含 e 与 ln 的精确切线与法线方程（Paper 1）

求曲线 y = x² ln x（x > 0）在 x = e 处的切线（Tangent）与法线（Normal）精确方程。

解：
① 当 x = e 时，y = e² · ln e = e²，切点为 (e, e²)。
② 乘积法则（令 u = x², v = ln x）：
dydx = x² · 1x + (ln x) · 2x = x + 2x ln x = x(1 + 2 ln x)。
③ 在 x = e 处，切线斜率 mT = e(1 + 2·1) = 3e；法线斜率 mN = −13e。
④ 切线：y − e² = 3e(x − e) ⇒ y = 3ex − 2e²。
⑤ 法线：y − e² = −13e(x − e) ⇒ 3ey + x = 3e³ + e。

📘 例题 14.4b · 衰减振荡函数 y = e⁻ˣ sin x 的驻点与二阶导分类

求曲线 y = e−x sin x 在区间 0 ≤ x ≤ π 内的驻点精确坐标，并判定其极值类型。

解：
① 乘积法则：dydx = e−x cos x + sin x (−e−x) = e−x(cos x − sin x)。
② 令 dydx = 0：因 e−x > 0，故 cos x = sin x ⇒ tan x = 1（可除 cos x，因当 cos x = 0 时 sin x = ±1 ≠ 0）。在 [0, π] 内唯一解为 x = π4。
③ 驻点纵坐标：y = e−π/4 sin(π4) = 1√2 e−π/4。
④ 二阶导数：d²ydx² = e−x(−sin x − cos x) − e−x(cos x − sin x) = −2 e−x cos x。
在 x = π4 处，d²ydx² = −√2 e−π/4 < 0 ⇒ 该驻点为 局部极大值点（Maximum point）。

把 Ch 12 的链式关联变化率 dydt = dydx × dxdt 及近似增量 δy ≈ (dydx) δx 应用于指数、对数和三角模型：

📘 例题 14.4c · 三角函数关联变化率（Paper 1）

变量 y 与 x 满足 y = 4 tan(2x)（x 为弧度）。已知 x 以恒定速率 0.05 rad s⁻¹ 增大，求当 x = π6 时 y 的变化率。

解：
① dydx = 4 · 2 sec²(2x) = 8 sec²(2x)。
② 当 x = π6 时，2x = π3，因 cos(π3) = 12，故 sec²(π3) = 4，所以 dydx = 8 × 4 = 32。
③ dydt = dydx × dxdt = 32 × 0.05 = 1.6 units s⁻¹。

SME 14.1 · Paper 1 商法则驻点与二阶导分类 y = (ln x)/x[6 marks]
A curve has equation y = ln xx for x > 0.
(a) Find dydx and the exact coordinates of the stationary point. [4]
(b) Use d²ydx² to determine the nature of this stationary point. [2]
0606 经典题：用商法则求 y = (ln x)/x 的精确驻点并用二阶导判定极值类型。
查看官方评分标准 (Mark Scheme · 6 Marks)

M1 Quotient rule: dydx = x · (1x) − (ln x) · 1x² = 1 − ln xx² (A1).

M1 Set dydx = 0 ⇒ 1 − ln x = 0 ⇒ ln x = 1 ⇒ x = e.

A1 When x = e, y = 1e ⇒ Stationary point is (e, 1e).

M1 d²ydx² = x²(−1x) − (1 − ln x)(2x)x⁴ = −3 + 2 ln xx³.

A1 At x = e: d²ydx² = −3 + 2e³ = −1e³ < 0 ⇒ Maximum point.

SME 14.2 · Paper 1 指数切法线与坐标轴围成面积[7 marks]
The curve y = e2x − 4x meets the y-axis at P.
(a) Find the equations of the tangent and the normal to the curve at P. [4]
(b) The tangent and normal cut the x-axis at Q and R respectively. Find the exact area of ΔPQR. [3]
无计算器：求指数曲线在 y 轴截距处的切线与法线方程，并求两者与 x 轴围成直角三角形的面积。
查看官方评分标准 (Mark Scheme · 7 Marks)

B1 At x = 0, y = e⁰ − 0 = 1 ⇒ P(0, 1).

M1 dydx = 2e2x − 4. At x = 0, mT = 2(1) − 4 = −2; hence mN = 12 (A1).

A1 Tangent: y = −2x + 1;  Normal: y = ½x + 1.

M1 Set y = 0: Tangent cuts x-axis at Q(12, 0); Normal cuts x-axis at R(−2, 0).

M1 Base QR = 12 − (−2) = 52, height = yP = 1.

A1 Area ΔPQR = 12 × 52 × 1 = 54 (or 1.25).

SME 14.3 · Paper 1 三角驻点与倍角因式分解[7 marks]
Find the exact x-coordinates of all stationary points of y = 2 sin x + cos 2x for 0 ≤ x ≤ π, and classify each point.
无计算器：求 y = 2 sin x + cos 2x 在 [0, π] 上的所有驻点（切勿因盲目约掉 cos x 而漏根！）并判断极值类型。
查看官方评分标准 (Mark Scheme · 7 Marks)

M1 dydx = 2 cos x − 2 sin 2x (A1).

M1 Use sin 2x = 2 sin x cos x: 2 cos x − 4 sin x cos x = 0 ⇒ 2 cos x(1 − 2 sin x) = 0.

A1 Either cos x = 0 ⇒ x = π2, OR sin x = 12 ⇒ x = π6, 5π6 (A1).

M1 d²ydx² = −2 sin x − 4 cos 2x.

A1 Evaluate at each root:
• x = π6: −2(½) − 4(½) = −3 < 0 ⇒ Maximum;
• x = π2: −2(1) − 4(−1) = +2 > 0 ⇒ Minimum;
• x = 5π6: −2(½) − 4(½) = −3 < 0 ⇒ Maximum.

SME 14.4 · Paper 2 对数律 + 乘积法则与关联变化率[6 marks]
A curve has equation y = e2x ln(3x − 2) (x > 23).
(a) Find dydx. [3]
(b) Given that x is increasing at 0.2 units s⁻¹ when x = 1, find the exact rate of change of y at this instant, and estimate the approximate change in y as x increases from 1 to 1.01. [3]
结合乘积法则、链式求导、关联变化率及小增量近似的综合应用题。
查看官方评分标准 (Mark Scheme · 6 Marks)

M1 Product rule: dydx = e2x · 33x − 2 + ln(3x − 2) · 2e2x (A1 A1).

M1 At x = 1: 3x − 2 = 1, ln 1 = 0 ⇒ dydx = e²(3) + 0 = 3e².

A1 dydt = 3e² × 0.2 = 0.6 e² units s⁻¹.

B1 Small change: δy ≈ 3e² × 0.01 = 0.03 e² (≈ 0.222 to 3 s.f.).

Differentiate y = tan²(4x) using the 3-layer chain rule.

推导 sec x = (cos x)⁻¹ 与 cot x = cos x / sin x 的导数。

Apply the product rule to d/dx(x e−3x) and factorise cleanly.
对乘积 x e−3x 求导并提取公因式。

D14 · Unit 14.4Quotient Trap
State the Quotient Rule for u/v and avoid dividing out valid roots when solving dy/dx = 0.
写出商法则公式，并说明解三角导数为 0 时为何严禁随意两边同除 cos x。
👆 点击查看参考答案
(v u' − u v') / v². Always factorise rather than divide by trig terms (dividing by cos x loses roots where cos x = 0!).

mN = −1 / (3e) (negative reciprocal mT mN = −1, keep e exact!).

Write the connected-rates chain and the small-increment formula.
