1.1 映射与对应关系 (Mappings)

Input-Output Mappings, Four Mapping Types & Vertical Line Test
Paper 1 基础概念 判定是否为 Function

1.1.1 映射的四类基本关系与“函数门槛”

映射 (Mapping) 是指把输入集合（原像集 Object / Input set）中的每个元素 x，按照某种规则对应到输出集合（像集 Image / Output set）中的元素 y。根据输入与输出的数量配对方式，映射可分为 4 类：

映射类型 (Mapping Type) 对应特征 是否为函数 (Function?) 是否存在反函数 (Inverse?) 典型示例
一对一 (One-one) 每个 x 只对应 1 个 y，且每个 y 只来自 1 个 x ✅ 是 (Yes) ✅ 存在 x ↦ 2x + 1（x ∈ ℝ）
多对一 (Many-one) 多个不同 x 可对应同一个 y，但每个 x 只有唯一输出 ✅ 是 (Yes) ❌ 不存在（除非限制定义域） x ↦ x²（x ∈ ℝ）
一对多 (One-many) 同一个输入 x 对应两个或多个输出 y ❌ 不是 (No) — x ↦ ±√x（x > 0）
多对多 (Many-many) 多个 x 对应多个 y，输入输出均不唯一 ❌ 不是 (No) — 圆 x² + y² = 25
函数准入铁律：Only one-one and many-one mappings are functions!

用图像判断看铅垂线检验 (Vertical Line Test)：任作一条竖直直线 x = c（c 在定义域内），若图像与该直线至多有 1 个交点，则为函数；若出现 2 个或以上交点（如开口向右的抛物线 y² = x 或完整的圆），则属于 one-many / many-many，不是函数。

📘 例题 1.1 · 映射分类与定义域对映射类型的改变

Classify each mapping and state whether it is a function:

(a) x ↦ 3x − 4, for x ∈ ℝ
(b) x ↦ x², for x ∈ ℝ
(c) x ↦ ±√x, for x ≥ 0
(d) x ↦ x², for x ≥ 0

解析 (Solution)：
(a) 线性且斜率非零：x₁ ≠ x₂ ⇒ 3x₁ − 4 ≠ 3x₂ − 4 ⇒ one-one，是函数。
(b) 如 x = 2 与 x = −2 均映射到 4 ⇒ many-one，是函数。
(c) 如 x = 9 同时映射到 +3 与 −3 ⇒ one-many，不是函数。
(d) 限制了 x ≥ 0 后，不存在两个不同非负数平方相等 ⇒ 从 many-one 变为 one-one，是函数（且因此存在反函数！）。

1.2 函数定义：定义域、值域与一一对应 (Definition of a Function)

Notation f(x), Natural Domain, Exact Range & One-One Criterion
Paper 1 高频失分点 二次函数区间值域陷阱

1.2.1 函数记号、自然定义域与值域求法

定义函数必须同时指明法则与定义域 (Domain)，常写作 f : x ↦ 2x + 1, x ∈ ℝ 或 f(x) = 2x + 1 (x ≥ 0)。其中：

  • 定义域 (Domain)：允许输入的所有 x 的集合。若题目未显式给出，则需找最大自然定义域： 分母 ≠ 0（如 12x − 5 ⇒ x ≠ 52）；偶次根号内 ≥ 0（如 √3x − 6 ⇒ x ≥ 2）；分母中的根号需严格大于 0（如 1√10 − 2x ⇒ x < 5）。
  • 值域 (Range)：输出值 f(x) 在给定定义域内实际取遍的集合（必须用 f(x) 或 y 表示，不要写成 x！）。
📘 例题 1.2 · 闭区间上的二次函数值域与自然定义域

(a) The function f is defined by f(x) = x² − 6x + 5 for −1 ≤ x ≤ 5. Find the range of f.
(b) State the largest possible domain of g(x) = 3√10 − 2x.

解析 (Solution)：
(a) 配方找顶点：f(x) = (x − 3)² − 4，顶点在 (3, −4)。
检查顶点横坐标 x = 3 是否落在区间 [−1, 5] 内：是！因此最小值必在顶点取到：f(3) = −4。
再算两端点：f(−1) = (−4)² − 4 = 12，f(5) = 2² − 4 = 0。
比较最大与最小输出，得值域：−4 ≤ f(x) ≤ 12。
(b) 分母不为 0 且根号内非负 ⇒ 10 − 2x > 0 ⇒ 2x < 10 ⇒ x < 5。

⚠️ 致命错题：求闭区间二次函数值域时只代入左右端点！

很多同学在例 1.2(a) 中直接代 f(−1) = 12 与 f(5) = 0，错写成 0 ≤ f(x) ≤ 12！只要开口向上（或向下）的抛物线对称轴落在给定定义域区间内，极值点（顶点）才是真正的一端边界。养成习惯：先画草图或先配方找顶点！

1.3 复合函数 (Composite Functions)

Order fg(x) = f(g(x)), Existence Condition Range(g) ⊆ Domain(f) & Range of fg
Paper 1 必考 复合存在条件 & 解域过滤

1.3.1 复合顺序、存在条件与复合值域两步流水线

fg(x) = f(g(x))（从右向左作用：先算内层 g，再代入外层 f）
  • 顺序不可交换：一般地 fg(x) ≠ gf(x)；且 f²(x) = f(f(x))，切忌当成 [f(x)]²！
  • 复合存在条件 (Existence Condition)：fg 有意义 ⇔ Range(g) ⊆ Domain(f)（内层的值域必须完全落入外层的定义域内）。
  • 求 fg 的值域：先根据 x 的定义域求出内层值域 u = g(x) 的范围，再把该范围作为输入代入外层 f(u) 求最终输出范围。
📘 例题 1.3A · 复合函数解析式、值域与解方程过滤定义域

Given f(x) = x² + 2 (x ∈ ℝ) and g(x) = 2x − 1 (x ≥ 1):
(a) Find an expression for fg(x) and state the range of fg.
(b) Solve the equation fg(x) = gf(x).

解析 (Solution)：
(a) fg(x) = f(2x − 1) = (2x − 1)² + 2 = 4x² − 4x + 3。
求值域：因为 x ≥ 1，所以内层 g(x) = 2x − 1 ≥ 2(1) − 1 = 1。
把 u = g(x) ≥ 1 代入外层 f(u) = u² + 2（在 u ≥ 1 单调递增），最小值为 f(1) = 1² + 2 = 3。
故 Range(fg): fg(x) ≥ 3（或 y ≥ 3）。
(b) 先算 gf(x) = g(x² + 2) = 2(x² + 2) − 1 = 2x² + 3。
联立 fg(x) = gf(x)：4x² − 4x + 3 = 2x² + 3 ⇒ 2x² − 4x = 0 ⇒ 2x(x − 2) = 0 ⇒ x = 0 或 x = 2。
关键验根：fg(x) 的定义域继承自内层 g（要求 x ≥ 1），故 x = 0 越界舍去，唯一解为 x = 2！

📘 例题 1.3B · 反求“使复合函数 fg 存在”的最小定义域限制

Given f(x) = √x − 3 (x ≥ 3) and g(x) = 2x − 1 (x ∈ ℝ). Explain why fg does not exist for x ∈ ℝ, and find the largest possible domain of g for which fg exists.

解析 (Solution)：
若 x ∈ ℝ，则 Range(g) = ℝ，它包含小于 3 的数，并非 Domain(f) = {x ≥ 3} 的子集，因此 fg 不存在。
要使 fg 存在，必须满足 g(x) ≥ 3 ⇒ 2x − 1 ≥ 3 ⇒ x ≥ 2。

1.4 绝对值函数基础 (Modulus Functions)

Definition |x|, Algebraic Properties, |f(x)| vs f(|x|) & Basic Modulus Equations
Paper 1 基础代数

1.4.1 绝对值的分段定义与核心运算性质

|x| = x (当 x ≥ 0 时)   |   |x| = −x (当 x < 0 时)

常用恒等式：|x| ≥ 0；|ab| = |a|·|b|；|x|² = x²；√x² = |x|（当 x < 0 时不是 x 而是 −x！）。
基础方程：|ax + b| = c，若 c > 0 ⇒ ax + b = c 或 ax + b = −c；若 c < 0 ⇒ 无实数解 (No solution)。

📘 例题 1.4 · 辨析 |f(x)| 与 f(|x|) 及含二次表达式的绝对值方程

(a) Given f(x) = 2x − 5, evaluate |f(−1)| and f(|−1|).
(b) Solve |x² − 5x| = 6.

解析 (Solution)：
(a) |f(−1)| = |2(−1) − 5| = |−7| = 7；而 f(|−1|) = f(1) = 2(1) − 5 = −3（两者完全不同！）。
(b) 因右边 6 > 0，拆成两个二次方程：
• x² − 5x = 6 ⇒ x² − 5x − 6 = 0 ⇒ (x − 6)(x + 1) = 0 ⇒ x = 6, −1
• x² − 5x = −6 ⇒ x² − 5x + 6 = 0 ⇒ (x − 2)(x − 3) = 0 ⇒ x = 2, 3
共 4 个精确解：x = −1, 2, 3, 6。

1.5 线性绝对值函数图像 (Graphs of y = |f(x)|, f linear)

V-Shaped Reflection, Sharp Vertex, Vertical Shifts & Graphical Solutions
Paper 1 作图必考 斜率比较防多解陷阱

1.5.1 四步画准 V 字图像 y = |mx + c|

  1. 先用轻虚线画出原一次函数 y = mx + c，标出与 x 轴交点 (−cm, 0) 及 y 轴截距 (0, c)；
  2. 保留 x 轴上方（y ≥ 0）部分不动；
  3. 把 x 轴下方（y < 0）的射线沿 x 轴向上翻折（截距 (0, c) 变成 (0, |c|)）；
  4. 标出尖点（Vertex）(−cm, 0)、左右支斜率 ±m 及对称轴 x = −cm。
💡 考官技巧：从图像斜率秒判 |2x − 4| = px + q 有几个解

画 y = |2x − 4| 时左右两支斜率分别是 −2 和 +2。如果右端直线 y = x + 1 的斜率 1 < 2，它会先后穿过左支和右支，有 2 个交点（x = 1 和 x = 5）；但如果右端直线是 y = 3x + 1（斜率 3 > 2），左支会相交于 x = 35，而右支平行往右跑得比它慢，永远追不上（代数解出 x = −5 在 x < 2 一侧，必须舍去）！

1.6 反函数与定义域限制 (Inverse Functions & Domain Restriction)

Existence Condition (One-One), Domain-Range Swap, Quadratic Sign Choice & Rational Inverses
Paper 1 必考大题 忘写 Domain(f⁻¹) 必扣分

1.6.1 反函数存在定理与定义域值域互换律

f⁻¹ 存在 ⇔ f 必须是 One-One 函数  |  Domain(f⁻¹) = Range(f)  且  Range(f⁻¹) = Domain(f)

求 f⁻¹(x) 四步走：① 令 y = f(x)；② 反解出 x（用 y 表示）；③ 互换 x 与 y 写成 f⁻¹(x) = ...；④ 务必同时写出 f⁻¹ 的定义域（即原函数 f 的值域）！

📘 例题 1.6A · 二次函数限制定义域使其可逆（开方符号选择！）

Let f(x) = x² − 6x + 11 for x ≥ k.
(a) Find the least value of k for which f⁻¹ exists.
(b) For this value of k, find f⁻¹(x) and state its domain and range.

解析 (Solution)：
(a) 配方：f(x) = (x − 3)² + 2。抛物线对称轴为 x = 3。为了使函数在 x ≥ k 上保持单调（one-one），k 不能跨过对称轴向左，故最小值为 k = 3。
(b) 当 x ≥ 3 时，(x − 3)² ≥ 0 ⇒ f(x) ≥ 2，即 Range(f) = {y ≥ 2}。
令 y = (x − 3)² + 2 ⇒ (x − 3)² = y − 2 ⇒ x − 3 = ±√y − 2。
因为 x ≥ 3 ⇒ x − 3 ≥ 0，取正号 +：x = 3 + √y − 2。
互换字母并注明定义域与值域：
f⁻¹(x) = 3 + √x − 2，Domain: x ≥ 2，Range: f⁻¹(x) ≥ 3。
（注：若题设改为 x ≤ 3，则 x − 3 ≤ 0，必须取负号得 f⁻¹(x) = 3 − √x − 2！）

📘 例题 1.6B · 分式线性函数求反函数

Given g(x) = 2x + 1x − 3 (x ≠ 3), find g⁻¹(x) and state the value of x not in the domain of g⁻¹.

解析 (Solution)：
令 y = 2x + 1x − 3 ⇒ y(x − 3) = 2x + 1 ⇒ xy − 2x = 3y + 1 ⇒ x(y − 2) = 3y + 1 ⇒ x = 3y + 1y − 2。
故 g⁻¹(x) = 3x + 1x − 2，Excluded value: x ≠ 2（这也正是原函数 g(x) 永远取不到的水平渐近线值 y = 2！）。

1.7 原函数与反函数图像的对称性 (Graph of f and f⁻¹ Symmetrical in y = x)

Reflection in y = x, Swapped Coordinates & Solving f(x) = f⁻¹(x) via f(x) = x
Paper 1 图像与方程联动 交互实验室在本节

1.7.1 关于直线 y = x 的镜像规则与交点捷径

  • 若点 (a, b) 在 y = f(x) 上，则点 (b, a) 必在 y = f⁻¹(x) 上。两曲线严格关于直线 y = x 轴对称。
  • 特殊要素同步互换：f 的起点/顶点 (p, q) 变为 f⁻¹ 的起点 (q, p)；y 轴截距 (0, c) 变为 x 轴截距 (c, 0)；铅垂渐近线 x = a 变为水平渐近线 y = a。
  • 求解 f(x) = f⁻¹(x) 的提速捷径：对于严格单调递增函数，f 与 f⁻¹ 的所有交点都在对称轴 y = x 上！因此不必硬算 f(x) = f⁻¹(x)（往往会出现四次方程或根式嵌套），只需直接解更简单的 f(x) = x（并检验解在定义域内）！
💡 考官提醒：递减函数可能有“不在 y = x 上”的对称交点！

仅当 f 在其定义域上严格递增时，才有 f(x) = f⁻¹(x) ⇔ f(x) = x。对于单调递减函数（例如 f(x) = 4 − x 是自身反函数 f = f⁻¹，整条直线重合！），交点可能成对出现在 (a, b) 与 (b, a)（a ≠ b）。但 0606 绝大多数考题给的是递增二次半支或对数/指数函数，直接解 f(x) = x 即可秒杀！

SME 1 · 二次配方、定义域截断、反函数与复合解方程[8 marks]
The function f is defined by f(x) = 2x² − 12x + 23 for x ≥ k.
(a) Express f(x) in the form a(x − b)² + c. [2]
(b) State the smallest possible value of k for which f⁻¹ exists. [1]
(c) Using this value of k, find f⁻¹(x) and state its domain. [3]
(d) Given g(x) = 4x − 1 for x ≥ 1, solve fg(x) = 23. [2]
无计算器：先配方确定反函数存在的最小 k，再求反函数与定义域，最后利用域限解复合方程。
查看评分细则 (Mark Scheme · 8 Marks)

M1 (a) 2(x² − 6x) + 23 = 2[(x − 3)² − 9] + 23 A1 2(x − 3)² + 5.

B1 (b) Axis of symmetry is x = 3, so least k = 3.

M1 (c) y = 2(x − 3)² + 5 ⇒ (x − 3)² = y − 52 ⇒ x = 3 + √y − 52 (positive root since x ≥ 3).
A1 f⁻¹(x) = 3 + √x − 52；B1 Domain: x ≥ 5.

M1 (d) 2(g(x) − 3)² + 5 = 23 ⇒ (4x − 4)² = 9 ⇒ 4x − 4 = ±3 ⇒ x = 74 or 14.
A1 Since x ≥ 1, reject 14 ⇒ x = 74.

SME 2 · 分式函数值域、反函数与对称轴 y = x 交点[7 marks]
The function f is defined by f(x) = 3x + 2x + 2 for x > −2.
(a) Find the range of f. [2]
(b) Find f⁻¹(x) and state its domain. [3]
(c) Solve f(x) = f⁻¹(x). [2]
无计算器：拆分常数法求分式函数值域，求反函数后用 f(x) = x 快速求解交点。
查看评分细则 (Mark Scheme · 7 Marks)

M1 (a) Rewrite f(x) = 3(x + 2) − 4x + 2 = 3 − 4x + 2. Since x + 2 > 0, 4x + 2 > 0 ⇒ A1 Range: f(x) < 3.

M1 (b) y(x + 2) = 3x + 2 ⇒ x(3 − y) = 2y − 2 ⇒ x = 2y − 23 − y.
A1 f⁻¹(x) = 2x − 23 − x；B1 Domain: x < 3.

M1 (c) Since f is strictly increasing on x > −2, intersections lie on y = x: 3x + 2x + 2 = x ⇒ x² + 2x = 3x + 2 ⇒ x² − x − 2 = 0 ⇒ (x − 2)(x + 1) = 0.
A1 Both x = 2 and x = −1 satisfy x > −2 ⇒ x = −1, 2.

SME 3 · 根式复合存在条件与精确根式解[7 marks]
Functions f and g are defined by f(x) = √x − 4 + 2 (x ≥ 4) and g(x) = x² − 5 (x ≥ 0).
(a) State the range of f and find f⁻¹(x) with its domain. [3]
(b) Find the restricted domain of x for which fg(x) exists. [2]
(c) Solve fg(x) = 5, giving your answer in simplest surd form. [2]
无计算器：考察复合函数存在域 Range(g) ⊆ Domain(f) 与最简根式输出。
查看评分细则 (Mark Scheme · 7 Marks)

B1 (a) Range of f: f(x) ≥ 2.
M1 y − 2 = √x − 4 ⇒ x = (y − 2)² + 4 ⇒ A1 f⁻¹(x) = (x − 2)² + 4, Domain: x ≥ 2.

M1 (b) Need g(x) ≥ 4 ⇒ x² − 5 ≥ 4 ⇒ x² ≥ 9. Since x ≥ 0, A1 x ≥ 3.

M1 (c) √(x² − 5) − 4 + 2 = 5 ⇒ √x² − 9 = 3 ⇒ x² = 18.
A1 Since x ≥ 3, x = 3√2.

SME 4 · 平移型线性绝对值函数与直线交点[7 marks]
The function f is defined by f(x) = |2x − 6| − 2 for 0 ≤ x ≤ 6.
(a) State the coordinates of the vertex and intercepts of y = f(x), and find the range of f. [3]
(b) Explain why f does not have an inverse on 0 ≤ x ≤ 6. [1]
(c) Solve f(x) = 12x. [3]
无计算器：含上下平移的绝对值函数端点与值域分析，并解与直线的交点。
查看评分细则 (Mark Scheme · 7 Marks)

B1 (a) Vertex at (3, −2); y-intercept (0, 4); x-intercepts |2x − 6| = 2 ⇒ (2, 0), (4, 0) (B1).
Endpoints f(0) = 4, f(6) = 4 ⇒ B1 Range: −2 ≤ f(x) ≤ 4.

B1 (b) f is many-one (e.g. f(2) = f(4) = 0), not one-one.

M1 (c) |2x − 6| = 12x + 2.
Branch 1 (x ≥ 3): 2x − 6 = 12x + 2 ⇒ 32x = 8 ⇒ x = 163 (A1).
Branch 2 (x < 3): 6 − 2x = 12x + 2 ⇒ 52x = 4 ⇒ x = 85 (A1). Both lie in [0, 6].

C01 · 1.1 MappingsDefinition
Which mapping types qualify as a function, and how does the Vertical Line Test confirm this?
哪几类映射才能被称为函数？如何用铅垂线检验图像？
👆 点击查看参考答案
Only one-one and many-one mappings are functions (each input has a unique output). A graph represents a function iff any vertical line cuts it at most once.
C02 · 1.2 Domain & RangeTrap
What are the three natural domain exclusions in Paper 1, and what is the trap in finding the range of a quadratic on [a, b]?
自然定义域的三大限制是什么？求闭区间二次函数值域的最大陷阱是什么？
👆 点击查看参考答案
Exclusions: denominator ≠ 0, even root ≥ 0, radicand in denominator > 0. Quadratic range trap: always check if the vertex (turning point) lies inside [a, b], never test endpoints only!
C03 · 1.3 Composite ConditionExistence
State the exact condition required for the composite function fg(x) to exist.
默写复合函数 fg(x) 存在的剑桥考纲标准充要条件。
👆 点击查看参考答案
fg(x) = f(g(x)) exists if and only if the range of g is a subset of the domain of f (Range(g) ⊆ Domain(f)).
C04 · 1.3 Composite RangeMethod
What is the difference between f²(x) and [f(x)]², and how do you find the range of fg?
区分 f²(x) 与 [f(x)]²，并简述求复合函数 fg 值域的两步法。
👆 点击查看参考答案
f²(x) = f(f(x)) (apply f twice), not [f(x)]². Range of fg: ① find Range(g) on Domain(g); ② feed that interval as inputs into f.
C05 · 1.4 ModulusDefinition
Write the piecewise definition of |x| and simplify √(x²) for general real x.
写出 |x| 的分段定义，并写出 √(x²) 对任意实数 x 的精确化简结果。
👆 点击查看参考答案
|x| = x (x ≥ 0) and −x (x < 0). Always √(x²) = |x| (not x when x < 0).
C06 · 1.4 Checking RootsValidation
Why must you substitute answers back when solving |ax + b| = cx + d?
解方程 |ax + b| = cx + d 时为什么必须回代检验右边表达式？
👆 点击查看参考答案
Because |ax + b| ≥ 0, any candidate root making cx + d < 0 is an extraneous root and must be rejected.
C07 · 1.5 Linear Modulus GraphSketching
Give the vertex coordinates, range, and slopes of the two branches of y = |ax + b| (a > 0).
写出折线 y = |ax + b| (a > 0) 的尖点坐标、值域与左右两支斜率。
👆 点击查看参考答案
Sharp vertex at (−b/a, 0); range y ≥ 0; right branch (x ≥ −b/a) has slope +a, reflected left branch has slope −a.
C08 · 1.5 Intersection CountGradient Rule
For |mx + c| = px + q (m > 0, p > 0), how does comparing p with m predict the number of roots?
如何比较直线斜率 p 与折线斜率 m，直观预测 |mx + c| = px + q 的交点个数？
👆 点击查看参考答案
If p < m, the line crosses both branches (up to 2 roots depending on y-shift); if p ≥ m, it cannot catch the steeper right branch, leaving at most 1 intersection on the left branch.
C09 · 1.6 Inverse ConditionExistence
State why a function f has an inverse f⁻¹, and write the Domain-Range swap identity.
默写反函数 f⁻¹ 存在的英文标准理由及定义域/值域互换律。
👆 点击查看参考答案
f⁻¹ exists iff f is a one-one function (Horizontal Line Test). Always Domain(f⁻¹) = Range(f) and Range(f⁻¹) = Domain(f).
C10 · 1.6 Quadratic Sign ChoiceAlgebra
When inverting f(x) = a(x − h)² + k (a > 0), how do you choose + or − before the square root?
对配方二次函数求反函数开方时，如何确定根号前取 + 还是 − ？
👆 点击查看参考答案
Check the restricted domain: if x ≥ h, then x − h ≥ 0 so take +√; if x ≤ h, then x − h ≤ 0 so take −√.
C11 · 1.7 Graph SymmetryGeometry
Describe the geometric relationship between y = f(x) and y = f⁻¹(x), and its effect on intercepts/asymptotes.
描述 y = f(x) 与 y = f⁻¹(x) 图像的几何关系及其对截距/渐近线的影响。
👆 点击查看参考答案
They are reflections of each other in the line y = x. Every point (a, b) maps to (b, a); x-intercepts swap with y-intercepts, and vertical asymptotes x = c become horizontal y = c.
C12 · 1.7 Solving f(x) = f⁻¹(x)Shortcut
Why is solving f(x) = f⁻¹(x) usually replaced by solving f(x) = x, and when must you be careful?
为什么解 f(x) = f⁻¹(x) 常转为解 f(x) = x？什么情况下要小心特例？
👆 点击查看参考答案
For strictly increasing functions, all intersections of f and f⁻¹ lie on y = x, so solving f(x) = x gives the exact roots (check Domain!). Caution: decreasing functions can have off-diagonal pairs (a, b) & (b, a).
