2.1 联立方程组：一线性一非线性 (Simultaneous Equations)

Substitution Method, Forming Quadratics, Exact Surd Pairs & Coordinate Pairing
Paper 1 无计算器精确解 几何交点对应必考

2.1.1 代入消元四步法与无分数选元技巧

求解一个一次方程（Linear）与一个二次/分式/乘积非线性方程（Non-linear）联立时，消元法几乎失效，必须严格使用代入消元法 (Substitution)：

  1. 挑选没有分数（或分母更简单）的变量从一次方程里解出：例如 2x − y = 3，果断写成 y = 2x − 3（避开 x = y + 32 的分母运算！）；
  2. 代入非线性方程，展开并整理为标准二次方程 ax² + bx + c = 0；
  3. 因式分解或用求根公式（Paper 1 务必化简为最简根式 a ± b√c）；
  4. 代回一次方程算出对应的另一变量，并成对写出 (x₁, y₁) 与 (x₂, y₂)。
📘 例题 2.1A · 一次方程与圆型二次方程联立

Solve the simultaneous equations: 2x − y = 3 and x² + y² − 6x = 17.

解析 (Solution)：
① 从一次方程解出 y = 2x − 3。
② 代入非线性方程：x² + (2x − 3)² − 6x = 17
展开：x² + (4x² − 12x + 9) − 6x = 17 ⇒ 5x² − 18x − 8 = 0。
③ 因式分解：(5x + 2)(x − 4) = 0 ⇒ x = −25 或 x = 4。
④ 回代 y = 2x − 3：
• 当 x = 4 时，y = 2(4) − 3 = 5；
• 当 x = −25 时，y = 2(−25) − 3 = −195。
故两组解为：(4, 5) 和 (−25, −195)。

📘 例题 2.1B · Paper 1 含精确根式的双曲线交点联立

Find the exact coordinates of intersection of x + y = 4 and xy = 2.

解析 (Solution)：
由一次式得 y = 4 − x，代入 xy = 2：x(4 − x) = 2 ⇒ x² − 4x + 2 = 0。
用求根公式：x = 4 ± √16 − 82 = 4 ± 2√22 = 2 ± √2。
代回 y = 4 − x：
• x = 2 + √2 ⇒ y = 2 − √2；
• x = 2 − √2 ⇒ y = 2 + √2。
精确坐标：(2 + √2, 2 − √2) 与 (2 − √2, 2 + √2)。

⚠️ 易错警报：切忌把 x 代回非线性方程求 y！

例如例 2.1A 若把 x = 4 代回 x² + y² − 6x = 17，会算出 y² = 25 ⇒ y = ±5，产生违背 2x − y = 3 的增根 (4, −5)！永远代回线性方程求另一变量，才能保证一一配对。

2.2 配方法与二次函数最值 (Maximum and Minimum Values)

Completing the Square a(x + p)² + q, Vertex Coordinates & Range
Paper 1 必考工具 反函数/最值/判别式基石

2.2.1 首项非 1 的标准配方模板与极值判定

ax² + bx + c = a(x + p)² + q   |   顶点 (Stationary Point / Vertex) = (−p, q)
  • 当 a > 0（U 形开口向上）：在 x = −p 处取得最小值 (Minimum) q，全实数域值域为 f(x) ≥ q；
  • 当 a < 0（∩ 形开口向下）：在 x = −p 处取得最大值 (Maximum) q，全实数域值域为 f(x) ≤ q；
  • Paper 1 规范动作：只对前两项 ax² + bx 提公因数 a，千万不要把整个式子除以 a（表达式没有“= 0”，除以 a 会改变函数本身的值！）。
📘 例题 2.2 · 正负首项配方法求最值与对称轴

(a) Express 3x² − 12x + 7 in the form a(x − p)² + q, and state its minimum value and the value of x where it occurs.
(b) Express 5 + 6x − 2x² in the form A − B(x − C)², and state its maximum value.

解析 (Solution)：
(a) 对前两项提 3：3(x² − 4x) + 7 = 3[(x − 2)² − 4] + 7 = 3(x − 2)² − 12 + 7 = 3(x − 2)² − 5。
因为 3(x − 2)² ≥ 0，最小值为 −5，当 x = 2 时取到。
(b) 先按降幂重排并从前两项提 −2：
−2x² + 6x + 5 = −2(x² − 3x) + 5 = −2[(x − 32)² − 94] + 5 = −2(x − 32)² + 92 + 5
整理为目标格式：192 − 2(x − 32)²。
因为 −2(x − 32)² ≤ 0，最大值为 192（在 x = 32 处取到）。

2.3 二次绝对值图像翻折 (Graphs of y = |f(x)|, f quadratic)

Reflecting Negative Arcs, Sharp Cusps at Roots & Counting Solutions to |f(x)| = k
Paper 1 作图与根数题 交互实验室在本节

2.3.1 三种判别式形态下的翻折规律与水平线交点计数

作图 y = |ax² + bx + c| 时，关键是先确定原抛物线与 x 轴的位置关系（即判别式 Δ = b² − 4ac）：

  • 情况 1（Δ > 0，两相异实根 α, β）：原抛物线在 x 轴下方的弧段全部沿 x 轴向上翻折！原顶点 (h, k)（k < 0）翻折为局部极点 (h, |k|)，而在根 (α, 0), (β, 0) 处形成两个尖角 (Cusps)。
  • 情况 2（Δ = 0，与 x 轴相切）：若 a > 0，图像全在 x 轴上方或轴上，|f(x)| = f(x) 保持不变；若 a < 0，整条倒抛物线向上翻转。
  • 情况 3（Δ < 0，无实根）：若 a > 0，恒正故图像完全不变；若 a < 0，整条曲线上下翻转成在 x 轴上方的 U 形抛物线！
📘 例题 2.3 · 作图 y = |x² − 4x + 3| 并讨论 |x² − 4x + 3| = k 的实根个数

Sketch the graph of y = |x² − 4x + 3|, labelling intercepts and the vertex, and state the number of solutions of |x² − 4x + 3| = k for different values of k.

解析 (Solution)：
原抛物线 y = (x − 1)(x − 3) = (x − 2)² − 1：x 轴截距 (1, 0), (3, 0)，y 轴截距 (0, 3)，原最低点 (2, −1)。
翻折后：1 < x < 3 这一段翻到 x 轴上方，形成局部最高点 (2, 1)。
作水平线 y = k 观察交点个数：
• k < 0：0 个解；
• k = 0：2 个解（x = 1, 3）；
• 0 < k < 1：4 个解（穿过左右外支及中间拱包两次）；
• k = 1：3 个解（恰好相切于翻折最高点 (2, 1)，外加外侧两支各 1 点）；
• k > 1：2 个解（只穿过左右两条外支）。

2.4 二次不等式 (Quadratic Inequalities)

Critical Values, Parabola Sketching, Inside vs Outside Intervals & Notation Traps
Paper 1/2 全章工具 绝对不可写成 α > x > β

2.4.1 “移项正首项 → 求根 → 画草图 → 读区间”四步法

设 a > 0 且 α < β：a(x − α)(x − β) < 0 ⇒ α < x < β (夹在中间)  |  a(x − α)(x − β) > 0 ⇒ x < α 或 x > β (在两边)

遇到负数首项（如 12 + x − x² > 0），先移项或乘 −1 （记得不等号方向反转！）化为 x² − x − 12 < 0 再因式分解！

📘 例题 2.4 · 移项整理解二次不等式与双边书写规范

Find the set of values of x satisfying:
(a) 2x² − 5x ≥ 3     (b) x(x + 2) < 15

解析 (Solution)：
(a) 移项得 2x² − 5x − 3 ≥ 0 ⇒ (2x + 1)(x − 3) ≥ 0。
临界值（Critical values）：x = −12 和 x = 3。开口向上取 ≥ 0（在 x 轴上方两翼）：
x ≤ −12 or x ≥ 3。
(b) 展开移项：x² + 2x − 15 < 0 ⇒ (x + 5)(x − 3) < 0。
临界值：−5 与 3。开口向上取 < 0（在 x 轴下方中间段）：−5 < x < 3。

⚠️ 两大扣分雷区：拆写连接词与禁止消去未知数

1. 两翼区间 不能写成 3 ≤ x ≤ −12，也不要用 “and”（一个数不可能同时大于 3 又小于 −1/2），必须写 or（或集合并集）。
2. 遇 x² > 4x 时绝对不能两边直接除以 x 得 x > 4！因为 x 可正可负可为 0，正确做法是移项提公因式 x(x − 4) > 0 ⇒ x < 0 or x > 4！

2.5 二次方程根与判别式 (Roots of Quadratics & Discriminant)

b² − 4ac Conditions, Real Roots vs Distinct Roots & Always-Positive Quadratics
Paper 1/2 核心压轴 二次恒正双条件陷阱

2.5.1 判别式 Δ = b² − 4ac 英文关键字速查表

英语题干关键字 判别式条件 几何含义
Two real and distinct roots b² − 4ac > 0 抛物线与 x 轴相交于 2 个不同点
Equal / repeated / one root b² − 4ac = 0 抛物线顶点恰好相切于 x 轴
Has real roots（注意没有 distinct!） b² − 4ac ≥ 0 至少 1 个实根（含相切与两相异实根！）
No real roots b² − 4ac < 0 抛物线完全浮在 x 轴上方或下方
Always positive (ax²+bx+c > 0 ∀ x ∈ ℝ) a > 0 AND b² − 4ac < 0 开口必须向上且与 x 轴无交点
📘 例题 2.5 · 含未知首项系数的判别式与“恒正”双条件检验

Find the set of values of k for which:
(a) kx² + 4x + (k − 3) = 0 has no real roots;
(b) kx² + 4x + (k − 3) > 0 for all x ∈ ℝ.

解析 (Solution)：
(a) 当 k = 0 时方程变为一次方程 4x − 3 = 0（有实根 x = 34，不满足无实根）。
当 k ≠ 0 时，无实根要求 Δ < 0：
4² − 4(k)(k − 3) < 0 ⇒ 16 − 4k² + 12k < 0。
除以 −4（不等号反转！）：k² − 3k − 4 > 0 ⇒ (k − 4)(k + 1) > 0。
故 k < −1 or k > 4。
(b) 要让二次式对所有实数 x 恒大于 0，必须同时满足：① Δ < 0（即 k < −1 或 k > 4），且 ② 开口向上 k > 0！
取交集舍去 k < −1（若 k < −1 则图像全在 x 轴下方恒负！），得 k > 4。

2.6 直线与曲线交点及相切条件 (Intersection of a Line and a Curve)

Eliminating y to Form Ax² + Bx + C = 0, Tangent (Δ = 0) & Disjoint Conditions (Δ < 0)
Paper 1 高频综合题

2.6.1 代入消元后用判别式控制位置关系

把直线方程 y = mx + c 代入曲线方程（抛物线、圆或双曲线 xy = k），消元整理为 Ax² + Bx + C = 0 后：

  • B² − 4AC > 0 ⇔ 直线与曲线交于 2 个不同点（Meets at two distinct points）；
  • B² − 4AC = 0 ⇔ 直线与曲线相切（Is a tangent to / touches the curve），切点即唯一重根 x = −B2A；
  • B² − 4AC < 0 ⇔ 直线与曲线不相交（Does not meet / never intersects）。
📘 例题 2.6 · 直线与抛物线相切求参数及切点坐标

The line y = mx − 4 and the curve y = x² − 2x + 5 are given.
(a) Find the set of values of m for which the line does not meet the curve.
(b) Find the two values of m for which the line is a tangent to the curve, and find the coordinates of the point of contact for m > 0.

解析 (Solution)：
消去 y：x² − 2x + 5 = mx − 4 ⇒ x² − (m + 2)x + 9 = 0。
计算判别式：Δ = [−(m + 2)]² − 4(1)(9) = (m + 2)² − 36。
(a) 不相交要求 Δ < 0：(m + 2)² < 36 ⇒ −6 < m + 2 < 6 ⇒ −8 < m < 4。
(b) 相切要求 Δ = 0：(m + 2)² = 36 ⇒ m + 2 = ±6 ⇒ m = 4 或 m = −8。
当 m = 4 时，方程化为 x² − 6x + 9 = 0 ⇒ (x − 3)² = 0 ⇒ x = 3，代回直线得 y = 4(3) − 4 = 8。
切点坐标为 (3, 8)。

SME 1 · 联立方程组精确分数解[6 marks]
Solve the simultaneous equations:
3x − y = 5
2x² − xy + y² = 8 [6]
无计算器：用代入法求两组精确分数坐标解并验算。
查看评分细则 (Mark Scheme · 6 Marks)

M1 Rearrange linear equation: y = 3x − 5.

M1 Substitute into quadratic: 2x² − x(3x − 5) + (3x − 5)² = 8.

M1 Expand & collect: 2x² − 3x² + 5x + 9x² − 30x + 25 = 8 ⇒ 8x² − 25x + 17 = 0 (A1).

M1 Factorise: (8x − 17)(x − 1) = 0 ⇒ x = 1 or x = 178.

A1 Back-substitute into y = 3x − 5: (1, −2) and (178, 118).

SME 2 · 二次绝对值图像、交点数与精确根式解[8 marks]
Let f(x) = x² − 6x + 5.
(a) Express f(x) in completed square form and state the coordinates of the vertex of y = |f(x)|. [2]
(b) State the number of solutions of |f(x)| = k when k = 4 and when 0 < k < 4. [2]
(c) Solve |x² − 6x + 5| = 3, leaving irrational answers in exact surd form. [4]
无计算器：二次绝对值翻折顶点、水平线交点计数与 4 根精确求解。
查看评分细则 (Mark Scheme · 8 Marks)

B1 (a) f(x) = (x − 3)² − 4. Since −4 < 0 reflects across x-axis, vertex of y = |f(x)| is (3, 4) (B1).

B1 (b) When k = 4: 3 solutions；B1 when 0 < k < 4: 4 solutions.

M1 (c) Split x² − 6x + 5 = ±3:
Case 1: x² − 6x + 5 = 3 ⇒ x² − 6x + 2 = 0 ⇒ x = 6 ± √36 − 82 = 3 ± √7 (A1).
M1 Case 2: x² − 6x + 5 = −3 ⇒ x² − 6x + 8 = 0 ⇒ (x − 2)(x − 4) = 0 ⇒ x = 2, 4 (A1).

SME 3 · 含参判别式与二次不等式求解集[7 marks]
(a) Find the set of values of k for which x² + (k − 2)x + (k + 1) = 0 has no real roots. [4]
(b) Find the range of values of k for which the line y = 2x − 1 meets the curve y = x² + kx + 8 at two distinct points. [3]
无计算器：综合考察判别式不等式展开与临界值求区间。
查看评分细则 (Mark Scheme · 7 Marks)

M1 (a) Δ = (k − 2)² − 4(1)(k + 1) < 0.
M1 k² − 4k + 4 − 4k − 4 < 0 ⇒ k² − 8k < 0.
M1 k(k − 8) < 0 ⇒ A1 0 < k < 8.

M1 (b) x² + kx + 8 = 2x − 1 ⇒ x² + (k − 2)x + 9 = 0.
M1 Δ = (k − 2)² − 36 > 0 ⇒ |k − 2| > 6 ⇒ A1 k < −4 or k > 8.

SME 4 · 直线与反比例双曲线相切及相交条件[7 marks]
The line 2x + y = k and the curve xy = 8 are given.
(a) Find the two values of k for which the line is a tangent to the curve, and find the coordinates of each point of contact. [5]
(b) State the set of values of k for which the line cuts the curve at two distinct points. [2]
无计算器：直线与双曲线 xy = 8 消元后判定相切与双交点。
查看评分细则 (Mark Scheme · 7 Marks)

M1 (a) Substitute y = k − 2x into xy = 8: x(k − 2x) = 8 ⇒ 2x² − kx + 8 = 0.

M1 Tangent condition Δ = (−k)² − 4(2)(8) = k² − 64 = 0 ⇒ A1 k = 8 or k = −8.

M1 When k = 8: 2x² − 8x + 8 = 0 ⇒ (x − 2)² = 0 ⇒ x = 2, y = 4 ⇒ (2, 4).
When k = −8: 2x² + 8x + 8 = 0 ⇒ (x + 2)² = 0 ⇒ x = −2, y = −4 ⇒ (−2, −4) (A1).

M1 (b) Two distinct points require k² − 64 > 0 ⇒ A1 k < −8 or k > 8.

Vertex at (−p, q). If a > 0, minimum value q occurs at x = −p (range f(x) ≥ q). If a < 0, maximum value q occurs at x = −p (range f(x) ≤ q).
C03 · 2.2 Factoring TrapAlgebra
Why must you factor out a rather than divide by a when completing the square on the expression ax² + bx + c?
对多项式 ax² + bx + c 配方时，为什么只能提公因数 a 而不能直接两边除以 a？
👆 点击查看参考答案
Because ax² + bx + c is an expression, not an equation = 0. Dividing by a alters its value (scaling the minimum/maximum by 1/a); you must factor a out of the first two terms.
C04 · 2.2 Symmetry & RootsShortcut
Given a parabola passes through (α, k) and (β, k), how do you immediately find its line of symmetry?
已知抛物线过同高度两点 (α, k) 与 (β, k)，如何一秒写出对称轴？
👆 点击查看参考答案
By symmetry, the axis of symmetry is the midpoint x = (α + β) / 2 (also equal to −b / (2a)).
C05 · 2.3 Modulus QuadraticSketching
How does the vertex (h, k) of y = f(x) behave in y = |f(x)| when k < 0 vs when Δ < 0 and a > 0?
作 y = |f(x)| 图像时，若原顶点在 x 轴下方 vs 原抛物线全在 x 轴上方，图像各有什么变化？
👆 点击查看参考答案
If k < 0, the negative arc reflects across the x-axis so (h, k) becomes a local maximum at (h, |k|) with sharp cusps at roots. If Δ < 0 and a > 0, f(x) > 0 everywhere so the graph is completely unchanged.
C06 · 2.3 Solution CountingGeometry
For y = |a(x − α)(x − β)| with flipped vertex height H > 0, list the number of roots of |f(x)| = k for k > 0.
写出翻折后拱顶高度为 H 的二次绝对值方程 |f(x)| = k（k > 0）在不同 k 下的解的个数。
👆 点击查看参考答案
For 0 < k < H: 4 solutions; at k = H: 3 solutions (tangent to flipped peak); for k > H: 2 solutions.
C07 · 2.4 InequalitiesInterval Rule
Write the standard solution intervals for (x − α)(x − β) < 0 and (x − α)(x − β) > 0 (α < β).
默写正首项二次不等式小于 0 与大于 0 的标准区间写法。
👆 点击查看参考答案
< 0 (below axis): α < x < β (single connected interval). > 0 (above axis): x < α or x > β (must use or, never β < x < α).
C08 · 2.4 Sign TrapMistake
Why is dividing both sides of x² > 5x by x wrong when solving inequalities?
解不等式 x² > 5x 时为什么禁止两边直接约去 x ？
👆 点击查看参考答案
The sign of x is unknown (dividing by negative x reverses >, and x could be 0). Always rearrange to x(x − 5) > 0 ⇒ x < 0 or x > 5.
C09 · 2.5 DiscriminantWord Cues
Distinguish "has two distinct real roots" from "has real roots" in terms of b² − 4ac.
英文题干中 "two distinct real roots" 与 "has real roots" 对应的判别式有何区别？
👆 点击查看参考答案
"Two distinct real roots" requires strict b² − 4ac > 0; "has real roots" allows equal roots too, so use b² − 4ac ≥ 0.
C10 · 2.5 Always PositiveDual Condition
State both necessary and sufficient conditions for ax² + bx + c > 0 for all x ∈ ℝ.
默写二次表达式对所有实数 x 恒大于 0 的充要双条件。
👆 点击查看参考答案
Both a > 0 (opens upwards) AND b² − 4ac < 0 (no x-intercepts).
C11 · 2.5 Linear DegenerateEdge Case
If the coefficient of x² contains parameter k (e.g. kx² + 4x + k − 3 = 0), what must you check separately?
当 x² 系数含有参数 k 时，解题时必须单独核查什么边界值？
👆 点击查看参考答案
Check when the x² coefficient equals 0, because the equation degenerates into a linear equation (having 1 real root, where the discriminant does not apply).
C12 · 2.6 Tangent ConditionGeometry
Write the full procedure to prove a line is a tangent to a curve and locate the point of contact.
默写证明直线与曲线相切并求出切点坐标的标准考场流程。
👆 点击查看参考答案
Eliminate one variable to form Ax² + Bx + C = 0; show B² − 4AC = 0 (tangent); then solve the repeated root x = −B/(2A) and substitute into the linear equation for y.
