4.1 解绝对值方程 |ax + b| = |cx + d| 与 |ax + b| = c (Solving Modulus Equations)

Difference of Two Squares, Two-Branch Splitting & Mandatory Extraneous Root Checks
Paper 1 必考 平方差秒解双绝对值

4.1.1 三大解题方法与适用场景对照

双绝对值 |A| = |B| ⇔ A² = B² ⇔ (A − B)(A + B) = 0   |   单绝对值 |A| = L ⇒ A = ±L 且必须检验 L ≥ 0
  • 方法 1：平方差法（首选用于 |ax + b| = |cx + d|）：因左右两边都 ≥ 0，直接平方等价变形为 [(ax + b) − (cx + d)][(ax + b) + (cx + d)] = 0，不必展开二次项！
  • 方法 2：正负双分支法（用于 |ax + b| = cx + d）：列 ax + b = cx + d 或 ax + b = −(cx + d)，解出所有候选值后，必须代回原方程右边 cx + d 检验是否 ≥ 0！
  • 方法 3：图像法辅助：在草纸画 V 形折线与直线/另一 V 形折线，一眼看清有 0、1 还是 2 个交点。
📘 例题 4.1 · 平方差解双绝对值与单绝对值增根检验

(a) Solve |3x − 2| = |x + 6|.
(b) Solve |2x − 5| = x − 1, and contrast with |x − 4| = 2x − 5.

解析 (Solution)：
(a) 两边均为绝对值，直接平方并用平方差公式分解：
(3x − 2)² = (x + 6)² ⇒ [(3x − 2) − (x + 6)][(3x − 2) + (x + 6)] = 0
(2x − 8)(4x + 4) = 0 ⇒ x = 4 或 x = −1。（代回均成立：10 = 10 与 5 = 5 ✓）。
(b) 对于 |2x − 5| = x − 1：
• 2x − 5 = x − 1 ⇒ x = 4（验右边 4 − 1 = 3 ≥ 0 ✓）；
• 2x − 5 = −(x − 1) ⇒ 3x = 6 ⇒ x = 2（验右边 2 − 1 = 1 ≥ 0 ✓）。故 x = 2, 4。
对比 |x − 4| = 2x − 5：得 x = 1 与 x = 3。检验右边 2x − 5：当 x = 1 时右边 2(1) − 5 = −3 < 0（舍去！），故唯一解为 x = 3。

⚠️ 易错警报：用平方法解 |ax + b| = cx + d 时同样可能产生增根！

若对 |x − 4| = 2x − 5 两边平方，实质上解的是 |x − 4| = |2x − 5|，必定会把使 2x − 5 < 0 的根（x = 1）也混进来！只要有一边没有绝对值符号，解完最后一步必须检验 RHS ≥ 0。

4.2 解绝对值不等式 (Solving Modulus Inequalities)

4.2.1 三类标准绝对值不等式通解策略

不等式类型 核心等价转换 考场推荐操作
|ax + b| < k (k > 0) −k < ax + b < k（夹心三明治） 同时减 b 再除以 a（a < 0 记得反转号）
|ax + b| > k (k > 0) ax + b < −k or ax + b > k（两翼） 拆写两段，用 or 连接
|ax + b| < |cx + d| 或 ≥ 两边非负 ⇒ 直接平方转为二次不等式 [(ax+b)−(cx+d)][(ax+b)+(cx+d)] < 0（或 ≥ 0）
|ax + b| < cx + d（单边含 x） −(cx + d) < ax + b < cx + d 先画草图确定几处相交，再解边界交点读高低区域！
📘 例题 4.2 · 图像法解 |3x − 6| < x + 2 与平方法解 |2x − 1| ≥ |x + 3|

(a) Solve |3x − 6| < x + 2.
(b) Solve |2x − 1| ≥ |x + 3|.

解析 (Solution)：
(a) 方法 1（图像法）：作 V 字 y = |3x − 6|（顶点 (2, 0)）与直线 y = x + 2。求交点：
• 左支 6 − 3x = x + 2 ⇒ 4x = 4 ⇒ x = 1（交点 (1, 3)）；
• 右支 3x − 6 = x + 2 ⇒ 2x = 8 ⇒ x = 4（交点 (4, 6)）。
从图 4-1 左图看出，V 字线严格位于直线下方的部分在两交点之间：1 < x < 4。
（验证代数夹心法：−(x + 2) < 3x − 6 < x + 2 ⇒ x > 1 且 x < 4 ⇒ 1 < x < 4 ✓）
(b) 两边均有绝对值，直接平方并用平方差分解：
(2x − 1)² ≥ (x + 3)² ⇒ [(2x − 1) − (x + 3)][(2x − 1) + (x + 3)] ≥ 0
(x − 4)(3x + 2) ≥ 0，临界值 x = −23 与 x = 4。开口向上取两翼：
x ≤ −23 or x ≥ 4。

4.3 三次多项式及其绝对值图像草图 (Graphs of Cubics & their Moduli)

4.3.1 零点重数与三次绝对值 y = |ax³ + bx² + cx + d| 画图五步法

  • 首项符号决定走向：若 x³ 系数 a > 0，曲线从左下 (−∞) 进、右上 (+∞) 出；若 a < 0，则从左上 (+∞) 进、右下 (−∞) 出。
  • 因式重数决定穿轴形态：
    • 单根 (x − r)：直接干净穿过 x 轴（翻折后变成尖点 Cusp）；
    • 二重根 (x − r)²：在 (r, 0) 处相切弹回（Tangent bounce，不穿过 x 轴！）；
    • 三重根 (x − r)³：在 (r, 0) 处水平拐点穿过（Point of inflection）。
  • 套绝对值 y = |f(x)|：将全部 y < 0 段沿 x 轴向上翻折；务必标出所有 x 轴截距与翻折后的 y 轴截距 (0, |f(0)|)！
📘 例题 4.3 · 含重根的三次绝对值草图与 |f(x)| = k 根数讨论

Let g(x) = (x + 2)(x − 1)² (which has a local maximum at (−1, 4)).
(a) Sketch y = |g(x)|, labelling all axial intercepts and stationary points.
(b) State the range of values of k for which |g(x)| = k has 4 distinct real solutions.

解析 (Solution)：
(a) g(x) 首项系数 +1 > 0，故在 x < −2 处位于 x 轴下方，于 (−2, 0) 穿过 x 轴上升到极值点 (−1, 4)，经过 y 轴截距 (0, 2)，然后在二重根 (1, 0) 处相切弹回进入正半轴。
套上绝对值后：仅 x < −2 这一支负射线翻折到 x 轴上方，于 (−2, 0) 形成尖角（见图 4-2 右图）。
(b) 观察水平线 y = k：当 0 < k < 4 时，直线依次穿过翻折左支 (1)、上升段 (1)、下降段 (1)、右支 (1)，共 4 个相异交点！

4.4 图像法解三次不等式 (Solving Cubic Inequalities Graphically)

Factorising to Zero, Wavy-Curve Sign Sketch & Repeated-Root Inclusion/Exclusion Traps
Paper 1 必考大题 重根孤立点陷阱

4.4.1 三次不等式的“草图读正负”规则与重根坑

  1. 先移项归零：将所有项移到左边形成 P(x) > 0 或 P(x) ≤ 0（可结合 Ch 3 因式定理分解出 a(x − r₁)(x − r₂)(x − r₃)）；
  2. 画三次曲线草图：从右上或右下起步（看首项符号），注意单根穿过、重根相切不穿轴！
  3. 按不等号读取区间：> 0 读 x 轴上方区间，< 0 读 x 轴下方区间。
📘 例题 4.4 · 含三个单根与含二重根的三次不等式精确解集

(a) Solve x³ + 4x ≤ 5x².
(b) Solve (x + 2)(x − 1)² ≤ 0 and compare with (x + 2)(x − 1)² > 0.

解析 (Solution)：
(a) 移项分解：x³ − 5x² + 4x ≤ 0 ⇒ x(x² − 5x + 4) ≤ 0 ⇒ x(x − 1)(x − 4) ≤ 0。
三根为 0, 1, 4，首项系数 +1 > 0（右下起左穿：负→正→负→正），取 ≤ 0：
x ≤ 0 or 1 ≤ x ≤ 4。
(b) 对于 (x + 2)(x − 1)² ≤ 0：因 (x − 1)² ≥ 0 恒非负，曲线在 x < −2 时为负，在 x = −2 和 x = 1 处为 0！
• (x + 2)(x − 1)² ≤ 0 的解：x ≤ −2 or x = 1（千万别漏掉孤立点 x = 1！）；
• (x + 2)(x − 1)² > 0 的解：x > −2, x ≠ 1（即 −2 < x < 1 or x > 1，严格大于 0 时必须挖掉 x = 1！）。

4.5 隐含二次代换方程 (Complex / Disguised Quadratic Equations)

Substitution u = x², √x, x^(1/3), 2ˣ & Domain Constraints on u
Paper 1/2 压轴必考 代换后 u 的正负取舍

4.5.1 五大高频换元伪装形态与 u 值域守则

常见方程外观 换元设定 u 对 u 的固有正负限制（关键舍根！）
ax⁴ + bx² + c = 0 u = x² u ≥ 0（若 u < 0 舍去；若 u > 0 得 x = ±√u 两个解！）
ax + b√x + c = 0 u = √x = x1/2 u ≥ 0（算术平方根永不为负！负 u 必舍，正 u 平方得 x = u²）
ax2/3 + bx1/3 + c = 0 u = x1/3 u ∈ ℝ（正负皆可！）（立方根可为负！最后立方得 x = u³）
ax⁻² + bx⁻¹ + c = 0 u = x⁻¹ = 1x u ≠ 0（解得 u 后取倒数 x = 1u）
k·a²ˣ + b·aˣ + c = 0 u = aˣ (a > 0) u > 0（指数恒严格正！u ≤ 0 一律舍去）
📘 例题 4.5 · 指数、分数指数与根式三类代换真题示范

Solve exactly:
(a) 22x+1 − 9(2ˣ) + 4 = 0
(b) 2x2/3 + 3x1/3 − 2 = 0
(c) x − √x − 6 = 0

解析 (Solution)：
(a) 拆幂指数：22x+1 = 2 · (2ˣ)²。设 u = 2ˣ（u > 0）：
2u² − 9u + 4 = 0 ⇒ (2u − 1)(u − 4) = 0 ⇒ u = 12 或 u = 4。
2ˣ = 2⁻¹ ⇒ x = −1；2ˣ = 2² ⇒ x = 2。解为 x = −1, 2。
(b) 设 u = x1/3：2u² + 3u − 2 = 0 ⇒ (2u − 1)(u + 2) = 0 ⇒ u = 12 或 u = −2。
因为三次根号允许为负，两边同时立方：x = (12)³ = 18 或 x = (−2)³ = −8。解为 x = 18, −8。
(c) 设 u = √x（必须 u ≥ 0）：
u² − u − 6 = 0 ⇒ (u − 3)(u + 2) = 0 ⇒ u = 3 或 u = −2。
由于 √x ≥ 0，舍去 u = −2！故 √x = 3 ⇒ x = 9。

⚠️ 易错对比：x^(1/3) = −2 有解 (x = −8)，而 x^(1/2) = −2 无解！

很多同学学了 u = √x ≥ 0 后，在 x1/3 = −2 时也误把负值舍去！记住：偶次根式 x1/2, x1/4 必须非负，奇次根式 x1/3 可以取负数！

When solving |ax + b| = cx + d, what condition must every final solution satisfy?

Every valid solution must satisfy cx + d ≥ 0; any root yielding cx + d < 0 is extraneous and must be rejected.

Both moduli are non-negative, so squaring preserves the inequality sign. For |ax + b| < cx + d, use −(cx + d) < ax + b < cx + d or sketch V-graph below line to avoid extraneous branches.

Describe the end behavior of y = ax³ + bx² + cx + d for a > 0 vs a < 0.
描述三次函数首项系数 a > 0 与 a < 0 时的左右端走势。
👆 点击查看参考答案
a > 0: starts bottom-left (x→−∞, y→−∞) and ends top-right (x→+∞, y→+∞). a < 0: starts top-left (y→+∞) and ends bottom-right (y→−∞).
C06 · 4.3 Root MultiplicitySketching
How does the graph behave at (r, 0) for a single factor (x − r), double factor (x − r)², and triple factor (x − r)³?
单重根、二重根和三重根处三次曲线分别怎样与 x 轴相交？

Single (x − r): crosses cleanly; Double (x − r)²: touches tangentially and bounces back (turning point); Triple (x − r)³: horizontal point of inflection crossing the axis.

Which key features must always be labelled on a sketch of y = |cubic| in Paper 1?

C08 · 4.4 Repeated Root TrapInequality
Contrast the solutions of (x − a)(x − b)² > 0, ≤ 0, and < 0 (where a < b).
对比 (x − a)(x − b)²（其中 a < b）大于 0、小于等于 0、严格小于 0 时的重根取舍差异。
👆 点击查看参考答案
> 0: x > a, x ≠ b (exclude b); ≤ 0: x ≤ a or x = b (include isolated zero b!); < 0: x < a only.

Rewrite 2^(2x+1) in terms of u = 2ˣ and state the domain restriction on u.

👆 点击查看参考答案
2^(2x+1) = 2¹ · (2ˣ)² = 2u², with strict constraint u > 0 (reject any u ≤ 0).
C10 · 4.5 Square Root vs Cube RootSign Trap
Why is u = −2 rejected for u = x^(1/2) = √x, yet kept for u = x^(1/3)?
为什么当换元得出 u = −2 时，u = √x 必须舍去而 u = x^(1/3) 却可以保留？
👆 点击查看参考答案
Principal square root x^(1/2) = √x ≥ 0 is never negative, whereas cube root x^(1/3) can be negative (e.g. (−8)^(1/3) = −2 ⇒ x = −8).
C11 · 4.5 BiquadraticRoot Count
When substituting u = x² into ax⁴ + bx² + c = 0, how many real x-values come from each positive u?
用 u = x² 解双二次方程时，每个正数根 u > 0 会还原出几个 x ？
👆 点击查看参考答案
Each u > 0 produces two roots x = ±√u; u = 0 gives x = 0; any u < 0 gives no real roots.
C12 · 4.5 Reciprocal EquationAlgebra
How do you convert 3x − 5/x = 14 or 3x⁻² − 5x⁻¹ − 2 = 0 into a quadratic?
遇到 3x − 5/x = 14 或 3x⁻² − 5x⁻¹ − 2 = 0 时如何快速化成二次方程？
👆 点击查看参考答案
For 3x − 5/x = 14 (x ≠ 0), multiply through by x to get 3x² − 14x − 5 = 0. For negative powers, substitute u = x⁻¹ (u ≠ 0) to form 3u² − 5u − 2 = 0, then take reciprocals x = 1/u.
