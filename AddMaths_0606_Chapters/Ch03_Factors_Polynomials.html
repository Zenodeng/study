3.1 多项式加减乘与恒等式比较 (Adding, Subtracting & Multiplying Polynomials)

Degree of a Polynomial, Targeted Coefficient Extraction & Polynomial Identities (≡)
Paper 1 基础运算 系数比较法底层原理

3.1.1 多项式的严格定义、次数与“定点抽项”乘法

多项式 (Polynomial) 是形如 P(x) = anxⁿ + an−1xⁿ⁻¹ + ... + a₁x + a₀（an ≠ 0）的代数式，其中指数 n 必须是非负整数 (0, 1, 2, 3, ...)。因此像 2x = 2x⁻¹ 或 √x = x1/2 都不是多项式！

次数法则：deg(P · Q) = deg(P) + deg(Q)  |  恒等号 (≡)：两个多项式恒等 ⇔ 所有同次幂系数一一相等

Paper 1 速算技巧（定点抽项）：当题目只问乘积中某一项（如 x²）的系数时，不要全部展开，只把能凑出 x² 的几对相乘相加即可！

📘 例题 3.1 · 乘积定点抽项与多项式恒等式求参

(a) Find the coefficient of x² in the expansion of (2x² − 3x + 5)(x² + 4x − 1).
(b) Given 2x³ + px² + qx − 6 ≡ (x − 2)(2x² + 5x + r) for all x, find p, q and r.

解析 (Solution)：
(a) 只找乘积为 x² 的配对：
(2x²)(−1) + (−3x)(4x) + 5(x²) = (−2 − 12 + 5)x² = −9x² ⇒ x² 系数为 −9。
(b) 对比常数项：−6 = −2r ⇒ r = 3。
对比 x² 系数：p = 5 − 2(2) = 1。
对比 x 系数：q = r − 2(5) = 3 − 10 = −7。

3.2 多项式除法：长除法与比较系数法 (Division of Polynomials)

Algebraic Long Division with 0x² Placeholders, Comparing Coefficients & Quadratic Divisors
Paper 1 必会基本功 缺项补 0 铁律

3.2.1 多项式带余除法恒等式与两种等价解法

P(x) ≡ Divisor(x) · Quotient(x) + Remainder(x)   （其中 deg(Remainder) < deg(Divisor)）

• 除式是一次式 (ax + b) ⇒ 余数是一个常数 R；
• 除式是二次式 (ax² + bx + c) ⇒ 余数是一次式 px + q（最多一次！）。

📘 例题 3.2A · 双法对比：除以一次式（注意缺项补 0x²！）

Divide 2x³ − 3x + 5 by (x − 2) to find the quotient and remainder.

解法 1（待定系数比较法，Paper 1 最稳最快）：
设 2x³ + 0x² − 3x + 5 ≡ (x − 2)(ax² + bx + c) + R：
• 对比 x³：a = 2；
• 对比 x²：0 = b − 2a = b − 4 ⇒ b = 4；
• 对比 x¹：−3 = c − 2b = c − 8 ⇒ c = 5；
• 对比常数：5 = −2c + R = −10 + R ⇒ R = 15。
解法 2（长除法验证）：按降幂写齐 2x³ + 0x² − 3x + 5，逐列相减（详见图 3-1）。
结论：商式 Quotient = 2x² + 4x + 5，余数 Remainder = 15。

📘 例题 3.2B · 四次多项式除以二次多项式（产生一次余式！）

Find the quotient and remainder when x⁴ + 2x³ − 5x + 1 is divided by x² − x + 2.

解析 (Solution)：
设 x⁴ + 2x³ + 0x² − 5x + 1 ≡ (x² − x + 2)(ax² + bx + c) + (px + q)。
• x⁴：a = 1；
• x³：2 = b − a ⇒ b = 3；
• x²：0 = c − b + 2a = c − 3 + 2 ⇒ c = 1；
• x¹：−5 = −c + 2b + p = −1 + 6 + p ⇒ p = −10；
• 常数：1 = 2c + q = 2 + q ⇒ q = −1。
结果：Quotient = x² + 3x + 1，Remainder = −10x − 1。

3.3 因式定理 (The Factor Theorem)

Linear Factor (ax − b) ⇔ P(b/a) = 0, Finding Unknown Constants & Rational Root Trials
Paper 1 核心定理

3.3.1 因式定理通用版与无计算器快速试根策略

(x − a) 是 P(x) 的因式 ⇔ P(a) = 0   |   通用版：(ax − b) 是 P(x) 的因式 ⇔ P(ba) = 0

Paper 1 试根规律：对于整系数多项式 ax³ + bx² + cx + d，有理根 pq 必满足：分子 p 整除常数项 d，分母 q 整除首项系数 a！考场优先试 x = ±1, ±2, ±3，若首项不为 1 再试分数 ±12, ±13。

📘 例题 3.3 · 已知两个一次因式反求未知系数并彻底分解

The polynomial P(x) = 2x³ + ax² + bx − 6 has factors (2x − 1) and (x + 2). Find a and b, and hence factorise P(x) completely.

解析 (Solution)：
令 2x − 1 = 0 ⇒ x = 12；令 x + 2 = 0 ⇒ x = −2。
由因式定理：
• P(12) = 2(18) + a(14) + b(12) − 6 = 0（两边乘 4）：1 + a + 2b − 24 = 0 ⇒ a + 2b = 23 ①
• P(−2) = 2(−8) + 4a − 2b − 6 = 0 ⇒ 4a − 2b = 22 ②
① + ②：5a = 45 ⇒ a = 9；代回 ① 得 2b = 14 ⇒ b = 7。
于是 P(x) = (2x − 1)(x + 2)(kx + c) = (2x² + 3x − 2)(kx + c)。对比首项 2k = 2 ⇒ k = 1，常数项 −2c = −6 ⇒ c = 3。
彻底分解：P(x) = (2x − 1)(x + 2)(x + 3)。

⚠️ 易错警报：用 (2x + 3) 除却代入 x = +3/2 或 x = −3！

找代入值永远先令除式等于 0 解方程：2x + 3 = 0 ⇒ x = −32。正负号一旦错，满盘皆输！

3.4 三次式因式分解与三次方程求根 (Cubic Expressions & Equations)

3-Step Cubic Solving Workflow, Exact Surd Roots & Proving "Only One Real Root"
Paper 1 必考题型 二次因式判别式判定实根数

3.4.1 三次方程求解三步走与非有理根处理

  1. 试根定一因式：代入简单整数/分数找到一个 P(ba) = 0，写出一次因式 (ax − b)；
  2. 降次为二次：用比较系数法或长除法写出 P(x) = (ax − b)(Ax² + Bx + C)；
  3. 处理二次因式 Ax² + Bx + C = 0：
    • 若 Δ = B² − 4AC 为完全平方数 ⇒ 拆为 3 个一次因式；
    • 若 Δ > 0 但非完全平方数 ⇒ 用求根公式保留最简根式（Paper 1）；
    • 若 Δ < 0 ⇒ 明确写明 B² − 4AC < 0，证明二次因式无实根，从而原三次方程仅有一个实根！
📘 例题 3.4 · 含三个有理根、含根式根与“仅有一实根”三类母题

(a) Solve 2x³ − 3x² − 11x + 6 = 0.
(b) Solve x³ − 4x² + 2x + 4 = 0, giving exact answers.
(c) Show that x³ − 2x² + 3x − 6 = 0 has only one real root.

解析 (Solution)：
(a) 试根 x = 3：2(27) − 3(9) − 33 + 6 = 54 − 27 − 33 + 6 = 0 ⇒ (x − 3) 是因式。
比较系数得：(x − 3)(2x² + 3x − 2) = 0 ⇒ (x − 3)(2x − 1)(x + 2) = 0。
三根为：x = −2, 12, 3。
(b) 试根 x = 2：8 − 16 + 4 + 4 = 0 ⇒ (x − 2) 是因式。
分解：(x − 2)(x² − 2x − 2) = 0。
二次式用求根公式：x = 2 ± √4 + 82 = 1 ± √3。
全部实根：x = 2, 1 + √3, 1 − √3。
(c) 分组或试根得 (x − 2)(x² + 3) = 0。对于 x² + 3 = 0，判别式 Δ = 0² − 4(1)(3) = −12 < 0（且 x² ≥ 0 ⇒ x² + 3 ≥ 3 > 0），无实根。因此 x = 2 是唯一实根。

3.5 余数定理与重线性因式 (Remainder Theorem & Repeated Factors)

Remainder P(b/a), Quadratic Divisor Remainder Ax + B & Repeated Factor (x − a)²
Paper 1 压轴高频 交互实验室在本节

3.5.1 余数定理、二次除式余式与重因式 (x − a)² 的两种处理方法

1. 线性余数：P(x) 除以 (ax − b) 的余数 R = P(ba)
2. 二次除式余数：P(x) ≡ (x − α)(x − β)Q(x) + Ax + B ⇒ 代入 x = α, β 解联立方程求 A, B

3. 重线性因式 (Repeated Linear Factor) (x − a)²：
• 系数比较法（Ch 3 首选）：直接设 P(x) = (x − a)²(px + q) 展开对比系数；或先用 P(a) = 0 求出商式 Q(x)，再用一次 Q(a) = 0！
• 微积分拓展（学完 Ch 12 后可秒杀）：(x − a)² 是因式 ⇔ P(a) = 0 且一阶导数 P'(a) = 0！

📘 例题 3.5A · 除以二次式 (x − 1)(x + 2) 求一次余式参数

When P(x) = x⁴ + ax² + bx + 3 is divided by (x − 1)(x + 2), the remainder is 2x + 5. Find a and b.

解析 (Solution)：
写出除法恒等式：x⁴ + ax² + bx + 3 ≡ (x − 1)(x + 2)Q(x) + (2x + 5)。
无需知道商式 Q(x)，直接取使除式归零的 x = 1 和 x = −2：
• x = 1：1 + a + b + 3 = 2(1) + 5 ⇒ a + b = 3 ①
• x = −2：16 + 4a − 2b + 3 = 2(−2) + 5 ⇒ 4a − 2b = −18 ⇒ 2a − b = −9 ②
① + ②：3a = −6 ⇒ a = −2，代回 ① 得 b = 5。

📘 例题 3.5B · 含重因式 (x − 2)² 的三次多项式待定系数

Given that (x − 2)² is a factor of P(x) = x³ + px² + qx + 12, find p and q.

解析 (Solution)：
设 x³ + px² + qx + 12 ≡ (x − 2)²(x + c) = (x² − 4x + 4)(x + c)。
展开右边：x³ + (c − 4)x² + (4 − 4c)x + 4c。
对比常数项：4c = 12 ⇒ c = 3。
从而：p = c − 4 = 3 − 4 = −1；q = 4 − 4(3) = −8。

SME 1 · 因式与余数定理联立求参 + 彻底分解[8 marks]
Let P(x) = 2x³ + ax² + bx + 6. Given that (x − 2) is a factor of P(x) and that the remainder when P(x) is divided by (x + 1) is 18:
(a) Find the values of a and b. [4]
(b) Factorise P(x) completely, and hence solve P(x) = 0. [4]
无计算器：联立求参数后再做三次因式分解与求解。
查看评分细则 (Mark Scheme · 8 Marks)

M1 (a) P(2) = 16 + 4a + 2b + 6 = 0 ⇒ 2a + b = −11.
M1 P(−1) = −2 + a − b + 6 = 18 ⇒ a − b = 14.
M1 Add equations: 3a = 3 ⇒ A1 a = 1, b = −13.

M1 (b) 2x³ + x² − 13x + 6 = (x − 2)(2x² + 5x − 3) (A1).
M1 Factorise quadratic: (x − 2)(2x − 1)(x + 3).
A1 Roots: x = −3, 12, 2.

SME 2 · 三次方程求精确根式解[6 marks]
The polynomial Q(x) = x³ − 5x² + 4x + 4.
(a) Show that (x − 2) is a factor of Q(x). [1]
(b) Solve Q(x) = 0, giving all solutions in exact form. [5]
无计算器：试根分解后对不可因式分解的二次因式使用求根公式并化简。
查看评分细则 (Mark Scheme · 6 Marks)

B1 (a) Q(2) = 2³ − 5(2²) + 4(2) + 4 = 8 − 20 + 8 + 4 = 0, hence (x − 2) is a factor.

M1 (b) Divide by (x − 2) (or compare coefficients): Q(x) = (x − 2)(x² − 3x − 2) (A1).

M1 Solve x² − 3x − 2 = 0: x = 3 ± √(−3)² − 4(1)(−2)2 = 3 ± √172 (A1).
A1 Exact roots: x = 2, 3 + √172, 3 − √172.

SME 3 · 四次式除以二次因式求余数系数[6 marks]
When f(x) = x⁴ + 3x³ + px + q is divided by (x − 2)(x + 1), the remainder is 5x − 3.
(a) Find the values of p and q. [5]
(b) Hence state the remainder when f(x) is divided by (x − 2). [1]
无计算器：写出 f(x) = (x − 2)(x + 1)Q(x) + 5x − 3，代零点秒杀双参数。
查看评分细则 (Mark Scheme · 6 Marks)

M1 (a) f(x) ≡ (x − 2)(x + 1)Q(x) + (5x − 3).
M1 Set x = 2: 16 + 24 + 2p + q = 5(2) − 3 = 7 ⇒ 2p + q = −33.
M1 Set x = −1: 1 − 3 − p + q = 5(−1) − 3 = −8 ⇒ −p + q = −6.
M1 Subtract: 3p = −27 ⇒ A1 p = −9, q = −15.

B1 (b) Remainder by (x − 2) is f(2) = 5(2) − 3 = 7.

SME 4 · 待定系数 + 证明三次方程唯一实根[6 marks]
The polynomial P(x) = 2x³ − 3x² + ax − 6 has (x − 2) as a factor.
(a) Find the value of a. [2]
(b) Factorise P(x) as a linear factor times a quadratic factor, and prove that P(x) = 0 has only one real root. [4]
无计算器：求参分解后必须计算二次因式判别式来严谨完成“唯一实根”证明。
查看评分细则 (Mark Scheme · 6 Marks)

M1 (a) P(2) = 16 − 12 + 2a − 6 = 0 ⇒ 2a − 2 = 0 ⇒ A1 a = 1.

M1 (b) Divide 2x³ − 3x² + x − 6 by (x − 2): P(x) = (x − 2)(2x² + x + 3) (A1).
M1 For 2x² + x + 3 = 0, discriminant Δ = 1² − 4(2)(3) = −23 < 0, so 2x² + x + 3 = 0 has no real roots.
A1 Therefore x = 2 is the only real root of P(x) = 0.

C01 · 3.1 PolynomialDefinition
What exponents are permitted in a polynomial, and why are 1/x and √x not polynomials?
多项式对未知数的幂次有何严格规定？为什么 1/x 与 √x 不是多项式？

All powers of x must be non-negative integers (0, 1, 2, ...). Terms like x⁻¹ or x^(1/2) have negative or fractional exponents, so they are not polynomials.
C02 · 3.1 IdentityPrinciple
What does the identity sign ≡ tell you when comparing two polynomials?
恒等号 ≡ 在比较两个多项式时给你什么直接操作权？
👆 点击查看参考答案
Two polynomials are identical for all x if and only if the coefficients of every corresponding power of x are equal (method of equating coefficients).
C03 · 3.2 Division IdentityFormula
State the polynomial division identity and the rule linking the degrees of Divisor and Remainder.
写出多项式带余除法恒等式，并说明余式与除式次数的关系。
👆 点击查看参考答案
P(x) ≡ D(x)·Q(x) + R(x), where deg(R) < deg(D) (e.g. quadratic divisor leaves linear remainder Ax + B).

State the generalised Factor Theorem for a linear divisor (ax − b).
默写一般一次式 (ax − b) 的因式定理。
👆 点击查看参考答案
(ax − b) is a factor of polynomial P(x) if and only if P(b/a) = 0 (set ax − b = 0 to find the test value).

C09 · 3.5 Remainder TheoremTheorem
State the Remainder Theorem when P(x) is divided by (ax + b).
写出 P(x) 除以一次式 (ax + b) 时的余数定理。
👆 点击查看参考答案
When P(x) is divided by (ax + b), the constant remainder equals P(−b/a).
C10 · 3.5 Quadratic DivisorMethod
How do you find the linear remainder R(x) = Ax + B when P(x) is divided by (x − α)(x − β)?
当 P(x) 除以二次式 (x − α)(x − β) 时，如何不求出商 Q(x) 就直接算出一次余式 Ax + B？
👆 点击查看参考答案
Write P(x) ≡ (x − α)(x − β)Q(x) + Ax + B, then substitute x = α and x = β so Q(x) vanishes, solving P(α) = Aα + B and P(β) = Aβ + B.
C11 · 3.5 Repeated FactorAlgebra
Give two algebraic methods (without calculus) when (x − a)² is given as a factor of cubic P(x).
已知 (x − a)² 是三次式 P(x) 的重因式，不用微积分时有哪两种代数解法？
👆 点击查看参考答案
Method ① Write P(x) ≡ (x − a)²(px + q) and equate coefficients; Method ② Use P(a) = 0, divide by (x − a) to get Q(x), then set Q(a) = 0.
C12 · 3.5 Factor vs RemainderDistinction
If P(x) leaves the same remainder when divided by (x − 1) and (x + 3), what equation do you form?
题目若说“P(x) 除以 (x − 1) 与 (x + 3) 余数相同”，第一步应写出什么等式？
👆 点击查看参考答案
By the Remainder Theorem, equate the two remainders directly: P(1) = P(−3).
