log / ln / e 与三次函数图像怎么画

画图题（sketch）不用精确描点，但必须标出：渐近线、截距、关键点、增减趋势、三次函数的根与两端趋势。缺一个就可能扣分。

图 1 · y = eˣ 与 y = ln x：关于 y = x 对称

怎么画，一步步来

  • y = eˣ：定义域全体实数，值域 y > 0，渐近线 y = 0（x 轴），过 (0,1)，递增，永远碰不到 x 轴。
  • y = ln x：定义域 x > 0，值域全体实数，渐近线 x = 0（y 轴），过 (1,0)，递增，永远碰不到 y 轴。
  • 互为反函数：把 eˣ 上的点 (a,b) 对换成 (b,a) 就得到 ln x 上的点：(0,1) ↔ (1,0)，(1,e) ↔ (e,1)，渐近线 y=0 ↔ x=0。画的时候把虚线 y = x 也画出来。
  • 变式：y = ln(x−2)：渐近线移到 x=2，定义域 x>2，过 (3,0)。y = eˣ+2：渐近线移到 y=2，值域 y>2，过 (0,3)。y = e^(−x)：递减，但渐近线还是 y=0。
常见错误：把 ln x 画到 y 轴左侧（定义域错了）；把 eˣ 画成碰到 x 轴；把反函数画成上下翻转（那是 y = −f(x)，不是反函数）。

图 2 · 三次函数：先找根，再看两端

例：y = (x−1)(x−3)(x+2) = x³ − 2x² − 5x + 6

画三次函数的四步

  • 1. 找根（x 截距）：令每个括号等于 0，得 x = −2，1，3。单根都要穿过 x 轴。
  • 2. 找 y 截距：令 x = 0，得 y = (−1)(−3)(2) = 6，过 (0,6)。
  • 3. 看两端趋势：首系数 a > 0，次数 3 是奇数，所以左端向下（x→−∞，y→−∞），右端向上（x→+∞，y→+∞）。如果 a < 0，就反过来：左端向上，右端向下。
  • 4. 连线：按从左到右的顺序穿过三个根，中间起伏一下，不用算极值点（0606 期中考这个阶段不要求用导数求极值），只要根、截距、两端趋势对了，草图就对了。
如果三次式没有分解成因式，先因式分解（试根 + 综合除），再按上面四步画。Δ 在这里不直接决定图像形状，根的个数和重数才决定。

图 3 · 三次函数有重根：相切不穿过

例：y = (x−1)²(x+2) = x³ − 3x + 2

  • 单根 x = −2：穿过 x 轴，图像在该点两侧变号。
  • 二重根 x = 1：在 (1,0) 处与 x 轴相切，只碰一下不穿过，图像在该点两侧不变号。
  • y 截距：x = 0 时 y = 2，过 (0,2)。两端趋势和图 2 一样：左下右上。
重根只算一个交点位置，但画图时一定要画成“碰一下就回去”，画成穿过就错了。三重根则会穿过，但比单根“平”一些，期中考一般只考单根和二重根的区分。

三类图像的检查清单

  • log / ln：渐近线是竖直的吗？定义域在渐近线哪一侧？x 截距是真数等于 1 的点吗？有 y 截距吗？（ln x 没有）
  • eˣ：渐近线是水平的吗？y 截距是 (0,1) 平移后的点吗？有 x 截距吗？（eˣ 本身没有，平移后可能有）
  • 三次：根都标了吗？重根画成相切了吗？y 截距算了吗？左端和右端方向和首系数、奇偶次数对得上吗？

logₐ x（a>1）形状和 ln x 一样，只是过 (a,1) 而不是 (e,1)，渐近线同样是 x=0；0<a<1 时递减，考试里一般只画 a>1 的情况。
