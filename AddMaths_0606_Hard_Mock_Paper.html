B2 · [7]

(a) mx + 4 = x² − 2x + 5，移项得 x² − (m + 2)x + 1 = 0。
(b) Δ = (m + 2)² − 4 = m² + 4m = 0，得 m = 0 或 m = −4。
(c) Δ > 0，即 m(m + 4) > 0，得 m > 0 或 m < −4。
(d) m = 0 时 x² − 2x + 1 = 0，x = 1，y = 4，得 (1, 4)；m = −4 时 x² + 2x + 1 = 0，x = −1，y = 8，得 (−1, 8)。

B3 · [6]

(a) 5√3 − 4√3 + 3√3 = 4√3。
(b) 5(2 + √3) / (4 − 3) = 10 + 5√3。
(c) 平方得 x + 5 = x² − 2x + 1，即 x² − 3x − 4 = 0，x = 4 或 x = −1。检验：x = −1 时右边 −2，左边 ≥ 0，舍去。所以 x = 4。

B8 · [6]

(a) 平方或分两种情况：3x − 1 = x + 5 得 x = 3；3x − 1 = −(x + 5) 得 x = −1。检验都成立，所以 x = 3 或 x = −1。
(b) −5 ≤ x² − 4 ≤ 5，得 x² ≤ 9 且 x² ≥ −1（恒成立），所以 −3 ≤ x ≤ 3。

B9 · [8]

(a) 根号要求 x ≥ −3，分母要求 x ≠ 1，所以定义域是 [−3, 1) ∪ (1, ∞)，即 x ≥ −3 且 x ≠ 1。
(b) g(x) = (x − 2)² + 1，顶点 (2, 1)，在 0 ≤ x ≤ 4 内，端点 g(0) = g(4) = 5，所以值域是 1 ≤ y ≤ 5。
(c) x ≥ 2 时，y = (x − 2)² + 1，x − 2 = √(y − 1)（取正根，因为 x − 2 ≥ 0），所以 g−1(x) = 2 + √(x − 1)，x ≥ 1。
