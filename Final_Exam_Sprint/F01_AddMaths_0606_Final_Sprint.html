1.2 Paper 1 无计算器（2025+）四大核心硬功夫

Paper 1（80 分 · 2 小时）严禁使用计算器，所有最终答案必须保留最简根式、精确分数、π、e 或 ln 表达式。考前务必把下面四项手算练到零失误：

① 根式化简与分母有理化 (Surds)
• 拆最大完全平方数：√48 = √16×3 = 4√3；√72 = 6√2；√160 = 4√10。
• 共轭有理化：6√5 − √2 = 6(√5 + √2)5 − 2 = 2(√5 + √2)。
② 特殊角三角值（弧度 rad 必背）
• 0：sin=0, cos=1, tan=0；π2：sin=1, cos=0。
• π6 (30°)：sin=12, cos=√32, tan=1√3。
• π4 (45°)：sin=cos=√22, tan=1, sec²=2。
• π3 (60°)：sin=√32, cos=12, tan=√3, sec²=4。
③ 有理数试根 (Rational Root Trial)
• 对 aₙxⁿ + ··· + a₀ = 0，候选有理根 ±pq 满足 p | a₀ 且 q | aₙ。
• 考场顺序：先试 ±1, ±2, ±3，再试分数 ±½, ±⅓, ±⅔。找到一个根即长除降为二次！
④ 指数、对数与组合数心算
• 分数负幂：8−2/3 = (1∛8)² = 14；274/3 = 3⁴ = 81。
• 对数恒等：e2 ln 3 = eln 9 = 9；log₂(116) = −4；log₄ 8 = 32。
• 组合数对称：¹⁰C₈ = ¹⁰C₂ = 10×92 = 45。

1.3 Ch 1–6 高频母题解法模板精炼（含 Linear Law 与绝对值不等式）

图 1.1 · Ch 1–6 代数、函数、指对与直线线性化考场决策路由图
🔥 高频母题模板 A · Ch 1–2：反函数定义域与配方法/判别式联动

1. 分式反函数求域值：已知 f(x) = 2x + 1x − 3 (x > 3)。先做长除分离常数：f(x) = 2 + 7x − 3。因 x > 3 ⇒ 7x − 3 > 0，故 Range(f): y > 2。反解 y(x−3)=2x+1 ⇒ x(y−2)=3y+1，得 f⁻¹(x) = 3x + 1x − 2 (x > 2)（切忌只写 x ≠ 2！）。
2. 抛物线恒成立与直线不相交：若“直线 y = 2x + k 与曲线 y = x² − 4x + 7 无交点”，联立得 x² − 6x + (7 − k) = 0，令 Δ = 36 − 4(7 − k) < 0 ⇒ 8 + 4k < 0 ⇒ k < −2。若问“二次式 px² + 4x + p 恒正”，除 Δ < 0（得 p < −2 或 p > 2）外，必须附加首项系数 p > 0，最终仅保留 p > 2！

🔥 高频母题模板 B · Ch 3–4：三次因式分解与 |ax + b| < |cx + d| 平方降维

1. 含参三次多项式：已知 P(x) = 2x³ + ax² − 11x + b 有因式 (x − 2)，且除以 (x + 1) 余 6。由 P(2)=0 得 4a+b=6，由 P(−1)=6 得 a+b=−3，联立解得 a=3, b=−6。长除或比系数得 P(x) = (x−2)(2x²+7x+3) = (x−2)(2x+1)(x+3)（注：若二次因式不可再分，记得用 b²−4ac < 0 说明无实根）。
2. 双绝对值不等式 P1 无计算器秒杀法：解 |2x − 5| < |x + 4|。因两侧非负直接平方并用平方差：
(2x−5)² − (x+4)² < 0 ⇒ [(2x−5)−(x+4)][(2x−5)+(x+4)] < 0 ⇒ (x−9)(3x−1) < 0。
临界根 13 与 9，二次开口向上取中间，直接写 13 < x < 9！
⚠️ 对比单侧绝对值：解 |x − 4| = 2x − 5 得出 x = 1, 3 后，必须代入右边 2x − 5 检验：当 x=1 时右边为 −3 < 0 舍去，仅 x = 3 有效！

🔥 高频母题模板 C · Ch 5–6：对数验根、鞋带面积与 Linear Law 正反互推

1. 对数合并与增根淘汰：解 log₃(x − 1) + log₃(x − 3) = 1 ⇒ log₃[(x−1)(x−3)] = log₃ 3 ⇒ x² − 4x + 3 = 3 ⇒ x(x−4)=0 ⇒ x=0 或 4。检验定义域 x−3 > 0，舍去 x = 0，唯一解 x = 4。
2. Linear Law 逆推标准流程（从直线上两点推原方程参数）：
已知直线方程轴为纵轴 Y = lg y、横轴 X = x，过两点 (1, 3) 与 (3, 7)，原关系为 y = A · bˣ。
• Step 1（原式线性化）：两边取 lg 得 lg y = (lg b) x + lg A，识别 m = lg b，c = lg A。
• Step 2（直线算斜率截距）：m = 7 − 33 − 1 = 2；代入 (1, 3) 得 3 = 2(1) + c ⇒ c = 1。
• Step 3（还原指数/对数反解）：lg b = 2 ⇒ b = 100；lg A = 1 ⇒ A = 10。
四大常见 Linear Law 变形对照：
① y = axⁿ ⇒ lg y = n lg x + lg a（Y=lg y, X=lg x）； ② y = Abˣ ⇒ ln y = (ln b)x + ln A（Y=ln y, X=x）；
③ y = ax² + bx ⇒ yx = ax + b（Y=y/x, X=x）； ④ xy = ax + b ⇒ y = a + b(1x)（Y=y, X=1/x 或 Y=xy, X=x）。

🚨 Ch 1–6 考场高频“0 分红线”提醒
  • 绝不把 logₐ(M + N) 拆成 logₐ M + logₐ N，也不把 lg A / lg B 写成 lg(A − B)！
  • 直线截距看清横坐标起点：若考卷坐标图横轴从 X = 1 或 X = 2 开始画，纵轴与直线交点不是截距 c！必须代入 Y − Y₁ = m(X − X₁) 计算 X = 0 时的 c！
  • 多边形鞋带面积 (Shoelace)：按顺时针或逆时针顺序排好顶点（最后一列再写回起点），Area = ½|向右下乘积和 − 向左下乘积和|，别漏绝对值与 ½！

2.1 Ch 10 排列组合：捆绑、插空、数字首位与“正难则反”模板

解题第一步永远先问：“调换两个选出对象的位置，算不算新方案？” 算 ⇒ 排列（ⁿPᵣ）；不算 ⇒ 组合（ⁿCᵣ）。若既有“选”又有“排”，铁律是 先选（C）后排（P）！

高频约束题型 核心解法模型 经典母题示范（Paper 1 手算）
相邻捆绑 (Together) 把必相邻的 k 个元素绑成 1 个大整体，算出 外部全排列 × 内部排列 4 男 3 女排成一排，3 名女生必须站在一起：把女生绑成 1 块，共 5 块全排 5!，内部女生互换 3! ⇒ 120 × 6 = 720。
不相邻插空 (Separated) 先排无约束元素形成 m + 1 个空位（含两端），再把需隔开的元素用 ⁿPᵣ 插入空位 4 男 3 女排成一排，任意两名女生不相邻：先排 4 男 (4!=24)，产生 5 个空位 _ B _ B _ B _ B _，3 女插空 ⁵P₃ = 60 ⇒ 24 × 60 = 1440。
含 0 奇数/偶数位限制 先定个位（奇偶）再定首位（非 0）；若 0 可作个位，必须拆分“末尾是 0”与“末尾非 0”两类！ 用 0,1,2,3,4,5 组无重复四位偶数：① 末位为 0：5×4×3×1 = 60；② 末位为 2 或 4 (2 选)：首位非 0 且非末位有 4 选，中间 4×3 ⇒ 4×4×3×2 = 96；共 156。
至少/至多 & 排斥组队 正难则反（补集法）：Total − 不合题意的少数情况（需仔细核对边界） 从 5 男 4 女选 4 人至少 1 男 1 女：总选法 ⁹C₄=126，减去全男 ⁵C₄=5 与全女 ⁴C₄=1 ⇒ 120。
含重复字母排列 先按全部不同作 n!，再除以各重复字母个数的阶乘 p! q! ··· 单词 STATISTICS（10 字母：3S, 3T, 2I）：总数 10!3! 3! 2!。

2.2 Ch 11 二项式定理与 AP / GP / S∞ 核心通关技

二项展开第 r + 1 项：Tᵣ₊₁ = ⁿCᵣ · aⁿ⁻ʳ · bʳ   |   数列第 n 项通用式：uₙ = Sₙ − Sₙ₋₁（u₁ = S₁）
  • 二项式三大失分坑：① b 为负号或分式时（如 −2x²），必须连负号一起加括号求 r 次方；② 求 Term independent of x（常数项）令 x 的合成指数 = 0，写出具体数值；③ 求 Coefficient of xᵏ 只答数字，不要把 xᵏ 带进最终答案！④ 两括号相乘如 (1+3x)(2−x/2)⁶ 求 x² 系数，先把右括号展开到 x² 项，再做交叉配对相乘相加。
  • AP 与 GP 高频考点：公式表已给出 uₙ, Sₙ, S∞，但考题专卡：① 给定 Sₙ = 3n² + 2n，直接用 u₁ = S₁ = 5 与 uₙ = Sₙ − Sₙ₋₁；② 证明或利用 AP 某几项同时成 GP，列等比中项 (u_mid)² = u_prev × u_next 并排除 d = 0；③ 无穷等比级数 S∞ = a1 − r 必须检验或解出 |r| < 1（即 −1 < r < 1）！

2.3 Ch 12 基础求导衔接速记 → Ch 14 复合指数/对数/三角求导

为确保你直接攻克 Ch 14 综合求导时零断层，下设 Ch 12 必备基础桥接 + Ch 14 三大函数导数与综合应用：

【Ch 12 衔接基石】 幂法则：(axⁿ)′ = anxⁿ⁻¹  |  链式：dydx = dydu · dudx  |  乘积：(uv)′ = uv′ + vu′  |  商法则：(uv)′ = vu′ − uv′v²
Ch 12 衔接必会 4 步：① 见分式/根号先拆成 axⁿ 再求导（如 3x² − 2√xx = 3x − 2x−1/2）；② 切线斜率 m_T = dydx，法线斜率 m_N = −1m_T；③ 驻点令 dydx = 0，用 d²ydx² > 0（极小）或 < 0（极大）判定，若 = 0 则改查左右一阶导符号；④ 微小增量 δy ≈ (dydx) δx，关联变化率 dydt = dydx · dxdt。
【Ch 14 进阶求导】 (eax+b)′ = aeax+b  |  [ln(ax+b)]′ = aax+b  |  (sin ax)′ = a cos ax  |  (cos ax)′ = −a sin ax  |  (tan ax)′ = a sec² ax
⚠️ 弧度红线：上述所有三角求导公式仅在 x 为弧度（rad）时成立！遇到 sec² ax 需要数值化时记住 sec θ = 1cos θ。

🔥 高频母题模板 D · Ch 14 指数驻点、对数“先拆后导”与三角切线（Paper 1）

1. 指数乘积求驻点与极值：已知 y = x² e−3x。
• 乘积法则：dydx = 2x e−3x + x²(−3e−3x) = x e−3x(2 − 3x)。

• 先用 Ch 5 对数律拆分：y = 2 ln(x + 1) − 12 ln(2x − 1)。

Q1 · Ch 1 函数与反函数 [2 marks]
The functions f and g are defined by f(x) = 3 − (x − 2)² for x ≥ 2, and g(x) = 2x + 1. State the domain of f⁻¹ and find fg(1).
已知 f(x) = 3 − (x − 2)²（x ≥ 2），g(x) = 2x + 1。求反函数 f⁻¹ 的定义域以及复合函数值 fg(1)。
查看 Mark Scheme 过程分拆解
B1由顶点 (2, 3) 开口向下，x ≥ 2 时 Range(f) ≤ 3，故 Domain(f⁻¹): x ≤ 3。
B1g(1) = 2(1)+1 = 3 ⇒ fg(1) = f(3) = 3 − (3−2)² = 2。
常见 0 分误区：错把 f 的定义域 x ≥ 2 直接写成 f⁻¹ 的定义域，或算反成 gf(1) = g(2) = 5。
Q2 · Ch 2 判别式与相切 [2 marks]
The straight line y = kx − 1 is a tangent to the curve y = x² + 3x + 8. Find the possible values of k.
直线 y = kx − 1 与曲线 y = x² + 3x + 8 相切，求常数 k 的所有可能值。
查看 Mark Scheme 过程分拆解
M1消去 y 得 x² + (3 − k)x + 9 = 0，置 b² − 4ac = 0 ⇒ (3 − k)² − 36 = 0。
A13 − k = ±6 ⇒ k = −3 或 k = 9。
常见丢分点：展开 (3−k)² 时算错符号或漏掉负根，导致丢掉一半 A1 分。
