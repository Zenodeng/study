Topic 0 · 前置基础：指数与根式运算

0.1 指数运算法则 (Laws of Indices)

am · an = am+n  |  am / an = am−n  |  (am)n = amn  |  a−n = 1an  |  ap/q = (q√a)p

0.2 根式化简与分母有理化 (Surds & Rationalising the Denominator)

  • 拆分完全平方因子：√72 = √36 × 2 = 6√2。
  • 单项分母有理化：分子分母同乘 √b。
  • 二项共轭分母有理化（Conjugate surd）：利用平方差 (a + √b)(a − √b) = a² − b，彻底消灭分母根号！
✍️ 典型例题 (Non-Calc P1)：将 14 − 4√32 + √3 化简为 a + b√3 的精确形式
  1. Step 1 乘共轭分母：分子分母同乘 (2 − √3)。
  2. Step 2 算分母：(2 + √3)(2 − √3) = 4 − 3 = 1。
  3. Step 3 展开分子：(14 − 4√3)(2 − √3) = 28 − 14√3 − 8√3 + 4(3) = 40 − 22√3。
⚠️ 高频扣分坑：根号不是线性算子！

严禁写出 √a² + b² = a + b 或 (a + √b)² = a² + b（漏掉中间交叉项 2a√b）！

Topic 1 · 函数、反函数与绝对值图像

Functions: Domain, Range, Composite fg(x), Inverse f⁻¹(x) & Modulus |f(x)|
Non-Calc (P1) Calc (P2) 核心必会

1.1 函数定义、定义域 (Domain) 与值域 (Range)

  • 什么是函数（Function）？每个输入 x（Domain）只能对应唯一一个输出 y（允许 One-to-One 或 Many-to-One；垂直线检验 Vertical line test 最多只能有一个交点）。一对多（One-to-Many）不是函数！
  • 定义域（Domain）：允许输入的 x 的集合（受分母 ≠ 0、偶次根号内 ≥ 0、对数真数 > 0 或题干给定区间限制）。
  • 值域（Range）：对应所有输出值 f(x) 的集合！求值域绝不能只代端点——对二次函数务必先配方找顶点（turning point），看顶点是否在给定定义域内！

1.2 复合函数 fg(x) 与反函数 f⁻¹(x)

  • 复合顺序：fg(x) = f(g(x)) 表示先算内层 g(x)，再代入 f；通常 fg(x) ≠ gf(x)！
    复合函数存在条件：内层函数 g 的值域必须是外层函数 f 定义域的子集（Range of g ⊆ Domain of f）。
  • 反函数 f⁻¹(x) 存在的充要条件（必考 1 分原话）：函数 f 必须是一对一函数（One-to-one function）！对于开口向上/下的二次抛物线，必须在顶点（对称轴 x = h）处截断定义域（如 x ≥ h 或 x ≤ h）才能成为 one-to-one。
  • 求反函数 3 步法 + 必写定义域：① 写 y = f(x)；② 把 x 解出来用 y 表示（注意平方开方时根据原定义域选正负号！）；③ 互换 x 与 y，并记住铁律：
    Domain of f⁻¹ = Range of f  |  Range of f⁻¹ = Domain of f。
  • 几何对称性：y = f(x) 与 y = f⁻¹(x) 的图像严格关于直线 y = x 轴对称（reflection in the line y = x）！若求两曲线交点，通常直接联立更简单的方程 f(x) = x 即可！

Topic 2 · 二次函数、配方法与判别式

Quadratic Functions: Completing the square, Discriminant (b² − 4ac) & Quadratic inequalities
Non-Calc (P1) 核心高频 Calc (P2)

2.1 配方法 (Completing the Square) 与最值顶点

ax² + bx + c = a(x + p)² + q   ⇒   顶点 Turning point = (−p, q)
带系数配方法 3 步铁律：先把前两项提取 a：a[x² + (b/a)x] + c → 括号内加减一半的平方 → 把负平方项乘以括号外的 a 再移出括号合并！（90% 学生都会忘记乘外面的 a！）

2.2 判别式 Δ = b² − 4ac 与二次不等式

判别式条件方程 ax²+bx+c=0 根的情况直线与曲线联立几何意义
b² − 4ac > 0两个不相等实根（2 distinct real roots）直线与曲线/圆相交于两不同点（intersects at 2 distinct points）
b² − 4ac = 0两个相等实根 / 重根（2 equal / repeated real roots）直线与曲线/圆相切（tangent to the curve）
b² − 4ac < 0无实数根（no real roots）直线与曲线/圆相离（永不相交）（does not intersect）
补充：仅要求“有实根” (real roots)两个相等或不等都算！务必写 b² − 4ac ≥ 0！至少有一个交点（intersects / meets）
🔬 深度讲透：为什么“表达式 ax² + bx + c > 0 对一切实数 x 恒成立”要求 a > 0 且 b² − 4ac < 0？

图像永远严格在 x 轴上方（没有与 x 轴交点），意味着抛物线必须开口向上（a > 0）并且无实根（Δ < 0）。解二次不等式如 (x−2)(x−5) < 0 时，必须先求临界根（critical values: 2, 5）并画 U 型草图再取区间 2 < x < 5，切忌胡乱写 x < 2 且 x < 5！

Topic 4 · 方程、不等式与三次图像

Equations, Inequalities and Graphs: Modulus equations, Hidden quadratics & Cubic inequalities
Non-Calc (P1) Calc (P2)

4.1 绝对值方程与不等式 (Modulus Equations & Inequalities)

  • 型 1：|ax + b| = c (c > 0) ⇒ 拆成正负两个方程：ax + b = c 或 ax + b = −c。
  • 型 2：|ax + b| = |cx + d| ⇒ 最稳妥做法是两边同时平方 (ax + b)² = (cx + d)²（用平方差展开最不易出错），或者分正负拆解！
  • 型 3：|ax + b| = cx + d（右侧无绝对值含 x！） ⇒ 拆出两个解后必须代回原方程检验右侧 cx + d ≥ 0，舍去负值增根！
  • 绝对值不等式：|ax + b| < k ⇔ −k < ax + b < k；|ax + b| > k ⇔ ax + b < −k 或 ax + b > k。

4.2 换元法解隐藏二次方程 (Hidden Quadratics)

常见换元信号：两个含未知数项的幂次呈 2 : 1 关系！

  • x − 5√x + 4 = 0 ⇒ 令 u = √x (u ≥ 0)，化为 u² − 5u + 4 = 0；
  • 3ex = 12 − 5e−x ⇒ 两边同乘 ex 得 3(ex)² − 12ex + 5 = 0，令 u = ex > 0（解出负 u 必须舍去！）；
  • 2x2/3 + x1/3 − 6 = 0 ⇒ 令 u = x1/3（注意三次方根允许负值！）。

4.3 三次多项式及绝对值 |P(x)| 草图与不等式求解

遇到 y = a(x − p)(x − q)(x − r)（及加绝对值 |...|）：

  1. 标出三个 x 轴截距 (p, 0), (q, 0), (r, 0) 及 y 轴截距（令 x = 0）；
  2. 看首项系数 a：a > 0 时图形从左下出发到右上结束（“N”型：左下→穿→穿→右上）；a < 0 时从左上出发到右下结束；
  3. 若题目求 y = |a(x−p)(x−q)(x−r)|，先画虚线原三次曲线，再把 x 轴下方波谷沿 x 轴对称翻折到上方（在三个根处形成尖锐 V 型波谷！）；
  4. 图解法解三次不等式：例如解 (x+1)(x−2)(x−4) > 0，画完正 N 型图后直接读出位于 x 轴上方的区间：−1 < x < 2 或 x > 4！（比硬代试数快 5 倍且绝不会漏！）

Topic 5 · 联立方程组 (线性与非线性)

Simultaneous Equations: Substitution, Intersection of Curves & Tangent Parameters
Non-Calc (P1) Calc (P2)

5.1 代入消元与成对配对书写规范

0606 的联立方程永远是“一条一次直线方程 + 一条二次/双曲/圆非线性方程”。黄金步骤：① 从一次方程解出系数最简单的变量（如 y = 2x − 3 或 x = ... 避免分数）；② 代入二次方程整理成 ax² + bx + c = 0；③ 解出两根后必须代回一次方程（绝不代回二次方程以免产生伪根！）算出另一坐标；④ 明确写成坐标配对或对应组（x = ..., y = ...）。

8.1 圆的标准方程与一般方程配方

标准式：( x − a )² + ( y − b )² = r²  ⇒  圆心 (a, b), 半径 r
一般式：x² + y² + 2gx + 2fy + c = 0  ⇒  圆心 (−g, −f), 半径 r = √g² + f² − c
最稳防错配方流：别死背 g, f 容易正负号搞反！直接把 x 项和 y 项分别配成完全平方：
如 x² − 6x + y² + 4y = 12 ⇒ (x−3)² − 9 + (y+2)² − 4 = 12 ⇒ (x−3)² + (y+2)² = 25 ⇒ 圆心 (3, −2)，半径 5！

8.2 圆的切线 (Tangents)、直线与圆、两圆位置关系

  • 圆上一点 P(x₁, y₁) 的切线方程（几何垂直法，无需微积分！）：① 求圆心 C(a, b) 到切点 P 的半径斜率 mCP；② 因切线垂直于过切点的半径（tangent ⊥ radius），切线斜率 mtan = −1 / mCP；③ 过点 P 用点斜式写出直线方程！（水平或竖直半径需特判斜率为 0 或无穷大）。
  • 直径式圆与半圆直角性质：若 AB 为圆的直径，则圆周上任意一点 P 满足 ∠APB = 90°（mAP · mBP = −1），且圆心即为 AB 中点！
  • 直线与圆的位置判定（两种等价法）：① 代入联立用判别式 Δ > 0（两交点割线）、Δ = 0（相切）、Δ < 0（相离）；② 或算圆心到直线距离 d 与半径 r 对比（d < r 相交，d = r 相切，d > r 相离）。
  • 两圆位置关系与公共弦（Two Circles）：设两圆心距为 D = |C₁C₂|，两半径 r₁, r₂：
    • 外离：D > r₁ + r₂；外切（Touch externally）：D = r₁ + r₂；
    • 相交（Intersect）：|r₁ − r₂| < D < r₁ + r₂；求公共弦（Common chord）或两圆交点绝招：把两个圆的展开方程直接相减消去 x² + y²，立刻得到一条一次直线（即公共弦/公切线方程），再代入其中一个圆即可秒解交点！
    • 内切（Touch internally）：D = |r₁ − r₂|；内含：D < |r₁ − r₂|。

14.4 运动学微积分 (Kinematics: s ↔ v ↔ a)

• Initially ⇒ t = 0；
• Instantaneously at rest（瞬时静止） ⇒ v = 0；
