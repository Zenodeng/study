19.1 烷烃的取代反应与烯烃的高活性加成反应

Alkanes (combustion & UV photochemical substitution) vs Alkenes (addition of Br₂, H₂ & steam)
Core · 烷烃低活性与燃烧；烯烃不饱和度与溴水褪色检验 Extended · 紫外光光化学取代、烯烃催化加氢与水合反应精确条件

1. 烷烃的低反应活性与燃烧反应 Core

烷烃（Alkanes，通式 CnH2n+2）属于饱和烃（saturated hydrocarbons），分子内只存在很强的 C–C 与 C–H 共价单键，缺乏易进攻的活泼官能团。因此在常温、无光照条件下，烷烃表现得极不活泼（generally unreactive），不与酸、碱、氧化剂（如酸化 KMnO₄）或溴水发生反应。烷烃最主要的两类反应是燃烧与紫外光下的卤代反应：

  • 完全燃烧（Complete combustion，氧气充足）：所有碳和氢分别氧化为二氧化碳与水，伴随蓝色火焰并释放大量热能（用作优质气体/液体燃料）：
    CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l)
    2C₂H₆(g) + 7O₂(g) → 4CO₂(g) + 6H₂O(l)
  • 不完全燃烧（Incomplete combustion，氧气不足）：产生剧毒气体一氧化碳（CO）或黑烟状炭黑（C, soot）与水，火焰偏黄带烟且放热减少：
    2CH₄(g) + 3O₂(g) → 2CO(g) + 4H₂O(l)

2. 烷烃与氯气的紫外光光化学取代反应 Extended

CH₄(g) + Cl₂(g) → CH₃Cl(g) + HCl(g) （条件：紫外光 UV light）

• 取代反应定义（Substitution reaction）：有机分子中一个原子或原子团被另一个原子或原子团替换（replaced）的反应。
• 为什么必须有紫外光（UV light）？ 氯气与烷烃分子自身非常稳定，在黑暗中混合完全不反应；UV 紫外光提供反应的活化能（activation energy, Eₐ），打断 Cl–Cl 键启动光化学反应，属于典型的光化学反应（photochemical reaction）。
• 一元取代配平细节：每一步仅用 1 个 Cl 原子置换 1 个 H 原子，同时放出 1 分子氯化氢 HCl（切记产物不是只有 CH₃Cl，必须写上副产物 + HCl！）。反应现象：黄绿色氯气逐渐褪色，生成溶于水显强酸性的白雾 HCl。
• 多取代产物风险：实际反应中若氯气过量，剩余 H 会继续被置换，生成二氯甲烷（CH₂Cl₂）、三氯甲烷（CHCl₃）与四氯化碳（CCl₄）的混合物（乙烷氯代还可得到 1,1- 与 1,2-二氯乙烷同分异构体）。因此 IGCSE 考纲方程只要求掌握一元取代（monosubstitution），例如乙烷：C₂H₆ + Cl₂ → C₂H₅Cl + HCl。

3. 烯烃的高活性：C=C 双键的加成反应与溴水检验 Core Extended

烯烃（Alkenes，通式 CnH2n）含有活泼的 C=C 碳碳双键（不饱和烃）。在加成反应（addition reaction）中，双键中较弱的一根键打开，两个新原子或基团分别加合到双键两端的碳原子上，整个反应只生成一种产物（only one product is formed）！

加成反应类型 反应试剂与考纲条件 典型方程式（以乙烯为例）与现象
加溴水（Bromination）
Core Ext		 溴水 Br₂(aq)
常温下直接摇匀反应（无需 UV 或催化剂）		 C₂H₄(g) + Br₂(aq) → CH₂BrCH₂Br(l)（1,2-二溴乙烷，无 HBr 生成）
权威检验现象：溴水由橙棕色迅速褪为无色（orange / orange-brown → colourless）；烷烃则无变化！
加氢 / 氢化（Hydrogenation）
Extended		 氢气 H₂(g)
条件：镍（Ni）催化剂，150–200 °C		 C₂H₄(g) + H₂(g) → C₂H₆(g)（烯烃饱和化为烷烃）
工业应用：将液态不饱和植物油氢化硬化制造人造黄油（margarine）。
催化水合（Hydration）
Extended		 水蒸气 H₂O(g)
条件：300 °C、6000 kPa (60 atm)、磷酸 H₃PO₄ 催化剂		 C₂H₄(g) + H₂O(g) ⇌ C₂H₅OH(g)（工业制乙醇核心反应）
丙烯水合时，–H 与 –OH 分别加在双键两端，可生成 propan-1-ol 或 propan-2-ol。
⚠️ 溴水检验的三大失分雷区（Mark Scheme 高压线）

1. 描述褪色现象时只能写 "orange / orange-brown to colourless"，严禁写成 "turns clear"（透明不代表无色！）；
2. 写加成产物时千万不要写成 C₂H₃Br + HBr——烯烃和溴是加成（Addition）不是取代，两个溴原子分别接在原来双键的两个相邻碳上（即 1,2-dibromoethane，绝不是 1,1-dibromoethane！）；
3. 若问为何可以用溴水区分乙烷（ethane）和乙烯（ethene），必须答：乙烯是含 C=C 双键的不饱和烃发生加成使溴水褪色，乙烷为饱和烃无双键不反应。

📝 精解例题 19.1 · 丙烯的加成反应与烷烯鉴别

写出丙烯（Propene, CH₃–CH=CH₂）与过量溴水反应及在镍催化下与氢气反应生成的产物化学式、名称与实验现象差异。

分步规范解答：
1. 加溴水：双键在 1 号和 2 号碳之间打开，各连一个 Br 原子，生成 CH₃CHBrCH₂Br（1,2-二溴丙烷, 1,2-dibromopropane），溴水由橙棕色迅速褪为无色；
2. 加氢气（Ni, 150–200 °C）：生成饱和丙烷 CH₃CH₂CH₃（Propane, C₃H₈），与丙烯相比，丙烷不再能使溴水褪色（但可在 UV 光下与 Cl₂ 发生取代反应生成 1-chloropropane 或 2-chloropropane + HCl）。

19.2 乙醇的两种制法对比、性质与工业用途

Manufacture of ethanol (fermentation vs catalytic hydration of ethene), combustion & uses
Core · 葡萄糖发酵与乙烯水合制乙醇方程式、条件及燃料/溶剂用途 Extended · 两种制法工业优缺点全维度评估与无氧控制机理

1. 路线一：葡萄糖无氧发酵法（Fermentation of glucose） Core

C₆H₁₂O₆(aq) → 2C₂H₅OH(aq) + 2CO₂(g)

• 原料：植物糖类/淀粉水解得的葡萄糖水溶液（如甘蔗、玉米，属于可再生生物质资源 renewable resource）。
• 三大必备条件（缺一不可，Paper 4/6 高频满分点）：
  ① 催化剂：加入酵母菌（Yeast）提供生物酶（enzymes）催化分解；
  ② 最适温度 25–35 °C：温度过低反应极慢；若超过 ~40 °C，酵母菌体内的酶蛋白质变性失活（enzymes denature），反应彻底停止；
  ③ 隔绝氧气（Anaerobic conditions / absence of oxygen）：容器口需装单向水封发酵阀（让 CO₂ 气体逸出同时防止空气进入）。若氧气进入，空气中的醋酸菌会把乙醇进一步氧化成乙酸（ethanoic acid，变酸变醋），同时酵母菌转行有氧呼吸只生成 CO₂ 和水而不再产乙醇！
• 提纯问题：当乙醇浓度升至约 15% 时，高浓度酒精会杀死酵母菌使反应自停，因此得到的稀乙醇水溶液必须通过分馏（fractional distillation）分离纯化。

2. 路线二：乙烯催化水合法（Catalytic addition of steam to ethene） Core Extended

C₂H₄(g) + H₂O(g) ⇌ C₂H₅OH(g) （条件：300 °C、6000 kPa / 60 atm、H₃PO₄ 催化剂）

• 原料：乙烯（来自不可再生石油原油的石脑油裂化）+ 高温高压水蒸气。
• 工艺特征：在高压反应塔中将混气通过涂有固体磷酸（H₃PO₄）的催化剂床层；该反应为可逆反应，未转化的乙烯与水蒸气冷却分离后循环回流重新反应，几乎无废料排放。

3. 乙醇两大工业制法深度优缺点对比表 Extended

评估维度 路线一：葡萄糖无氧发酵 (Fermentation) 路线二：乙烯催化水合 (Hydration of ethene)
原料可持续性 优势：植物糖分属于可再生资源（renewable），适合缺乏石油但农业发达的国家（如巴西甘蔗） 劣势：乙烯源自石油（crude oil），属于不可再生化石资源（non-renewable），终将枯竭
温度压强与能耗 优势：常温常压（25–35 °C、常压），设备简单，能耗极低 劣势：需 300 °C 高温与 6000 kPa 高压，设备造价高且能耗极大
反应速率与生产模式 劣势：间歇法（batch process），反应非常缓慢（需数天至数周），需频繁清罐重启 优势：连续化流水线（continuous process），反应极快，单位时间产量巨大
产物纯度与原子经济 劣势：仅产 ~15% 含水稀溶液，含酵母残渣，必须耗能分馏提纯；且 1/3 碳原子变成温室气体 CO₂ 流失 优势：直接得到高纯度纯乙醇（含水极少），原子利用率 100%，无 CO₂ 温室副产物

4. 乙醇的两大核心用途与完全燃烧 Core

  • 作为清洁燃料（Fuel）：乙醇易燃，燃烧只生成二氧化碳和水（相对洁净，如加入汽油制成“乙醇汽油”或酒精灯燃料）：
    C₂H₅OH(l) + 3O₂(g) → 2CO₂(g) + 3H₂O(l)（配平核查：左 C=2, H=6, O=1+6=7；右 C=2, H=6, O=4+3=7）。
  • 作为重要有机溶剂（Solvent）：乙醇分子一端有极性羟基 –OH（可混溶于水），另一端有非极性乙基 C₂H₅–（能溶解油脂、色素与芳香物质），广泛用于香水、护肤品、油漆、油墨与药品配方中。

19.3 羧酸的典型酸性反应、乙醇氧化与酯化反应

Reactions of ethanoic acid, oxidation of ethanol to ethanoic acid & esterification
Core · 乙酸与活泼金属、碱及碳酸盐的三类盐生成反应 Extended · 弱酸部分离解、乙醇两种氧化途径与酯化反应机理命名

1. 乙酸（Ethanoic acid, CH₃COOH）的三大典型酸性反应 Core

乙酸（俗称醋酸，含羧基 –COOH）在水溶液中属于弱酸（weak acid）——仅发生部分离解（partially dissociated）：
CH₃COOH(aq) ⇌ CH₃COO⁻(aq) + H⁺(aq)（pH 约 3）。因此它既能发生普通酸的全部三类特征反应，生成名以 -oate 结尾的乙酸盐（ethanoates）；但由于 H⁺ 浓度低于同浓度强酸（如 HCl），其反应速率较慢但同摩尔酸最终放出的 H₂ 或 CO₂ 总量相同！

反应类型 化学方程式（含状态符号） 盐的名称与实验现象
乙酸 + 活泼金属
（如 Mg, Zn）		 2CH₃COOH(aq) + Mg(s) → (CH₃COO)₂Mg(aq) + H₂(g) 生成 magnesium ethanoate + 无色氢气气泡（燃着木条发出‘pop’声，镁条逐渐溶解）
乙酸 + 碱 / 碱金属氢氧化物 CH₃COOH(aq) + NaOH(aq) → CH₃COONa(aq) + H₂O(l) 生成 sodium ethanoate + 水（放热中和反应，无气泡，可用百里酚酞指示剂观察终点）
乙酸 + 金属碳酸盐 2CH₃COOH(aq) + Na₂CO₃(s) → 2CH₃COONa(aq) + H₂O(l) + CO₂(g) 生成 sodium ethanoate + 水 + 二氧化碳剧烈泡腾（通入澄清石灰水变浑浊）

2. 乙醇氧化生成乙酸的两种途径 Extended

  • 途径 ① · 细菌有氧氧化（Bacterial oxidation）：敞口放置的低度酒液中的乙醇，在空气中醋酸菌（Acetobacter）催化下被氧气缓慢氧化成乙酸（家庭酿醋原理）：
    C₂H₅OH(aq) + O₂(g) → CH₃COOH(aq) + H₂O(l)
  • 途径 ② · 酸化高锰酸钾加热氧化（Acidified aqueous potassium manganate(VII)）：将乙醇与稀硫酸酸化的 KMnO₄(aq) 在水浴中共热（warm / heat under reflux），强氧化剂供给氧 [O] 将乙醇氧化为乙酸：
    CH₃CH₂OH(aq) + 2[O] → CH₃COOH(aq) + H₂O(l)
    必背现象：氧化过程中高锰酸根离子（MnO₄⁻）被还原为锰(II)离子（Mn²⁺），溶液颜色由紫色褪为无色（purple → colourless）！

3. 酯化反应（Esterification）与酯的结构命名法则 Extended

Carboxylic acid + Alcohol ⇌ Ester + Water （条件：浓硫酸 H₂SO₄ 作催化剂 + 加热）

• 典型例式（乙酸 + 乙醇 ⇌ 乙酸乙酯 + 水）：CH₃COOH(l) + C₂H₅OH(l) ⇌ CH₃COOC₂H₅(l) + H₂O(l)（产物称 ethyl ethanoate）。
• 成键机制：羧酸脱去羧基上的 –OH，醇脱去羟基上的 –H，两者结合成小分子 H₂O；其余两部分对接形成酯基官能团 –C(=O)–O–（简写 –COO–）。注意该反应是可逆反应（⇌），浓硫酸既作催化剂加快速率，又吸收生成的水推动平衡向右生成更多酯。
• 酯的物理性质与用途：低分子酯通常为不溶于水、密度比水小的易挥发油状液体，带有浓郁的甜果香味（fruity smell），广泛用于食用香精（flavourings）、香水（perfumes）及油漆指甲油溶剂。

💡 酯的双向命名绝招：先写醇侧 (-yl)，后写酸侧 (-oate)！

给定任何酯的结构式时，立刻在 C(=O) 与单键 –O– 之间划一刀劈开：
• 不含 C=O、直接连在单键氧 –O– 上的烃基来自醇 → 变成前缀 ...-yl（如 –O–CH₃ 为 methyl，–O–CH₂CH₃ 为 ethyl，–O–CH₂CH₂CH₃ 为 propyl）；
• 包含羰基 C=O 在内的那一整侧碳链来自羧酸 → 数清包含 C=O 碳在内的总碳数，变成后缀 ...-oate（1C = methanoate，2C = ethanoate，3C = propanoate，4C = butanoate）。
例如：HCOOCH₂CH₂CH₃ 左侧含 C=O 共 1 个碳（methanoate），右侧连单键氧共 3 个碳（propyl）→ 名称为 propyl methanoate！

📝 精解例题 19.2 · 由酯化学式反推酸、醇与全称 [Extended]

某果香味液态有机物结构简式为 CH₃CH₂CH₂COOCH₃。写出它的 IUPAC 名称，并指出合成该酯所需的羧酸与醇的名称及必要反应条件。

分步规范解答：
1. 劈开酯键判碳数：左侧含 –COO– 中羰基碳的基团为 CH₃CH₂CH₂C(=O)–，共 4 个碳，源自丁酸（butanoic acid）；右侧连在单键氧上的基团为 –OCH₃，共 1 个碳，源自甲醇（methanol）。
2. 先醇后酸命名：methanol → methyl；butanoic acid → butanoate，合称 methyl butanoate。
3. 条件：将丁酸与甲醇混合，加入浓硫酸（concentrated sulfuric acid）作催化剂并加热（heat）。
