10.1 氧化还原三大认知层次：得失氧、OIL RIG 与氧化数

Oxygen Gain/Loss, Roman Numerals, OIL RIG Electron Transfer & Oxidation Number Rules
Core: Oxygen Gain/Loss & Roman Numerals Extended: OIL RIG & Oxidation Numbers

10.1.1 层次一：得失氧（Core）与罗马数字命名法 Core

  • 氧化反应（Oxidation）：物质得到氧（gain of oxygen）。例如镁在空气中燃烧：2Mg + O₂ → 2MgO（Mg 得氧被氧化为 MgO）。
  • 还原反应（Reduction）：物质失去氧（loss of oxygen）。例如氢气还原氧化铜：CuO + H₂ → Cu + H₂O（CuO 失去氧被还原为 Cu，同时 H₂ 得氧被氧化为 H₂O）。
  • 氧化还原反应（Redox reaction）：任何反应中，只要有物质被氧化，必然同时有另一种物质被还原（oxidation and reduction occur simultaneously）。
  • 罗马数字（Roman numerals）的含义（Core 必识）：化学名称中的罗马数字表示变价元素的氧化态（Oxidation number）：
    • Iron(II) chloride FeCl₂ 含 Fe²⁺（铁为 +2 价），Iron(III) chloride FeCl₃ 含 Fe³⁺（铁为 +3 价）；
    • Copper(II) sulfate CuSO₄ 含 Cu²⁺（铜为 +2 价）；
    • Potassium manganate(VII) KMnO₄ 中锰元素为 +7 价；Potassium dichromate(VI) K₂Cr₂O₇ 中铬为 +6 价。

10.1.2 层次二：OIL RIG 电子转移层面 Extended

很多重要化学反应（如金属置换、卤素置换、电解槽半反应）根本没有氧元素参与，必须使用电子转移（Electron transfer）定义：

OIL RIG 口诀：Oxidation Is Loss (of electrons) · Reduction Is Gain (of electrons)
• 氧化（失电子）：如 Zn(s) → Zn²⁺(aq) + 2e⁻；2Br⁻(aq) → Br₂(aq) + 2e⁻；Fe²⁺ → Fe³⁺ + e⁻
• 还原（得电子）：如 Cu²⁺(aq) + 2e⁻ → Cu(s)；Cl₂(g) + 2e⁻ → 2Cl⁻(aq)；Fe³⁺ + e⁻ → Fe²⁺

10.1.3 层次三：氧化数 (Oxidation Numbers) 判定六大铁律 Extended

对于共价化合物（如 CO、CH₄、NH₃）或复杂多原子离子（如 MnO₄⁻），没有纯粹的离子电荷，此时氧化数（Oxidation number / Oxidation state）是最万能的判据：

  • 氧化（Oxidation） = 元素的氧化数升高（increases）（如 −1 → 0 或 +2 → +3）；
  • 还原（Reduction） = 元素的氧化数降低（decreases）（如 +7 → +2 或 0 → −1）。
氧化数分配六大铁律 必须牢记的典型实例（符号写在数字前！）
1. 单质永远为 0
(Uncombined element = 0)		 Fe(s) = 0、O₂(g) = 0、Cl₂(g) = 0、S₈ = 0、Cu = 0
2. 单核简单离子 = 离子所带电荷 Na⁺ = +1、Mg²⁺ = +2、Fe³⁺ = +3、Cl⁻ = −1、O²⁻ = −2
3. 化合物中常见固定值 • 第 I 族金属恒 +1，第 II 族金属恒 +2，氟 (F) 恒 −1；
• 氢 (H) 一般为 +1（金属氢化物如 NaH 中为 −1）；
• 氧 (O) 一般为 −2（过氧化物 H₂O₂ 中为 −1，OF₂ 中为 +2）。
4. 中性化合物氧化数代数和 = 0 Fe₂O₃ 中 2×Fe + 3×(−2) = 0 ⇒ Fe = +3；CO₂ 中 C = +4；NH₃ 中 N = −3
5. 多原子离子氧化数代数和 = 离子总电荷 MnO₄⁻ 中 Mn + 4×(−2) = −1 ⇒ Mn = +7；
Cr₂O₇²⁻ 中 2×Cr + 7×(−2) = −2 ⇒ Cr = +6；SO₄²⁻ 中 S = +6
6. 规范书写格式对比 氧化数（符号在前）：+2, +7, −1；离子电荷（符号在后）：Fe²⁺, Mn²⁺, Cl⁻。
⚠️ 考官高频陷阱：识别“伪装非氧化还原反应 (Non-redox reactions)”

并不是所有化学反应都是氧化还原反应！用氧化数一查便知：
• 酸碱中和：H⁺(+1)Cl⁻(−1) + Na⁺(+1)O(−2)H(+1) → Na⁺(+1)Cl⁻(−1) + H₂(+1)O(−2)
• 复分解沉淀：Ag⁺(+1)NO₃⁻ + Na⁺Cl⁻(−1) → AgCl(s) + NaNO₃
• 碳酸钙热分解：Ca(+2)C(+4)O₃(−2) → Ca(+2)O(−2) + C(+4)O₂(−2)
上述反应中没有任何元素的氧化数发生改变，因此它们都不是（NOT）Redox 反应！

📘 例题 10.2 · 高炉炼铁核心反应双向全维度拆解

In the blast furnace, iron(III) oxide reacts with carbon monoxide: Fe₂O₃(s) + 3CO(g) → 2Fe(l) + 3CO₂(g).
Identify which substance is oxidised, which is reduced, the oxidising agent, and the reducing agent, justifying your answer using oxidation numbers.

解析 (Solution)：
① 标注各元素氧化数：Fe₂O₃ 中 Fe = +3、O = −2；CO 中 C = +2、O = −2；生成物 Fe 单质 = 0；CO₂ 中 C = +4、O = −2。
② 被还原的物质：Fe₂O₃（或 Fe³⁺）—— 因为失去氧且 Fe 氧化数从 +3 降至 0。
③ 被氧化的物质：CO —— 因为得到氧且 C 氧化数从 +2 升至 +4。
④ Agent 角色反转互换：
• Reducing agent（还原剂）= CO（它把 Fe₂O₃ 还原了，自身氧化数升价被氧化）；
• Oxidising agent（氧化剂）= Fe₂O₃（它把 CO 氧化了，自身氧化数降价被还原）。

SME 1 · 得失氧与罗马数字基础氧化还原分析Core Extended [5 marks]
Copper(II) oxide reacts with carbon when heated strongly:
2CuO(s) + C(s) → 2Cu(s) + CO₂(g)
(a) Explain why copper(II) oxide has the Roman numeral (II) in its name. [1]
(b) State which substance is oxidised and which substance is reduced, explaining your answer in terms of oxygen transfer. [2]
(c) Extended Identify the reducing agent and state the change in oxidation number of copper during this reaction. [2]
氧化铜与碳粉高温反应 2CuO + C → 2Cu + CO₂：(a) 解释名称中罗马数字 (II) 的含意；(b) 从氧得失角度指明何者被氧化、何者被还原；(c) [Extended] 指出还原剂并写出铜元素氧化数变化。
查看评分细则 (Mark Scheme · 5 Marks)

B1 (a) Copper has an oxidation number / state of +2 (exists as Cu²⁺ ions).

B1 (b) Carbon (C) is oxidised because it gains oxygen (to form CO₂);
B1 Copper(II) oxide (CuO) is reduced because it loses oxygen (to form Cu).

B1 (c) Reducing agent: carbon (C);
B1 Oxidation number of copper decreases from +2 to 0.

中文精析：氧层面与氧化数层面完全自洽；注意氧化数数字零要明确写为 0，+2 不可漏写正号！

SME 2 · 铁与铜置换反应 OIL RIG 离子方程式与电子流向Extended [5 marks]
When zinc granules are added to aqueous copper(II) sulfate, the ionic equation is:
Zn(s) + Cu²⁺(aq) → Zn²⁺(aq) + Cu(s)
(a) Write two separate ionic half-equations for this reaction and label each as oxidation or reduction. [3]
(b) Explain in terms of electron transfer why this is a redox reaction, and state which particle is the oxidising agent. [2]
锌粒投入硫酸铜溶液离子方程式 Zn + Cu²⁺ → Zn²⁺ + Cu：(a) 拆写两个半方程式并标注氧化或还原；(b) 用电子转移说明为何属于氧化还原并指出氧化剂。
查看评分细则 (Mark Scheme · 5 Marks)

B1 (a) Zn → Zn²⁺ + 2e⁻ — oxidation (loss of electrons);
B1 Cu²⁺ + 2e⁻ → Cu — reduction (gain of electrons); B1 both correctly balanced and labelled.

B1 (b) Oxidation and reduction occur at the same time (electrons are transferred from Zn to Cu²⁺);
B1 Oxidising agent: Cu²⁺ (or CuSO₄, because it accepts/gains electrons from Zn and oxidises it).

中文精析：切记氧化数和半方程式配平缺一不可；铜离子 Cu²⁺ 抢走了锌的电子，因此 Cu²⁺ 是氧化剂！

SME 3 · 酸化 KMnO₄ 与 KI(aq) 定性检验实验题 (2023 新增重点)Extended [6 marks]
A student has two unlabelled reagent bottles containing aqueous solutions of a reducing agent (e.g. FeSO₄) and an oxidising agent (e.g. Cl₂ water).
(a) Describe a test using acidified aqueous potassium manganate(VII) to confirm the reducing agent, stating the exact colour change and the change in oxidation number of manganese. [3]
(b) Describe a test using aqueous potassium iodide to confirm the oxidising agent, stating the colour change and writing the ionic half-equation for iodide ions. [3]
某同学有两瓶未贴标签溶液，一瓶为还原剂、一瓶为氧化剂：(a) 用酸化 KMnO₄(aq) 检验还原剂的实验现象与 Mn 氧化数变化；(b) 用 KI(aq) 检验氧化剂的显色现象与碘离子半方程式。
查看评分细则 (Mark Scheme · 6 Marks)

B1 (a) Add acidified KMnO₄(aq) to the reducing agent;
B1 Colour change: purple to colourless (decolourised);
B1 Oxidation number of Mn changes from +7 to +2 (MnO₄⁻ reduced to Mn²⁺).

B1 (b) Add aqueous KI(aq) to the oxidising agent;
B1 Colour change: colourless to brown (yellow-brown, due to I₂ formed);
B1 Half-equation: 2I⁻(aq) → I₂(aq) + 2e⁻ (oxidation, I changes from −1 to 0).

中文精析：2023 考纲明确要求会背写这两个实验的颜色变化（purple → colourless 与 colourless → brown），不要把“无色 colourless”错写成“透明 clear”！

SME 4 · 复杂方程式氧化数全面核算与 Redox 鉴别Extended [6 marks]
Consider the reaction between iron(II) ions and hydrogen peroxide in acidic solution:
2Fe²⁺(aq) + H₂O₂(aq) + 2H⁺(aq) → 2Fe³⁺(aq) + 2H₂O(l)
(a) State the oxidation number of oxygen in H₂O₂ and in H₂O. [2]
(b) Use oxidation numbers to prove which species is oxidised and which species is reduced. [2]
(c) Identify the oxidising agent and the reducing agent in this reaction. [2]
酸性条件下亚铁离子与过氧化氢反应 2Fe²⁺ + H₂O₂ + 2H⁺ → 2Fe³⁺ + 2H₂O：(a) 求出 H₂O₂ 与 H₂O 中氧的氧化数；(b) 用氧化数升降证明何者被氧化/被还原；(c) 指明氧化剂与还原剂。
查看评分细则 (Mark Scheme · 6 Marks)

B1 (a) In H₂O₂ (peroxide): 2(+1) + 2×O = 0 ⇒ O = −1;
B1 In H₂O: O = −2.

B1 (b) Fe²⁺ is oxidised because the oxidation number of Fe increases from +2 to +3;
B1 H₂O₂ is reduced because the oxidation number of O decreases from −1 to −2 (H⁺ stays +1).

B1 (c) Oxidising agent: H₂O₂; B1 Reducing agent: Fe²⁺.

中文精析：特例规律 H₂O₂ 中 O 是 −1 价，变回水中常见的 −2 价正是“降价被还原”，所以双氧水在这里担当氧化剂！

用电子转移理论（OIL RIG）写出氧化与还原的英文定义。
👆 点击查看参考答案
Oxidation Is Loss of electrons; Reduction Is Gain of electrons.
C04 · 10.1 Half-Equation CheckExtended
Identify whether 2Cl⁻ → Cl₂ + 2e⁻ and Fe³⁺ + e⁻ → Fe²⁺ are oxidation or reduction.
判断 2Cl⁻ → Cl₂ + 2e⁻ 与 Fe³⁺ + e⁻ → Fe²⁺ 各属于氧化还是还原。
👆 点击查看参考答案
2Cl⁻ → Cl₂ + 2e⁻ is oxidation (loss of electrons, −1 → 0); Fe³⁺ + e⁻ → Fe²⁺ is reduction (gain of electron, +3 → +2).
C05 · 10.1 Non-Redox CheckCore
Give two examples of common reaction types that are NOT redox reactions.
列举两类不属于氧化还原反应的常见化学反应类型。
👆 点击查看参考答案
Acid–base neutralisation, precipitation reactions, and thermal decomposition of metal carbonates (no oxidation numbers change).
C06 · 10.1 Roman NumeralsCore
What does the Roman numeral indicate in copper(II) oxide and potassium manganate(VII)?
化学名称 copper(II) oxide 与 potassium manganate(VII) 中的罗马数字表示什么？
👆 点击查看参考答案
The oxidation number (state) of the element in the compound: Cu is +2 in CuO; Mn is +7 in KMnO₄.
C07 · 10.1 Rule: Element & IonExtended
What is the oxidation number of an uncombined element and of a simple monatomic ion?
未化合单质和单核简单离子的氧化数各遵循什么规律？
👆 点击查看参考答案
Uncombined element = 0 (e.g. O₂, Fe); simple monatomic ion = the charge on the ion (with sign before number, e.g. Al³⁺ is +3).
C08 · 10.1 Rule: H, O, FExtended
State the usual oxidation numbers of H, O, and F in compounds (and one exception for H and O).
写出化合物中 H、O、F 的常规氧化数及常见例外情形。
👆 点击查看参考答案
F is always −1; H is usually +1 (except −1 in metal hydrides like NaH); O is usually −2 (except −1 in peroxides like H₂O₂).
C09 · 10.1 Sum RulesExtended
State the oxidation number sum rule for (a) a neutral compound and (b) a polyatomic ion.
写出中性化合物与多原子离子中所有原子氧化数的代数和规律。
👆 点击查看参考答案
Sum in a neutral compound = 0; sum in a polyatomic ion = the overall charge of the ion (e.g. SO₄²⁻ sums to −2).
C10 · 10.1 Ox. Number ShiftExtended
Define oxidation and reduction in terms of oxidation numbers.
如何根据元素氧化数的变化判断氧化与还原？
👆 点击查看参考答案
Oxidation = increase in oxidation number; Reduction = decrease in oxidation number.
C11 · 10.1 Sign NotationExtended
How does writing an oxidation number differ from writing an ionic charge?
氧化数的正负号书写位置与离子电荷有何严格区别？
👆 点击查看参考答案
For oxidation numbers, put the sign BEFORE the number (e.g. +3, −2); for ionic charges, put the sign AFTER the number (e.g. Fe³⁺, O²⁻).
C12 · 10.2 Oxidising AgentExtended
Define an oxidising agent.
写出氧化剂（Oxidising agent）的官方双层英文定义。
👆 点击查看参考答案
A substance that oxidises another substance and is itself reduced (gains electrons / oxidation number decreases).
C13 · 10.2 Reducing AgentExtended
Define a reducing agent.
写出还原剂（Reducing agent）的官方双层英文定义。
👆 点击查看参考答案
A substance that reduces another substance and is itself oxidised (loses electrons / oxidation number increases).
C14 · 10.2 Acidified KMnO₄ TestExtended
Describe the use of acidified aqueous potassium manganate(VII) as a redox test, including the colour change.
说明酸化 KMnO₄(aq) 用于检验哪类物质，写出其颜色变化与 Mn 氧化数变化。
👆 点击查看参考答案
Acidified KMnO₄(aq) is an oxidising agent used to test for a reducing agent; it turns from purple to colourless (Mn: +7 → +2).
C15 · 10.2 KI(aq) TestExtended
Describe the use of aqueous potassium iodide as a redox test, including the colour change and half-equation.
说明 KI(aq) 用于检验哪类物质，写出显色变化及碘离子半方程式。
👆 点击查看参考答案
KI(aq) is a reducing agent used to test for an oxidising agent; it turns from colourless to brown as I⁻ oxidises to I₂ (2I⁻ → I₂ + 2e⁻).
C16 · 10.2 Blast Furnace RedoxExtended
In Fe₂O₃ + 3CO → 2Fe + 3CO₂, identify the oxidising agent and reducing agent using oxidation numbers.
在高炉炼铁反应 Fe₂O₃ + 3CO → 2Fe + 3CO₂ 中，结合氧化数指出氧化剂与还原剂。
👆 点击查看参考答案
Fe₂O₃ is the oxidising agent (Fe reduced +3 → 0); CO is the reducing agent (C oxidised +2 → +4).
