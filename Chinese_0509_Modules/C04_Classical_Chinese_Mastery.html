4.1 Paper 1 Sec 3 命题全景与 18 大高频文言虚词秒杀法

Classical Chinese Reading (12 Marks): Top 18 Function Words & Context Disambiguation
Paper 1 Sec 3 · 12 Marks 100% Unseen 课外浅易文言 建议考场耗时：22–25 分钟
📢 考纲定位：12 分课外文言为什么是最稳拿的“高性价比阵地”？

IGCSE 0509 Paper 1 Section 3 固定考查一篇 180–250 字的课外浅易文言文（Unseen），题材九成出自《史记》《汉书》《后汉书》《世说新语》《资治通鉴》《说苑》《韩非子》等史传记事与笔记寓言。12 分设题极其规律：实词释义（3–4 分）+ 虚词辨析（2 分）+ 关键句直译（4 分）+ 主旨道理/人物形象简答（2–3 分）。生僻专名（人名/官职/器物）卷面均会加注，真正拉开分差的是18 大高频虚词、词类活用、古今异义与特殊句式。

考场三大高频夺命坑聚焦：死磕“之”与“而”的隐形语法功能
“之”在主谓之间取消独立性（删去不译） ｜ “而”辨转折（却）/ 顺承（就）/ 修饰（地）
• “之”取消句子独立性（极高频考点）：当“之”卡在主语和谓语之间（如予独爱莲之出淤泥而不染、虽我之死、无丝竹之乱耳），它把整个小句子降级为一个名词性短语，翻译时绝不能译成“的”，必须直接删去不译！
• “而”三义秒断法：前后句语义褒贬/预期相反 → 表转折“却、但是”（人不知而不愠）；前后为连续先后动作 → 表顺承“就、然后”（拔山倒树而来）；前为情态/方式/时间状语 + 而 + 中心动词 → 表修饰“地、着”（面山而居、密愧而出）。

一、18 大高频文言虚词完整对照表与考场位置秒杀口诀

# / 虚词 考纲核心词性与高频义项 真题级经典例句与当句精准译义 考场句法位置秒判口诀
1. 之
必考榜首		 ① 取消句子独立性（不译）
② 代词：他 / 她 / 它 / 这件事
③ 结构助词：的
④ 动词：到、往
⑤ 宾语/定语倒装标志（不译）		 • 予独爱莲之出淤泥而不染（取消独立性，不译）
• 肉食者谋之（这件事）
• 辍耕之垄上（到、前往）
• 何陋之有（宾语前置标志，不译）		 主 + 之 + 谓 = 取消独立性不译；动 + 之 = 代词；名 + 之 + 名 = 的；之 + 处所 = 动词“到”；“何……之有”= 提宾不译。
2. 其 ① 人称/指示代词：他的/它的/那/其中
② 语气副词：难道（表反问）
③ 语气副词：大概/恐怕（表揣测）
④ 语气副词：可要/应当（表祈使）		 • 恐前后受其敌（它们的）
• 其真无马邪？（难道）
• 圣人之所以为圣，愚人之所以为愚，其皆出于此乎？（大概）
• 安陵君其许寡人！（可要）		 其 + 名词 = 它的/那；“其……邪/乎？”句首多表反问“难道”或揣测“大概”；主语 + 其 + 动词祈使句 = 可要。
3. 而
必考榜首		 ① 表转折：却、但是
② 表顺承：就、于是、然后
③ 表修饰：地、着（不译作并且）
④ 表并列：又、并且		 • 予独爱莲之出淤泥而不染（转折：却）
• 夺其物而去（顺承：然后）
• 密愧而出 / 朝而往（修饰：地）
• 蔚然而深秀（并列：并且）		 先看前后语义反不反（反→转折“却”）；再看前项是不是描摹情状/方式（是→修饰“地”）；再看是否先后两步（是→顺承）。
4. 以 ① 介词：用、拿、凭借、按照
② 介词：因为、由于
③ 连词：来、以便（表目的）/ 以致
④ 动词：认为		 • 以刀劈狼首（用）
• 不以物喜，不以己悲（因为）
• 属予作文以记之（来、以便）
• 以君为长者（认为）		 以 + 工具/方式 = 用/凭；以 + 心理/事由 = 因为；“动词 1 + 以 + 动词 2”= 目的连词“来”；“以 A 为 B”= 把 A 当作/认为 B。
5. 于 ① 介词：在、到、从
② 介词：对、向、给
③ 介词：比（表比较）
④ 介词：被（表被动）		 • 战于长勺（在）
• 告之于帝（向）
• 苛政猛于虎（比）
• 见笑于乡人（被）		 形容词 + 于 + 名词 = 比；动词受事 + 于 + 人 = 被；动词 + 于 + 处所 = 在/到（注意多为状语后置）。
6. 为 ① 介词(wèi)：替、给、为了、因为
② 介词(wéi)：被（“为……所……”）
③ 动词(wéi)：做、担任、成为、认为		 • 为人谋而不忠乎（替）
• 为巨浪所吞（被）
• 项燕为楚将（担任）/ 俱为一体（成为）		 见“为……所……”百分百是被动“被”；见“为 + 对象 + 动作”常读 wèi 译“替/给”。
7. 者 ① 代词：……的人 / ……的事物
② 助词：句中提顿表判断（不译）
③ 定语后置标志（不译）		 • 肉食者鄙（做大官的人）
• 陈胜者，阳城人也（主语停顿不译）
• 马之千里者（定语后置标志）		 “形/动 + 者”= ……的人/事物；“……者，……也”中的“者”绝不译成“……的人”，只作主语提示停顿。
8. 也 ① 句末表判断（配合“者”或单用）
② 句末表肯定、感叹或陈述语气（可不译）
③ 句中表停顿舒缓		 • 夫战，勇气也（判断：“是……”）
• 环滁皆山也（陈述肯定语气）
• 其真不知马也！（感叹“啊”）		 名词性谓语 + 也 = 判断句（翻译补“是”）；形容词/动词句末 + 也 = 语气助词可省或译“啊”。
9. 乃 ① 副词：于是、就（顺承）
② 副词：竟然、却（转折）
③ 判断词：是、原来是
④ 副词：才 / 代词：你的		 • 见渔人，乃大惊（于是、就）
• 乃不知有汉（竟然）
• 当立者乃公子扶苏（是）
• 久之，乃悟（才）		 按事件推进译“于是就”；语义出乎意料大反差译“竟然”；主语 + 乃 + 名词 = 判断“是”。
10. 则 ① 连词：就、那么（顺承/假设条件）
② 连词：却、反倒（转折）
③ 判断词：就是		 • 学而不思则罔（就）
• 欲速则不达（却、反倒）
• 此则岳阳楼之大观也（就是）		 前件成立后件随之 = 就；前后语意相反相悖 = 却；“此则……也”= 就是。
11. 焉 ① 兼词（=于此/于之）：在这里、从其中
② 疑问代词：哪里、怎么
③ 句末语气词：啊、呢（可不译）
④ 形容词词尾：……的样子		 • 三人行，必有我师焉（在其中）
• 焉知非福？（怎么、哪里）
• 寒暑易节，始一反焉（语气助词）
• 默默焉（……的样子）		 句首“焉 + 动词”= 怎么/哪里；不及物动词末尾缺地点状语 = 兼词“在那里/其中”。
12. 且 ① 副词：将近、几乎
② 副词：暂且、姑且
③ 连词：况且、尚且（递进）/ 并且		 • 年且九十（将近）
• 存者且偷生（姑且、暂且）
• 且焉置土石？（况且）		 且 + 数词 = 将近；且 + 动词且后文有转折或后续行动 = 暂且；放句首加反问 = 况且。
13. 虽 ① 连词：即使、哪怕（假设让步，最高频！）
② 连词：虽然（已然让步）		 • 虽我之死，有子存焉（即使）
• 虽有千里之能（虽然）		 0509 大坑提醒：古汉语“虽”超半数表未发生的假设“即使”，切忌一见“虽”就无脑译“虽然”！
14. 若 ① 连词：如果、假如
② 动词：像、好像、比得上
③ 代词：你、你的
④ 复音词“若夫”：至于		 • 若有作奸犯科者（如果）
• 曾不若孀妻弱子（比得上）
• 若为佣耕（你）		 句首设条件 = 如果；“A + 若 + B”比较 = 像/比得上；对话主语 = 你。
15. 因 ① 副词/连词：于是、就
② 介词：趁着、凭借、通过
③ 介词：因为		 • 宅边有五柳树，因以为号焉（于是就）
• 因利乘便（趁着）
• 因材施教（根据/依照）		 先有某契机 + 因 + 动词 = 于是/趁着；注意“因以为……”= “于是把它当作……”。
16. 所 ① 结构助词：“所 + 动”= ……的人/事/物
② 固定短语“所以”= ……的原因 / 用来……的办法
③ 被动句式“为……所……”		 • 视其所以（他做事的方法）
• 此臣所以报先帝而忠陛下之职分也（……的原因）
• 所以动心忍性（用来……的方式）		 遇“所以”必警觉！文言极少作现代“因此”，几乎全考“……的原因”或“用来……的手段”。
17. 乎 ① 句末助词：吗、呢、吧、啊（疑问/反问/揣测/感叹）
② 句中介词（=于）：在、对、比
③ 形容词词尾：……的样子		 • 学而时习之，不亦说乎？（吗）
• 醉翁之意不在酒，在乎山水之间也（在）
• 生乎吾前（比）		 放句末读语气；放句中“动词/形容词 + 乎 + 名词”一律等同于介词“于”（切勿将“在乎”错译为“在意”！）。
18. 矣 ① 句末助词：了（表动作已发生或状态即将改变）
② 句末助词：啊、啦（表强烈感叹）		 • 温故而知新，可以为师矣（了）
• 甚矣，汝之不惠！（啊——主谓倒装感叹）		 放陈述句末译作“了”（表新情况形成）；放感叹句形容词前倒装处，表惊叹“太……啊！”。

4.2 古今异义、通假字、四大词类活用与五大特殊句式“六字诀”直译

Semantic Shifts, Phonetic Loans, Flexible Word Classes, 5 Special Syntax Patterns & 6-Step Translation
翻译扣分重灾区清零 使动/意动/倒装/被动 留·删·补·换·调·变六字诀

一、古今异义高危词汇表（严防“以今律古”闹笑话）

文言以单音节词为主。很多看似熟悉的双音节词（如“妻子”“卑鄙”“交通”“无论”）在古文中其实是两个单音词连用或意义已彻底转移。翻译时必须拆解或置换为古代本义：

文言词 古代原义（考场必译） 现代义（绝对陷阱） 高频真题例句与拆译
走跑、疾行、逃跑慢步走、步行两股战战，几欲先走（几乎想要抢先逃跑）
去离开、距离到……去、前往委而去之（丢下城池离开）；去国怀乡（离开国都）
汤热水、开水菜汤、汤汁及其日中如探汤（如同把手伸进热水里）
兵兵器、武器 / 军队单个士兵非兵不利（不是兵器不锋利）；穷兵黩武（军队）
妻子妻子和儿女（两词并列）男子的配偶率妻子邑人来此绝境（带领妻子儿女和同乡人）
卑鄙出身低微、见识浅陋品行恶劣不道德先帝不以臣卑鄙（不嫌弃我身份低微、见识浅陋）
交通交错相通交通运输往来阡陌交通（田间小路交错相通）
绝境与人世隔绝的地方没有出路的危境来此绝境（来到这个与外界隔绝的地方）
无论更不用说、不要说条件连词“不管”乃不知有汉，无论魏晋（更不必说魏晋了）
可以可以凭此、可以用来能愿动词“能够”可以一战（可以凭借这一点去作战）
其实它的果实 / 实际上转折副词“实际上”叶徒相似，其实味不同（它们的果实味道不同）
地方土地方圆（面积）某一区域/处所今齐地方千里（齐国国土方圆千里）
牺牲祭祀用的纯色牲畜舍弃生命或利益牺牲玉帛，弗敢加也（祭祀用的猪牛羊与玉帛）
涕眼泪鼻涕临表涕零（流下眼泪）

二、通假字快速识别法与考卷高频通假清单

核心识别信号：当你按该字的本义和常用引申义在句中彻底讲不通，且换成一个读音相同或相近（或增减偏旁）的字后瞬间豁然开朗，即为通假字！翻译时按“通某字”的本义直接译出即可：

  • 说 通 悦（愉快、高兴）：学而时习之，不亦说乎？
  • 反 通 返（往返、返回）：寒暑易节，始一反焉。
  • 要 通 邀（邀请）：便要还家，设酒杀鸡作食。
  • 亡 通 无（没有）：河曲智叟亡以应。
  • 见 通 现（显露、表现）：才美不外见；何时眼前突兀见此屋。
  • 被 通 披（穿着）：将军身被坚执锐。
  • 知 通 智（智慧、明智）：孰为汝多知乎？
  • 属 通 嘱（嘱托）：属予作文以记之。

三、四大词类活用（使动 / 意动 / 名词作动词 / 名词作状语）

活用类型 语法结构识别特征 标准直译公式 真题例句精准示范
1. 使动用法 主语本身不发出这个动作或具此性质，而是致使宾语发生动作或状态改变。 “使 + 宾语 + 动/形” • 必先苦其心志，劳其筋骨（使他意志痛苦、使他筋骨劳累）
• 闻寡人之耳者（使我听到）
2. 意动用法 仅限形容词或名词，表达主语主观心理上对宾语的评价或看待态度（宾语客观没变）。 “认为 + 宾语 + …… / 把……当作……” • 渔人甚异之（认为这件事很奇特）
• 邑人奇之（认为他很非凡）
• 友善士（把贤士当作朋友）
3. 名词作动词 名词后直接带宾语，或名词前出现能愿动词/副词（欲/乃/不）且句中再无其他谓语动词。 译为与该名词相关的具体动作。 • 一狼洞其中（打洞）
• 策之不以其道（用马鞭驱赶）
• 名于世（闻名、出名）
4. 名词作状语 名词紧挨在动词前面修饰动作，但该名词不是主语（主语另有其人或承前省）。 译为“像……一样”“在……”“用……”“每天/每夜”。 • 其一犬坐于前（像狗一样蹲坐）
• 夜映积雪以诵（在夜里）
• 手自笔录（亲手/用笔）
⚠️ 考场 1 秒区分：使动 vs 意动

看宾语客观上有没有“真的发生改变”！“苦其心志” → 心志真的吃了苦，所以是使动；“轻之” / “奇其志” → 对方的漏洞没真的变轻、志向没真的变奇，只是说话人主观认为轻不足患或很奇异，所以是意动！

四、五大特殊句式与直译“留、删、补、换、调、变”六字诀

五大特殊句式 文言典型结构标志 直译处理动作（缺一扣分）
1. 判断句 ……者，……也 / ……也 / 乃、则、即、皆、非 原文通常不用“是”，译文必须补出“是 / 就是 / 不是”（如夫战，勇气也 → 作战，是凭勇气的）。
2. 被动句 见……于…… / 为……所…… / 于 / 意念被动 当主语明显是动作承受者时，译文必须补出“被”字（如见笑于乡人 → 被同乡人耻笑）。
3. 宾语前置 ① 否定句代词宾语：未之有也（未有之）
② 疑问代词宾语：何以战？（以何战）
③ 提宾标志“之/是”：何陋之有？（有何陋）		 必须把提前的宾语调回动词或介词后面再翻译（如未之有也 → 从来没有过这样的人/事）。
4. 状语后置
（兼定语后置）		 介词短语 于 / 以 + 名词 放到动词后面：战于长勺 / 假书于乡绅；定语后置：马之千里者 把后置的介词短语调回动词前面译为“在……/向……/用……”（如假书于乡绅 → 向乡绅借书）。
5. 省略句 承前省主语、省代词宾语“之”（公与之乘 vs 不察[之]）、省介词“于” 翻译时补全隐含主语或宾语（可加括号或不加），绝不能缺主语导致语义残缺。

《吴工制舟》（寓言体短篇）

吴人有善制大舟者，日取良木于山林，然好雕镂①窗棂，涂以丹青，饰以金碧，务令观者悦之，而不察舟底微隙。有老渔过而见之，甚异其工之巧，乃绕舟而视，良久，因指微隙谓曰：“子之舟固美矣，然江涛汹涌，此隙虽小，久必为巨浪所穿，子其速修之，毋致后患！”吴工轻之，仰天笑曰：“吾选大木百围，坚如铁石，微隙何足患？且吾舟非急走千里者，焉能遽覆？”遂不补而下之江。及至中流，飓风骤起，波如山立，江水自隙涌入，舟遂沉，工仅抱木而免，见笑于乡人。

注释：① 雕镂（diāo lòu）：雕刻镂空。

《周生假书》（笔记劝学短篇）

周生家贫而好学，每闻乡绅陆氏多藏古籍，乃备束脩①，徒步百里往谒，假②书以读。时方隆冬，北风怒号，室无炉火，生夜映积雪以诵，手冻僵则呵笔录其要语，虽指裂未尝折损一叶，亦不以饥寒废业。期年③归书，整洁如初，并一一校出原帙④脱误十余处，别纸录以呈之。陆氏览而奇之，叹曰：“世人多以富贵自骄，未之有如生之诚笃者也！且学而不思则罔，思而不录则忘，吾藏书久矣，今得子乃得其主。”因出秘本数帙尽赠之，且勉之勿忘初心。后生果以博雅名于世。

作及物动词，固定译为 “到、前往”（不作代词或助词“的”）。

虚词 #03而 · 转折 vs 修饰
出淤泥【而】不染 vs 密愧【而】出 / 面山【而】居
同样连接前后成分，怎么一秒辨出“却”还是“地”？
前后褒贬/常理反差 = 表转折“却、但是”；前为情状/方式（惭愧/面朝山）修饰后一个主要动作 = 表修饰“……地”（切忌机械硬译成“并且”）。

虚词 #04其 · 三大语气
【其】真无马邪？ / 【其】皆出于此乎？ / 子【其】修之！
当“其”不翻成“他的/它的”时，哪三种副词语气最常考？
① 配合反问句末“邪/乎” = 难道；② 配合推测语气 = 大概、恐怕；③ 劝勉祈使句 = 可要、应当。

虚词 #05以 / 所以
属予作文【以】记之 vs 亦不【以】饥寒废业 vs 正【所以】安其子
这三个“以”字和“所以”各自该怎样精准对译？
① 动 1 + 以 + 动 2 = 来、以便；② 以 + 缘由 = 因为；③ 文言“所以”必译 “……的原因”或“用来……的办法”（绝不直接写“因此”！）。

虚词 #06于 / 乎
苛政猛【于】虎 / 生【乎】吾前 / 在【乎】山水之间也
“乎”放在句子中间（而不是句末）时，等同于哪个虚词？
句中 “乎” = 介词“于”（在 / 比 / 对）！例如“生乎吾前”= 比我出生早，“在乎山水之间”= 在山水之间（不是“在意”）。

虚词 #07乃 / 则 / 因
【乃】不知有汉 vs 欲速【则】不达 vs 【因】利乘便
这三个虚词除“于是/就”外，哪几个反差义最易丢分？
① “乃”表意外反差 = 竟然；② “则”前后矛盾 = 却、反倒；③ “因”先有契机再行动 = 趁着、凭借（“因以为……”= 于是把它当作……）。

虚词 #08焉 / 虽 / 且
必有我师【焉】 / 【虽】我之死 / 年【且】九十
考卷遇上兼词“焉”和假设“虽”“且”时如何稳拿分？
① “焉”在动词末作兼词 = 在那里/在其中；② “虽”对未然之事 = 即使；③ “且”加数词 = 将近（放句首多表“况且”）。

活用异义 #09使动 vs 意动
【苦】其心志 / 【安】其子 vs 渔人甚【异】之 / 吴工【轻】之
一秒辨清使动与意动的最高效检验标尺是什么？
看宾语客观变没变！使儿子真获得平安 = 使动“使……”；对方本身没变，只是我觉得奇/轻视 = 意动“认为……/觉得……”。

活用异义 #10名作动 vs 名作状
一狼【洞】其中 / 【名】于世 vs 【犬】坐于前 / 生【夜】诵
同是名词放在句中，怎么区分是“作动词”还是“作状语”？
句中没其他动词且名词管宾语 = 名词作动词（打洞/闻名）；后面紧跟另一个真动词且它不是主语 = 名词作状语（像狗一样/在夜里）。

活用异义 #11古今异义组 A
几欲先【走】 / 委而【去】之 / 如探【汤】 / 非【兵】不利
请写出这四个高危单音古今异义词在考场上的必给释义。
走 = 跑、逃跑；去 = 离开（或卷走）；汤 = 热水、开水；兵 = 兵器、武器（或军队）。

活用异义 #12古今异义组 B
率【妻子】邑人 / 先帝不以臣【卑鄙】 / 阡陌【交通】 / 【无论】魏晋
如何防止把看似双音节的古代词汇当成现代词错译？
妻子 = 妻子和儿女；卑鄙 = 出身低微、见识浅陋；交通 = 交错相通；无论 = 更不用说。

活用异义 #13通假字还原法
不亦【说】乎 / 始一【反】焉 / 【亡】以应 / 才美不外【见】
考场生僻句中怀疑遇到通假字时，用哪两条线索还原？
按字面义完全讲不通时，试着用 同音/近音替代 或 增减偏旁 还原：说→悦（高兴）、反→返（往返）、亡→无（没有）、见→现（显露）。

句式直译 #14判断句
彼翁智者【也】 / 陈胜【者】，阳城人【也】 / 当立者【乃】扶苏
文言判断句直译最容易忘掉的 1 个关键汉字是什么？
翻译时必须手动补出判断动词 “是”（或否定判断“不是”），而“者”作为停顿词千万不能硬译成“……的人”。

句式直译 #15被动句
【为】巨浪【所】穿 / 【见】笑【于】乡人 / 受制【于】人
识别到这三大标志或主语本身是受事者时，译文怎么处理？
必须补译出 “被”字，并把“于+人”或“为+施事者”理顺为“被某人/某物 + 动词”（切忌把“为……所”错译为“为了”！）。

句式直译 #16宾语前置三式
【未之有】也 / 【何以】战？ / 何陋【之】有？
这三种典型宾语前置结构各自凭什么信号一秒识别？
① 否定词+代词+动（未之有→未有之）；② 疑问代词+动/介（何以战→以何战）；③ 宾语+之/是+动（何陋之有→有何陋）。翻译必调回正常语序！

句式直译 #17状语后置与省略
悉还七分【于子】 / 假书【于乡绅】 / 遂不补而下之【于】江
“动词 + 于/以 + 名词”放在句尾时翻译如何处理？
属 状语后置（介宾结构后置），翻译时需调到动词前面译成“把七成还给儿子 / 向乡绅借书”；遇“下之[于]江”省略介词与主语时必须补全！
